### Two versions per language

Each language now offers at most two versions. Node.js 22 (JavaScript and TypeScript), Python 3.11 and 3.12, and PHP 8.2 were retired.

- **Applications on a retired version** move to the recommended version on their next restart or deploy: Node.js 26.13.1, Python 3.13.18 and PHP 8.3.36. For JavaScript and TypeScript, Node.js 24 (24.22.3) stays available. If your application depends on a retired version, test it on one of the available versions and pick it in the application settings.
- **Creating or updating an application with a retired version** still works: the application is saved with the recommended version instead of answering `INVALID_VERSION`.
- The versions of each language are in the [knowledge base](/knowledge-base) and on [List Runtimes](/api-reference/endpoint/apps/runtimes) (`GET /v1/apps/runtimes`).
