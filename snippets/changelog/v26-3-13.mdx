### CLI and VS Code pages for developers

Vertra Cloud's developer tools now have their own pages:

- The **CLI** page covers installation, pre-deploy diagnostics, and commands for logs,
  applications, databases and automation with JSON output.
- The **official VS Code extension 1.0** page covers installation, connecting by account or API
  key, and features for deploy, logs, metrics, remote files, databases and snapshots inside the
  editor.

Open [CLI](/cli) or [VS Code Extension](/vscode-extension) to get started.

### New look for notifications

Notifications got a more compact look, with context-based icons and smooth transitions in light
and dark themes.

- New neutral, soft, outlined and solid presentations for success, error, info and update
  messages.
- Support for actions, a close button and a progress bar for operations that report their
  progress.
- Animations respect the device's reduced-motion preference.
