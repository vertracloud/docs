### Documentation in Portuguese and Spanish

The documentation is now available in Brazilian Portuguese and Spanish, alongside English. Pick the language in the switcher at the top of any page. English pages keep their addresses, and the translations live under `/pt-br` and `/es-es`. Guides, tutorials, Blob Storage, the developer tools and the changelog are translated. The API reference and the knowledge base stay in English in every language, so the contract reads the same everywhere.

### Corrections across the docs

- **API reference:** every endpoint now lists the authentication errors the API really returns: `AUTH_TOKEN_MISSING`, `API_KEY_INVALID` and `SESSION_REVOKED` with 401, and `API_KEY_IP_DENIED` and `API_KEY_SCOPE_DENIED` with 403. The generic `UNAUTHORIZED` code, which the API never returns, is gone, and the error examples show the right status codes.
- **Creating an app from the terminal:** run `vertra upload` in the project folder. It creates the application and saves its ID in `vertracloud.config`, so `vertra deploy` can then send new code to it. The docs used to start with `vertra deploy`, which only updates an application that already exists and fails on an account with none. The [CLI page](/cli#link-a-folder-to-an-app) also explains `vertra link` and `vertra unlink`.
- **Panel steps** point to the real tabs: **Settings → General**, **Deploy**, **Environment variables** and **Network**. Automatic deploy is **Settings → Deploy → Enable auto deploy**.
- **Database storage** is 6 GB + 1 GB for every 512 MB of RAM, or 3× the RAM when that is larger.
- **Application plus database:** running an application with PostgreSQL, MySQL or MongoDB needs Scale or above. With Redis, Pro is enough.
- **Workspace roles** have 20 permissions. Some pages said 19 or 21.
- **Code samples:** fixed the Python Discord bot (`message.channel.send`), the Flask, Telegram, Ruby, PHP and Django tutorials, and the Python, Go and JavaScript SDK examples.
- **Plan downgrade:** the example now moves Enterprise-4 to Intermediary, one step down.
