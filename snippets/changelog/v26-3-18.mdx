### Workspace ownership transfer removed

Transferring workspace ownership to another member has been removed from the platform.

- `POST /v1/workspaces/{id}/transfer-ownership` is no longer part of the API.
- The workspace owner is still the only member who can rename or delete the workspace, or
  link/unlink an application or database — that doesn't change, and remains fixed to the account
  that created the workspace.

### One error code for a subdomain already in use

Creating an application with a subdomain that another application already uses now returns
`409 SUBDOMAIN_TAKEN`, the same code as publishing or changing the subdomain.
`SUBDOMAIN_ALREADY_IN_USE` is no longer returned.

### Plan changes keep every remaining hour

When you switch plans, the time left on the current plan is converted into days of the new one
without rounding down, so switching right after a purchase no longer loses up to a day.
