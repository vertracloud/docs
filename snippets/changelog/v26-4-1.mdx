### Choose where uploaded files go

The **Upload changes** dialog in the file manager has a **Commit destination** field. It starts with
the folder you have open, and **Select** lets you pick any other folder of the application. Files are
written to that folder. A ZIP is extracted inside it and merged with the files already there, so files
you don't upload are kept.

- API: `POST /v1/apps/{id}/files/upload` accepts an optional `path` query parameter with the
  destination folder, relative to the application's root. Leave it empty or omit it to upload to the
  root. Three new error codes can come back: `INVALID_PATH`, `FORBIDDEN_PATH` and `PATH_IS_FILE`.
- SDKs: JavaScript `apps.files.upload(id, file, filename, { path })`, Python `upload(..., path="src")`
  and Go `ApplicationFileUploadParams{Path: "src"}`.
- CLI: `vertra app commit --path src` uploads into that folder.

### Uploaded files appear right away when restarting

With **Restart the application** checked, uploaded files used to show up in the file list only after
the restart finished. They now appear as soon as the upload completes.
