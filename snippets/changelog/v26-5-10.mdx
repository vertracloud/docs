### Runtime status in the dashboard

A shield next to the name of an application or database shows whether its runtime is up to date. It covers applications on a Vertra Cloud runtime and databases; applications built from a Docker image do not show it.

- **Up to date** (green), **update available** (blue), **security update** (amber, with a dot) and **retired version** (amber).
- **Hover** the shield to see the version in use and the new one. **Click** it for the details: the version in use, the new version, whether it includes security fixes and, for applications, a button to restart and apply it.
- The update is applied on the next restart (for databases, the next stop and start). Nothing restarts on its own.
- In the projects list, the shield appears only when there is something to apply.

### Runtime lines instead of patch versions

The site and the documentation now show each runtime by its line, such as Node.js 26 or Python 3.13, instead of the exact patch. Each line automatically receives the latest patch release, including security updates. Nothing changes in your applications: `VERSION=26` keeps running the newest patch of the 26 line.
