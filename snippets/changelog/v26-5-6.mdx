### Sign-in and account security

#### Email sign-in with an 8-character code

The code in the sign-in email now has 8 characters, shown in two blocks (`K7M2-QXAB`).

- **Paste it from anywhere.** Click anywhere on the code step and paste, or use the **Paste code** button. The dash and lowercase letters are accepted.
- **Open your inbox in one click.** The code step has a shortcut to your mail provider.
- **The email link only fills in the code.** You still click **Sign in** to finish.
- **Safer email.** The email says never to share the code and that Vertra never asks for it by email, phone or chat.

#### Email confirmation for sensitive actions

In the dashboard, these actions now ask for a code sent to your email:

- connecting a Google, GitHub or Discord account (GitHub only the first time you connect it);
- creating an API key;
- downgrading your plan;
- removing a saved card;
- turning off automatic renewal;
- deleting a workspace;
- resetting a database password.

This only applies to the dashboard. Requests made with an API key are not affected.

#### Emails and sessions

- **New emails** tell you when a Google, GitHub or Discord connection is added or removed.
- **New sign-in alerts** now also fire when you sign in from a country you have not used before.
- **Sign out now ends the session on Vertra too,** not only in your browser.

### Card payments pause after repeated declines

After several declined attempts, adding or paying with a card is paused for a while, and the message says how long to wait.

### API keys: changes to review

- **Downloading app code needs `apps:files`.** [Download Application](/api-reference/endpoint/apps/download) (`GET /v1/apps/{id}/download`) now requires the `apps:files` permission instead of `apps:read`. Keys created with only `apps:read` can no longer download the code: create a key with `apps:files`.
- **Changing how the app starts needs `apps:files`.** [Update Application Config](/api-reference/endpoint/apps/updateconfig) (`PATCH /v1/apps/{id}/config`) now also requires `apps:files` when a request changes `start_command`, `build_command` or `main_file`. Other config fields are unchanged.
- **Removed:** `POST /v1/users/me/generate-api-key`. Use `POST /v1/users/me/api-keys` to create keys.
