### Language runtimes updated to the latest releases

Go, Python, Ruby, .NET and Elixir published new patch releases, which include security fixes made by each project. Applications on these languages now run on them:

| Language | Before | Now |
| --- | --- | --- |
| Go | 1.26.10 · 1.27.3 | 1.26.11 · 1.27.4 |
| Python | 3.11.17 · 3.12.15 · 3.13.17 | 3.11.18 · 3.12.16 · 3.13.18 |
| Ruby | 3.3.12 · 3.4.11 | 3.3.13 · 3.4.12 |
| .NET | SDK 10.0.402 | SDK 10.0.404 |
| Elixir | 1.20.4 | 1.20.5 |

- **When it applies:** an application moves to the new version the next time it restarts or deploys. An application that keeps running stays on the version it started with until then.
- **Pinned versions keep their line:** an application pinned with `VERSION` moves to the new patch of the same line (for example, `3.12.15` becomes `3.12.16`). You don't need to change your `vertracloud.config`.
- **First restart:** the first restart on the new version can take a little longer than usual.

### Bun 1.4 is now the recommended version

Bun 1.4.4 is now both the recommended and the latest version. New Bun applications, and existing ones without `VERSION` in `vertracloud.config`, run on 1.4.4 from their next restart or deploy. Bun 1.3.14 is still available: declare `VERSION=1.3` to keep using it.

### Deno 2.8 removed

Deno 2.8.3 is no longer available, because the 2.8 line no longer receives fixes. Applications on Deno 2.8 run on 2.9.8 from their next restart or deploy, and `VERSION=2.8` now resolves to the recommended version.
