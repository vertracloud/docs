### Historial de actividad más completo

El historial de actividad de la cuenta y de cada proyecto incluye más eventos: cambios de archivos desde el gestor de archivos (guardar, eliminar, mover, subir), despliegues, restauraciones de snapshots y cambios de dominio.

Cada actividad muestra ahora quién la activó, con un filtro específico para explorar por origen.

### Claves de API con permisos y IP permitidas

Hasta ahora, una cuenta tenía una única clave de API con acceso total. Ahora puedes crear hasta **10 claves**, cada una con un nombre, un conjunto de permisos (aplicaciones, bases de datos, snapshots, cuenta, workspaces y notificaciones, con los atajos "solo lectura", "lectura y escritura" y "acceso total") y, opcionalmente, una lista de IP permitidas. La comprobación usa la IP de origen real, no una cabecera que envía el propio cliente. Una clave que usa solo un servidor de CI, por ejemplo, puede restringirse a crear despliegues sin ver nada más, y bloquearse a la IP de ese servidor.

El secreto de una clave nueva (`vc_live_...`) se muestra una sola vez, al crearla o rotarla; después solo permanecen visibles el inicio y el final. Las claves generadas antes de este cambio siguen funcionando con normalidad, con acceso total.

La generación heredada (el botón único de "generar clave") sigue disponible para scripts y para la CLI.
