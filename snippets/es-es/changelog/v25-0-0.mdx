### Descripción general

Mayo marca el inicio de Vertra Cloud con el lanzamiento del primer panel. Esta versión base aporta la gestión esencial de aplicaciones, la conectividad con bases de datos y los cimientos de todas las funciones posteriores.

---

### Funciones

#### Panel
Página inicial del panel para la gestión de aplicaciones y bases de datos.

- Ver todas las aplicaciones desplegadas
- Ver todas las bases de datos conectadas
- Resumen rápido del estado
- Listado y filtrado de proyectos
- Gestión básica de recursos

#### Detalles de la base de datos
Interfaz de gestión de las bases de datos conectadas.

- Ver la información de la base de datos
- Mostrar las credenciales de conexión
- Estadísticas de uso de la base de datos
- Gestión de la configuración
- Integración con la API

#### Detalles de la aplicación
Gestión de aplicaciones y visualización de archivos.

- Resumen de la aplicación
- Integración con el gestor de archivos
- Navegación por pestañas desde los parámetros de la URL
- Logs de la aplicación
- Estado del despliegue

#### Páginas de aplicaciones y bases de datos
Páginas de listado dedicadas para tenerlo todo organizado.

- Página de aplicaciones con todas las aplicaciones
- Página de bases de datos con todas las bases de datos
- Filtrado y ordenación
- Acciones rápidas por recurso

#### Campo de dominio personalizado
Soporte inicial de dominios personalizados en el modelo de aplicación.

- Configuración de dominio personalizado en las aplicaciones
- Validación de dominios
- Guía para configurar el DNS
- Base para las funciones de dominio personalizado

### Configuración de desarrollo

#### Herramientas de calidad de código
Estándares profesionales de desarrollo.

- Configuración de ESLint para el análisis estático del código

- Comprobaciones automáticas de calidad del código
- Aplicación uniforme del estilo de código

#### Sistema de diseño
Configuración personalizada de Tailwind.

- Tailwind CSS para los estilos
- Sistema de colores propio con los colores de la marca
- Tokens y utilidades de diseño
- Marco de diseño adaptable
