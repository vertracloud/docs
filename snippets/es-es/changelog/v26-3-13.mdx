### Páginas de la CLI y de VS Code para desarrolladores

Las herramientas para desarrolladores de Vertra Cloud ahora tienen páginas propias:

- La página de **CLI** cubre la instalación, los diagnósticos previos al despliegue y los comandos para logs, aplicaciones, bases de datos y automatización, con salida en JSON.
- La página de la **extensión oficial de VS Code 1.0** cubre la instalación, la conexión con tu cuenta o con una clave de API, y las funciones de despliegue, logs, métricas, archivos remotos, bases de datos y snapshots dentro del editor.

Abre [CLI](/es-es/cli) o [Extensión de VS Code](/es-es/vscode-extension) para empezar.

### Nuevo diseño para las notificaciones

Las notificaciones tienen un aspecto más compacto, con iconos según el contexto y transiciones suaves en los temas claro y oscuro.

- Nuevas presentaciones neutral, suave, con contorno y sólida para los mensajes de éxito, error, información y actualización.
- Compatibilidad con acciones, un botón de cierre y una barra de progreso para las operaciones que informan de su avance.
- Las animaciones respetan la preferencia de movimiento reducido del dispositivo.
