### Página de aplicaciones

Vertra Cloud tiene una página pública para las **aplicaciones** en `/apps`, en portugués, inglés y español.

Explica el camino desde ZIP o GitHub hasta el contenedor, los tipos Bot y Website, los runtimes compatibles, los métodos de despliegue y las funciones operativas: aislamiento, logs, métricas, snapshots, variables de entorno, publicación web y dominios personalizados.

También documenta el ciclo de vida y la recuperación tras las caídas, con las preguntas frecuentes publicadas como datos estructurados para los buscadores.

### Orígenes de las bases de datos

Las páginas públicas de PostgreSQL, MySQL, MongoDB y Redis incluyen ahora una sección sobre cómo surgió cada base de datos, con hitos históricos y el perfil de un autor o colaborador destacado.

Las páginas siguen disponibles en portugués, inglés y español.

### Nueva experiencia Enterprise

La página de Enterprise termina ahora con un configurador de capacidad rediseñado: memoria, cómputo, límite de proyectos y precio cambian a la vez al elegir un nivel.

El SLA, el soporte premium y la escala de 4 GB a 32 GB ahora se explican con más claridad.
