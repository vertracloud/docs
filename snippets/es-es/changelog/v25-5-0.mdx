### Descripción general

Noviembre trajo mejoras críticas de infraestructura y un rediseño importante del modelo de precios. El nuevo sistema de reinicio automático evita los bucles de fallos, el nuevo plan Intermediary amplía el acceso y el alojamiento de sitios estáticos permite desplegar frontends puros.

---

### Novedades

#### Reinicio automático
Reinicio inteligente de contenedores con detección de caídas para evitar bucles de fallos.

- Supervisa el estado del contenedor de forma continua
- Solo reinicia ante fallos reales de ejecución (caídas), no ante errores de configuración o de sintaxis
- Evita bucles de reinicio infinitos que malgastan recursos
- Estabilización automática ante problemas transitorios

#### Archivo .vertraignore
Controla qué archivos y carpetas se excluyen de los despliegues automáticos.

- Funciona de forma similar a `.gitignore` para el despliegue
- Evita subir archivos innecesarios
- Optimiza la velocidad del despliegue y reduce el tamaño del paquete

#### Commits mejorados
Flujo de commits reforzado para más estabilidad y fiabilidad.

- Proceso de despliegue simplificado
- Mejor seguimiento de los commits y opciones de rollback
- Mayor fiabilidad en los despliegues

#### Alojamiento de sitios estáticos
Nueva opción de lenguaje para alojar aplicaciones frontend puras.

- Despliegue directo de sitios HTML, CSS y JavaScript
- Opción de lenguaje `static` al crear el proyecto
- Ideal para sitios estáticos, SPA y documentación
- Servicio automático con los tipos MIME adecuados

#### Nueva estructura de planes
Niveles de precio rediseñados con asignaciones de recursos claras.

- **Plan Intermediary**: R\$ 18,99/mes con soporte de dominio personalizado
- **Plan PRO**: dominio personalizado incluido y hasta 2 APIs alojadas por R\$ 5,99/mes
- vCPU asignadas actualizadas por nivel de plan
- Propuesta de valor más clara en cada nivel

#### Pagos con tarjeta
Primera implementación de la interfaz para el pago con tarjeta de crédito.

- Base para el procesamiento de pagos con tarjeta de crédito
- Preparación para opciones de pago más amplias
- Experiencia de compra mejorada

#### Descargar .env
Exporta las variables de entorno del proyecto como archivo.

- Descarga de todas las variables de entorno de una vez
- Práctico para configurar el entorno de desarrollo local
- Acceso seguro y sin conexión a la configuración

#### Mejoras visuales
- Botón de descarga añadido a la pestaña de archivos
- Carga del panel más rápida

- Detección automática al pegar variables de entorno

- Subidas de archivos más rápidas
- Operaciones de commit más ágiles

#### Nueva página de pago
Flujo de pago completamente rediseñado.

- Opciones de pago más claras
- Mejor experiencia de usuario durante la compra
- Compatibilidad con varios métodos de pago
- Historial de transacciones y acceso a las facturas
