### Descripción general

Julio marcó un gran hito con el lanzamiento del sistema de pagos, la gestión de organizaciones y los ajustes completos de las aplicaciones. La plataforma pasó de ser un servicio de alojamiento básico a un sistema completo de gestión de aplicaciones, con colaboración en equipo y funciones de facturación.

---

### Novedades

#### Pestañas de ajustes de la aplicación
Gestión organizada de las aplicaciones en pestañas dedicadas.

- **General**: ajustes básicos e información de la aplicación
- **Variables de entorno**: gestión de secretos y configuración
- **Despliegues**: historial de despliegues y configuración del despliegue automático
- **Red**: dominio personalizado y opciones de red
- **Zona de peligro**: operaciones destructivas, como la eliminación de la aplicación

#### Variables de entorno
Sistema completo de gestión de secretos y configuración.

- Operaciones CRUD completas para las variables de entorno
- Sección dedicada a los secretos para datos sensibles
- Soporte de pegado masivo para una configuración rápida
- Inyección de variables de entorno en tiempo real
- Cifrado de las variables en reposo

#### Dominios personalizados
Gestión de DNS y subdominios para las aplicaciones.

- Configuración de un dominio personalizado para cualquier aplicación
- Guía y validación de la configuración de DNS
- Personalización del subdominio
- Aprovisionamiento de certificados SSL/TLS

#### Despliegues automáticos
Despliegue automático desde webhooks de GitHub.

- Integración con webhooks de GitHub
- Despliegue automático al hacer push en la rama indicada
- Configuración y gestión de webhooks
- Logs e historial de despliegues

#### Organizaciones
Gestión completa de equipos con control de acceso basado en roles.

- Crear y gestionar organizaciones
- Gestión de miembros con asignación de roles
- Permisos de commit por rol
- Control de acceso a las copias de seguridad por rol
- Eliminación de organizaciones

#### Página de precios
Estructura de precios completa con comparativa de planes.

- Tabla comparativa de niveles
- Lista de funciones por plan
- Precios de los planes de bases de datos
- Opciones de precio anual
- Diferenciación clara entre planes

#### Sistema de pagos
Integración de Mercado Pago para la facturación.

- **Integración con PIX**: método de pago instantáneo brasileño
- Página de facturas con el historial de transacciones
- Página de pago para la compra de planes
- Gestión de la renovación de planes
- Compatibilidad con varios métodos de pago

#### Códigos de canje
Canje de códigos promocionales.

- Canje de códigos promocionales
- Validación y verificación de códigos
- Seguimiento y historial de uso

#### Gestión de planes
Interfaz de gestión de planes fácil de usar.

- Subir a un nivel superior
- Bajar a un nivel inferior
- Renovación del plan
- Historial de cambios de plan

#### Avisos de caducidad del plan
Alertas sobre la próxima caducidad del plan.

- Aviso por correo antes de la caducidad
- Indicadores de aviso en el panel
- Información sobre el tiempo que queda para renovar
- Recordatorio de renovación en los ajustes

#### Clave de API
Solicitud y gestión de claves de API desde el panel.

- Generar claves de API
- Revocar claves
- Interfaz de gestión de claves
- Uso de la clave de API en las aplicaciones

#### Actividad y registros de auditoría
Seguimiento completo de la actividad para garantizar la trazabilidad.

- Seguimiento de la actividad de las aplicaciones
- Logs de actividad de las bases de datos
- Historial de acciones del usuario
- Fecha y detalles de cada acción
- Posibilidad de exportar
