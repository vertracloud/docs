### Inicio de sesión y seguridad de la cuenta

#### Inicio de sesión por correo con código de 8 caracteres

El código del correo de inicio de sesión ahora tiene 8 caracteres, mostrados en dos bloques (`K7M2-QXAB`).

- **Pégalo desde cualquier sitio.** Haz clic en cualquier punto del paso del código y pega, o usa el botón **Pegar código**. Se aceptan el guion y las letras minúsculas.
- **Abre tu bandeja de entrada con un clic.** El paso del código tiene un acceso directo a tu proveedor de correo.
- **El enlace del correo solo rellena el código.** Sigues haciendo clic en **Iniciar sesión** para terminar.
- **Correo más seguro.** El correo avisa de que nunca compartas el código y de que Vertra nunca lo pide por correo, teléfono ni chat.

#### Confirmación por correo en acciones sensibles

En el panel, estas acciones ahora piden un código enviado a tu correo:

- conectar una cuenta de Google, GitHub o Discord (GitHub solo la primera vez que lo conectas);
- crear una clave de API;
- bajar de plan;
- eliminar una tarjeta guardada;
- desactivar la renovación automática;
- eliminar un workspace;
- restablecer la contraseña de una base de datos.

Esto solo vale para el panel. Las peticiones hechas con clave de API no se ven afectadas.

#### Correos y sesiones

- **Correos nuevos** avisan cuando se añade o se quita una conexión con Google, GitHub o Discord.
- **El aviso de nuevo acceso** ahora también se envía cuando entras desde un país que no habías usado antes.
- **Cerrar sesión ahora termina la sesión también en Vertra,** no solo en el navegador.

### Los pagos con tarjeta se pausan tras rechazos repetidos

Después de varios intentos rechazados, añadir o pagar con tarjeta queda en pausa durante un tiempo, y el mensaje indica cuánto esperar.

### Claves de API: cambios que conviene revisar

- **Descargar el código de la aplicación exige `apps:files`.** [Download Application](/api-reference/endpoint/apps/download) (`GET /v1/apps/{id}/download`) ahora exige el permiso `apps:files` en lugar de `apps:read`. Las claves creadas solo con `apps:read` ya no descargan el código: crea una clave con `apps:files`.
- **Cambiar cómo arranca la aplicación exige `apps:files`.** [Update Application Config](/api-reference/endpoint/apps/updateconfig) (`PATCH /v1/apps/{id}/config`) ahora también exige `apps:files` cuando una petición cambia `start_command`, `build_command` o `main_file`. Los demás campos de la configuración no cambian.
- **Eliminada:** `POST /v1/users/me/generate-api-key`. Usa `POST /v1/users/me/api-keys` para crear claves.
