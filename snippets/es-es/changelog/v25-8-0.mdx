### Descripción general

Febrero de 2026 trajo funciones críticas de gestión de bases de datos y herramientas de desarrollo integradas. La extensión oficial de VSCode, el soporte de bases de datos gestionadas y las funciones de seguridad reforzadas convierten a Vertra Cloud en una plataforma completa para el desarrollo full stack.

---

### Novedades

#### Extensión de VSCode
Extensión oficial de Vertra Cloud para VS Code.

- Despliegue directo desde el editor
- Gestión de aplicaciones desde VS Code
- Visualización de logs en tiempo real en la barra lateral
- Estado y métricas rápidas
- Creación de proyectos integrada
- Disponible en el marketplace de VS Code

#### Bases de datos gestionadas
Alojamiento de bases de datos listo para producción, con gestión automática.

- **PostgreSQL 17**
- **MongoDB 8.0**

#### Certificados TLS automáticos
Conexiones cifradas a las bases de datos desde el primer momento.

- Generación automática de certificados TLS
- Gestión de la renovación de certificados
- Soporte de certificados de cliente
- Requisitos de conexión segura

#### Soporte de MySQL
Alojamiento de bases de datos MySQL 8.0.

- MySQL 8.0 con las últimas funciones
- Autenticación X509 obligatoria por seguridad

---

### Mejoras

#### Entrega de correos
Sistema de correo optimizado.

- Mayor velocidad en la entrega de los correos de enlace mágico
- Mejor enrutamiento del correo
- Menor latencia en la entrega
- Mayor fiabilidad

#### Correcciones de dominios personalizados
Resueltos los problemas de configuración de DNS.

- Corregidos los errores 404 en algunas configuraciones de dominio personalizado
- Mejor gestión de la propagación de DNS
- Mejor emisión de certificados para dominios personalizados

#### Gestión de bases de datos
Gestión mejorada de certificados y credenciales.

- Corregidos los casos límite en la generación de certificados
- Mejor visualización y gestión de las credenciales
- Comprobación de conexión a bases de datos mejorada

---

### Correcciones de errores

- Corregidos los problemas de temporización en la entrega de correos
- Corregida la generación de certificados en casos límite
- Corregida la configuración de DNS de dominios personalizados
- Mejorada la resiliencia de las conexiones a bases de datos
