### Carpetas y favoritos guardados por cuenta

Las carpetas y los favoritos ahora se guardan en la cuenta, en lugar de depender del almacenamiento local del navegador o del editor.

- La organización personal está separada de la organización de cada workspace.
- Las carpetas se pueden crear, renombrar, cambiar de color y reordenar.
- Las aplicaciones y las bases de datos se pueden colocar en carpetas y marcar como favoritas de forma independiente.
- El panel, los workflows, la CLI, MCP y la extensión de VS Code usan la misma organización persistida.
- La lista de proyectos y Flow muestran el mismo estado de carpetas y favoritos; los grupos del lienzo de Flow siguen siendo locales e independientes.
- Las acciones se registran en el historial de actividad, incluso cuando se realizan con una clave de API.

Los grupos de Flow son otra cosa: organizan elementos en el lienzo local. No hay sincronización ni migración entre los grupos de Flow y las carpetas de recursos.

### Opciones de reinicio: reinstalar dependencias y forzar build

[Reiniciar aplicación](/es-es/api-reference/endpoint/apps/restart) ahora acepta dos campos opcionales en el cuerpo de la petición:

- `reinstall_dependencies` reinstala las dependencias de la aplicación desde cero, ignorando la caché de instalación; equivale a "Reinstalar dependencias" en el gestor de archivos del panel.
- `force_build` vuelve a ejecutar el comando de build de la aplicación aunque ningún archivo de código haya cambiado desde el último build; equivale a "Forzar build" en el panel.

Esto reemplaza la ruta separada de instalación de dependencias. Enviar cualquiera de las dos opciones consume una posición del límite de despliegues por hora de tu plan.

### Extensión de VS Code 1.0

La extensión de Vertra Cloud para VS Code llega a la versión 1.0, disponible en el VS Code Marketplace y en Open VSX, además de un archivo `.vsix` para la instalación manual.

El archivo `vertracloud.config` de la carpeta vinculada ahora tiene soporte específico: autocompletado de campos, descripciones al pasar el cursor y advertencias en línea cuando falta un valor o está mal formado. Los logs en tiempo real ahora se envían a un canal de salida del editor en lugar de a un terminal integrado.

El resto de acciones de gestión de aplicaciones siguen disponibles en el panel.

Consulta [Gestiona Vertra Cloud desde VS Code](/es-es/vscode-extension) para ver la lista completa de funciones.
