### Servidor MCP y peticiones con clave de API

Vertra Cloud ya tiene un servidor MCP oficial (`@vertracloud/mcp`), que permite a las herramientas compatibles con MCP gestionar aplicaciones, bases de datos, snapshots y facturación, siempre a través de tu clave de API y dentro de lo que esta permita. Instálalo en local con `npx -y @vertracloud/mcp` o conéctate al endpoint MCP oficial que aparece en la página de integración.

Junto con él llegan tres nuevos permisos de clave de API: `billing:read` (listar pedidos y consultar su estado), `billing:write` (crear un pedido de plan y generar un código Pix) y `redeem:write` (canjear un código promocional). Cambiar a un plan inferior sigue siendo una acción exclusiva del panel.

Consulta [Conecta Vertra Cloud a agentes de IA (MCP)](/es-es/mcp) para ver la lista completa de herramientas.
