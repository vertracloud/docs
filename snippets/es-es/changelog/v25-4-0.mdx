### Descripción general

Septiembre trajo herramientas críticas para desarrolladores y un sistema de logs unificado. El runtime de Bun añade una alternativa moderna de JavaScript, las métricas inteligentes aportan información sobre el comportamiento de las aplicaciones y la extensión de VSCode lleva los despliegues de Vertra Cloud directamente al editor.

---

### Novedades

#### Sistema de logs unificado
Seguimiento centralizado de errores y caídas de todas las aplicaciones.

- Los errores y las caídas se guardan ahora en la pestaña LOGS dedicada
- Interfaz unificada para ver todos los logs de las aplicaciones
- Filtrado y búsqueda sencillos en el historial de logs
- Mejor depuración e investigación de incidencias

#### Soporte de Bun
Runtime rápido de JavaScript y TypeScript ya disponible.

- Despliegue de aplicaciones con Bun 1.2.2 o posterior
- Alternativa a Node.js con mayor rendimiento
- Soporte completo de TypeScript de serie
- Compatible con los paquetes npm existentes

#### Métricas inteligentes
Monitorización automática del rendimiento a intervalos regulares.

- Métricas recogidas cada 5 minutos
- Seguimiento del uso de CPU, del consumo de memoria y del número de peticiones
- Datos históricos para el análisis del rendimiento
- Base para las funciones de escalado automático

#### Pestaña de logs de la aplicación
Nueva interfaz dedicada a los logs de las aplicaciones.

- Transmisión de logs en tiempo real
- Consulta del historial de logs
- Filtrado y búsqueda de logs
- Integración con el seguimiento de errores

#### Extensión de VSCode
Extensión oficial de Vertra Cloud publicada para pruebas beta.

- Despliegue directo desde VS Code
- Gestión de las aplicaciones desde el editor
- Logs y métricas en la barra lateral
- Versión alfa disponible en el marketplace de VS Code

### Actualizaciones de runtimes

#### Versiones de Node.js
Ya se admiten varias versiones de Node.js.

- Node.js 22.18.0
- Node.js 24.5.0
- Selección automática de la versión durante el despliegue

#### Versión de Python
Ya disponible el soporte de Python 3.13, la versión más reciente.

#### Runtime de Bun
- Bun 1.2.2
