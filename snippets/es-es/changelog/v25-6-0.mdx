### Descripción general

Diciembre trajo soporte para nuevos runtimes de lenguajes y mejoró el sistema promocional con el cupón de temporada VERTRA30. Las mejoras en la entrega de correos garantizan una mejor comunicación con los usuarios de toda la plataforma.

---

### Novedades

#### Soporte de Go
Runtime de Go añadido para aplicaciones de alto rendimiento.

- Soporte de Go para el despliegue
- Compilación automática de Go
- Gestión de dependencias de módulos de Go
- Tiempos de build rápidos
- Ideal para microservicios y herramientas de CLI

#### Soporte de PHP
Runtime de PHP 8.x añadido para aplicaciones web.

- Soporte del runtime de PHP 8.x
- Compatibilidad con los frameworks web de PHP más habituales
- Soporte de configuración de Apache/Nginx
- Gestión de paquetes de PHP con Composer
- Alojamiento de aplicaciones web

#### Sistema de cupones
Soporte de códigos promocionales para descuentos en los pedidos.

---

### Mejoras

- Mayor fiabilidad en la entrega de correos y en el renderizado de las plantillas

---

### Correcciones de errores

- Resueltos los fallos en la entrega de correos
- Corregidos los cálculos de fechas y duraciones
- Mejorado el manejo de zonas horarias
