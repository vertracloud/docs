### Se elimina la transferencia de propiedad del workspace

Se ha eliminado de la plataforma la transferencia de la propiedad de un workspace a otro miembro.

- `POST /v1/workspaces/{id}/transfer-ownership` ya no forma parte de la API.
- El propietario del workspace sigue siendo el único miembro que puede renombrar o eliminar el workspace, o vincular y desvincular una aplicación o una base de datos. Eso no cambia y queda fijado a la cuenta que creó el workspace.

### Un solo código de error para un subdominio ya en uso

Crear una aplicación con un subdominio que ya usa otra aplicación ahora devuelve `409 SUBDOMAIN_TAKEN`, el mismo código que al publicar o cambiar el subdominio. `SUBDOMAIN_ALREADY_IN_USE` ya no se devuelve.

### Los cambios de plan conservan cada hora restante

Al cambiar de plan, el tiempo que queda en el plan actual se convierte en días del nuevo plan sin redondear a la baja, así que cambiar justo después de una compra ya no hace perder hasta un día.

### Verificación de bot al iniciar sesión

Al pedir por correo un código para iniciar sesión, ahora aparece una comprobación rápida de Cloudflare. La mayoría de las veces se supera sola; cuando no, basta con un clic para confirmar que eres una persona. Iniciar sesión con Discord, GitHub o Google no cambia.
