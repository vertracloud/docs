### Descripción general

Agosto trajo un rediseño completo de la plataforma, con una gestión de archivos modernizada, documentación completa de la API y una gestión más sencilla de las credenciales de las bases de datos. La renovación visual y las mejoras de funciones hacen que la plataforma sea más intuitiva y más amigable para los desarrolladores.

---

### Novedades

#### Modernización del gestor de archivos
Renovación visual y funcional completa del sistema de gestión de archivos.

- Interfaz nueva y moderna, más fácil de usar
- Botón de commit para que los usuarios del gestor de archivos desplieguen los cambios directamente
- Botón para reinstalar dependencias para los usuarios del plan Free
- Visualización del árbol de archivos mejorada
- Soporte de arrastrar y soltar
- Extracción de archivos ZIP

#### Certificados de bases de datos
Gestión simplificada de certificados para conexiones seguras a bases de datos.

- Flujo unificado de copia de certificados para Redis, MongoDB y PostgreSQL
- Nueva pestaña de certificados en los ajustes de la base de datos
- Copia de certificados al portapapeles con un solo clic
- Información clara sobre los certificados
- Mejor organización de los certificados

#### Referencia de la API
Documentación completa de la API REST publicada.

- Documentación completa del endpoint de aplicaciones
- Referencia del endpoint de bases de datos
- Documentación del endpoint de organizaciones
- Referencia del endpoint de usuarios
- Documentación del endpoint de servicios
- Ejemplos interactivos de la API y muestras de peticiones y respuestas

#### Soporte de TSX
Soporte de archivos TypeScript JSX en el gestor de archivos.

- Los archivos `.tsx` ya se reconocen y se pueden editar
- Resaltado de sintaxis completo para TSX
- Gestión correcta de estos archivos en los commits

#### Enlace a la aplicación en las tarjetas
Tarjetas de proyecto del panel mejoradas.

- En sitios web y APIs, la URL del despliegue se muestra directamente en la tarjeta del proyecto
- Acceso rápido para ver las aplicaciones en directo
- Navegación con un solo clic a la aplicación en ejecución

#### Abrir la aplicación
Comportamiento de apertura de aplicaciones mejorado.

- Ahora se abre en la misma pestaña en lugar de en una pestaña nueva
- Mejor experiencia de usuario
- Mejor gestión de las pestañas del navegador

#### Rediseño de la plataforma
Gran modernización visual en todo el sitio web.

- Esquema de colores y sistema de diseño actualizados
- Tipografía y espaciado mejorados
- Mejor jerarquía visual
- Componentes de interfaz modernos en todo el sitio
- Mejoras en el diseño adaptable
