### Páginas por idioma y por base de datos

#### Una página por lenguaje

El sitio ahora tiene **`/runtimes`**, la lista de los diez lenguajes que ejecuta la plataforma, y una página propia para cada uno: JavaScript, TypeScript, Python, Go, Rust, Java, Bun, PHP, Ruby y sitios estáticos.

Cada página responde a lo que la gente pregunta antes de registrarse:

- **Qué versiones existen**, cuál es la recomendada y cuál la más reciente, con el valor exacto de `VERSION` para `vertracloud.config`.
- **Qué gestiona la plataforma automáticamente** para ese runtime: instalación de dependencias durante el build, reinicio automático, logs y métricas en vivo.
- **Qué se ejecuta con él**: bots, APIs, workers, sitios.
- **La configuración mínima**, en un bloque que se puede copiar.
- **Las preguntas más frecuentes**, con respuestas breves: las mismas que llegan a soporte.

La tabla comparativa de arriba muestra los diez lenguajes uno al lado del otro, para quien todavía esté eligiendo.

#### Una página por base de datos

Las cuatro bases de datos gestionadas tienen sus propias páginas bajo `/databases`: **PostgreSQL**, **MySQL**, **MongoDB** y **Redis**. Cada una cubre la versión, el puerto, el modo de autenticación y el formato del host, un comando de conexión listo para usar con TLS, y qué hace cada operación del panel, incluido lo que borra un reinicio destructivo.

La página `/databases` sigue siendo la visión general del servicio; las nuevas páginas son para quien ya sabe qué motor quiere.

#### En tres idiomas

Todas las páginas existen en portugués, inglés y español, con la URL de cada idioma declarada para los buscadores. El FAQ de cada página también se publica como datos estructurados, para que pueda aparecer directamente en los resultados de búsqueda.

#### Dónde encontrarlas

Los diez lenguajes y las cuatro bases de datos aparecen en el pie de página de cada página, en sus propias columnas, y los lenguajes también aparecen en el menú superior **Recursos**, sin pasar por el hub.

#### Limpieza

Las páginas de prototipo que nunca se anunciaron se retiraron junto con algunos archivos de imagen sin uso; no se eliminó ninguna URL publicada antes.
