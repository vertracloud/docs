### Documentación en portugués y español

La documentación ya está disponible en portugués de Brasil y en español, además de en inglés. Elige el idioma en el selector de la parte superior de cualquier página. Las páginas en inglés conservan sus direcciones, y las traducciones están en `/pt-br` y `/es-es`. Las guías, los tutoriales, Blob Storage, las herramientas de desarrollo y el changelog están traducidos. La referencia de la API y la base de conocimiento siguen en inglés en todos los idiomas, para que el contrato se lea igual en todas partes.

### Correcciones en toda la documentación

- **Referencia de la API:** cada endpoint ahora lista los errores de autenticación que la API devuelve de verdad: `AUTH_TOKEN_MISSING`, `API_KEY_INVALID` y `SESSION_REVOKED` con 401, y `API_KEY_IP_DENIED` y `API_KEY_SCOPE_DENIED` con 403. El código genérico `UNAUTHORIZED`, que la API nunca devuelve, se ha eliminado, y los ejemplos de error muestran los códigos de estado correctos.
- **Crear una app desde el terminal:** ejecuta `vertra upload` en la carpeta del proyecto. Crea la aplicación y guarda su ID en `vertracloud.config`, y a partir de ahí `vertra deploy` le envía el código nuevo. La documentación empezaba con `vertra deploy`, que solo actualiza una aplicación que ya existe y falla en una cuenta sin ninguna. La [página de la CLI](/es-es/cli#vincular-una-carpeta-a-una-aplicación) también explica `vertra link` y `vertra unlink`.
- **Los pasos del panel** apuntan a las pestañas reales: **Ajustes → General**, **Deploy**, **Variables de entorno** y **Red**. El despliegue automático está en **Ajustes → Deploy → Activar deploy automático**.
- **El almacenamiento de la base de datos** es 6 GB + 1 GB por cada 512 MB de RAM, o 3× la RAM cuando eso es mayor.
- **Aplicación más base de datos:** ejecutar una aplicación con PostgreSQL, MySQL o MongoDB requiere Scale o superior. Con Redis, basta con Pro.
- **Los roles de workspace** tienen 20 permisos. Algunas páginas decían 19 o 21.
- **Ejemplos de código:** corregidos el bot de Discord en Python (`message.channel.send`), los tutoriales de Flask, Telegram, Ruby, PHP y Django, y los ejemplos de las SDK de Python, Go y JavaScript.
- **Downgrade de plan:** el ejemplo ahora lleva Enterprise-4 a Intermediary, un escalón más abajo.
