### Descripción general

Enero de 2026 marcó el lanzamiento oficial de la beta pública de Vertra Cloud, con una API REST completa y documentación exhaustiva. La plataforma se abrió a la comunidad con funciones de colaboración en equipo.

---

### Funciones

#### API v1
La primera versión pública de la API REST de Vertra Cloud.

- API REST completa para todas las operaciones de la plataforma
- Referencia completa de la API
- Ejemplos de peticiones y respuestas
- Autenticación con clave de API
- Límites de peticiones y gestión de cuotas

#### Workspaces
Colaboración en equipo con control de acceso basado en roles.

- Crear y gestionar workspaces para equipos
- 5 roles predefinidos: Owner, Admin, Developer, Operator, Viewer
- Gestión de permisos basada en roles
- Invitación y gestión de miembros
- Aislamiento y seguridad de los workspaces

#### Beta pública
Lanzamiento oficial del periodo de beta abierta.

- Plataforma abierta al registro público de usuarios
- Pruebas beta y recogida de opiniones
- Soporte a la comunidad de usuarios
- Mejoras de estabilidad y rendimiento basadas en las opiniones recibidas

#### Documentación
Documentación completa de la API y de la plataforma.

- Sitio de documentación en docs.vertracloud.app
- Referencia de la API con todos los endpoints
- Ejemplos de código y tutoriales
- Guías de inicio
- Preguntas frecuentes y solución de problemas
