### Visão geral

Agosto trouxe um redesenho completo da plataforma, com um gerenciador de arquivos modernizado, documentação completa da API e um tratamento simplificado das credenciais de banco de dados. A atualização visual e as melhorias de funcionalidades tornam a plataforma mais intuitiva e amigável para desenvolvedores.

---

### Novas funcionalidades

#### Modernização do gerenciador de arquivos
Reformulação visual e funcional completa do sistema de gerenciamento de arquivos.

- Nova interface moderna, com mais usabilidade
- Botão de commit para os usuários do gerenciador de arquivos fazerem deploy das alterações diretamente
- Botão de reinstalar dependências para usuários do plano Free
- Visualização em árvore de arquivos aprimorada
- Suporte a arrastar e soltar
- Recursos de extração de arquivos ZIP

#### Certificados de banco de dados
Gerenciamento simplificado de certificados para conexões seguras com bancos de dados.

- Fluxo unificado de cópia de certificados para Redis, MongoDB e PostgreSQL
- Nova aba de certificados nas configurações do banco de dados
- Cópia de certificados para a área de transferência com um clique
- Exibição clara das informações do certificado
- Melhor organização dos certificados

#### Referência da API
Documentação completa da API REST publicada.

- Documentação completa do endpoint de Aplicações
- Referência do endpoint de Bancos de dados
- Documentação do endpoint de Organizações
- Referência do endpoint de Usuários
- Documentação do endpoint de Serviços
- Exemplos interativos da API e amostras de requisição e resposta

#### Suporte a TSX
Adicionado suporte a arquivos TypeScript JSX no gerenciador de arquivos.

- Arquivos `.tsx` agora são reconhecidos e editáveis
- Realce de sintaxe completo para TSX
- Tratamento adequado dos arquivos nos commits

#### Link da aplicação nos cards
Cards de projetos do dashboard aprimorados.

- Para sites e APIs, a URL do deploy agora aparece diretamente nos cards de projeto
- Acesso rápido para visualizar as aplicações no ar
- Navegação com um clique até a aplicação em execução

#### Abrir aplicação
Comportamento aprimorado ao abrir uma aplicação.

- Agora abre na mesma aba, em vez de uma nova aba
- Melhor experiência do usuário
- Melhor gerenciamento das abas do navegador

#### Redesenho da plataforma
Modernização visual completa do site inteiro.

- Esquema de cores e design system atualizados
- Tipografia e espaçamento aprimorados
- Melhor hierarquia visual
- Componentes de interface modernos em todo o site
- Melhorias de design responsivo
