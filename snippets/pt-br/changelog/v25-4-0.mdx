### Visão geral

Setembro trouxe ferramentas essenciais para desenvolvedores e um sistema de logs unificado. O runtime Bun adiciona uma alternativa moderna de JavaScript, as métricas inteligentes oferecem insights sobre o comportamento das aplicações, e a extensão do VSCode leva os deploys da Vertra Cloud diretamente para o seu editor.

---

### Novas funcionalidades

#### Sistema de logs unificado
Rastreamento centralizado de erros e falhas de todas as aplicações.

- Erros e falhas agora armazenados em uma aba LOGS dedicada
- Interface unificada para visualizar todos os logs das aplicações
- Filtragem e busca fáceis no histórico de logs
- Melhor depuração e investigação de problemas

#### Suporte ao Bun
Runtime rápido de JavaScript e TypeScript agora disponível.

- Deploy de aplicações com Bun 1.2.2 ou superior
- Alternativa ao Node.js com desempenho mais rápido
- Suporte completo a TypeScript desde o início
- Compatível com os pacotes npm existentes

#### Métricas inteligentes
Monitoramento automatizado de desempenho em intervalos regulares.

- Métricas coletadas a cada 5 minutos
- Acompanhamento de uso de CPU, consumo de memória e número de requisições
- Dados históricos para análise de desempenho
- Base para recursos de auto-scaling

#### Aba de logs da aplicação
Nova interface dedicada de logs para as aplicações.

- Transmissão de logs em tempo real
- Recuperação de logs históricos
- Recursos de filtragem e busca nos logs
- Integração com o rastreamento de erros

#### Extensão do VSCode
Extensão oficial da Vertra Cloud publicada para testes beta.

- Deploy diretamente pelo VS Code
- Gerenciamento de aplicações a partir do editor
- Visualização de logs e métricas na barra lateral
- Versão alpha disponível no marketplace do VS Code
