### Servidor MCP e requisições guiadas por chave de API

A Vertra Cloud agora tem um servidor MCP oficial (`@vertracloud/mcp`), que dá às ferramentas compatíveis com MCP a capacidade de gerenciar aplicações, bancos de dados, snapshots e cobrança — sempre pela sua chave de API e dentro do que ela permite. Instale localmente com `npx -y @vertracloud/mcp` ou conecte-se ao endpoint MCP oficial listado na página de integração.

Três novos escopos de chave de API chegam junto: `billing:read` (listar pedidos e consultar o status), `billing:write` (criar um pedido de plano e gerar um código Pix) e `redeem:write` (resgatar um código promocional). Fazer downgrade de plano continua sendo uma ação exclusiva do dashboard.

Veja [Conecte a Vertra Cloud a agentes de IA (MCP)](/pt-br/mcp) para a lista completa de ferramentas.
