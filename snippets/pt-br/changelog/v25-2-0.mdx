### Visão geral

Julho marcou um grande marco com o lançamento do sistema de pagamento, do gerenciamento de organizações e das configurações completas de aplicações. A plataforma evoluiu de um serviço básico de hospedagem para um sistema completo de gerenciamento de aplicações, com colaboração em equipe e recursos de cobrança.

---

### Novas funcionalidades

#### Abas de configurações da aplicação
Gerenciamento organizado das aplicações em abas dedicadas.

- **General** — Configurações e informações básicas da aplicação
- **Environment Variables** — Gerenciamento de segredos e configurações
- **Deploys** — Histórico de deploys e configuração de deploy automático
- **Network** — Domínio personalizado e opções de rede
- **Danger Zone** — Operações destrutivas, como a exclusão da aplicação

#### Variáveis de ambiente
Sistema completo de gerenciamento de segredos e configurações.

- Operações CRUD completas para variáveis de ambiente
- Seção dedicada a segredos para dados sensíveis
- Suporte a colagem em massa para configuração rápida
- Injeção de variáveis de ambiente em tempo real
- Criptografia de variáveis em repouso

#### Domínios personalizados
Gerenciamento de DNS e subdomínios das aplicações.

- Configurar um domínio personalizado para qualquer aplicação
- Orientação e validação das configurações de DNS
- Personalização de subdomínio
- Provisionamento de certificados SSL/TLS

#### Deploys automáticos
Deploy automático a partir de webhooks do GitHub.

- Integração com webhooks do GitHub
- Deploy automático a cada push na branch especificada
- Configuração e gerenciamento de webhooks
- Logs e histórico de deploys

#### Organizações
Gerenciamento completo de equipes com controle de acesso baseado em funções.

- Criar e gerenciar organizações
- Gerenciamento de membros com atribuição de funções
- Permissões de commit por função
- Controle de acesso aos backups por função
- Exclusão de organizações

#### Página de preços
Estrutura completa de preços com comparação de planos.

- Tabela comparativa dos níveis
- Lista de funcionalidades por plano
- Preços dos planos de banco de dados
- Opções de preço anual
- Diferenciação clara entre os planos

#### Sistema de pagamento
Integração com o Mercado Pago para cobrança.

- **Integração com PIX** — Método de pagamento instantâneo brasileiro
- Página de faturas com o histórico de transações
- Página de pagamento para compras de planos
- Gerenciamento de renovação de planos
- Suporte a múltiplas opções de pagamento

#### Códigos de resgate
Resgate de códigos promocionais.

- Resgatar códigos promocionais
- Validação e verificação de códigos
- Registro de uso e histórico

#### Gerenciamento de planos
Interface amigável para gerenciar planos.

- Upgrade para um nível superior
- Downgrade para um nível inferior
- Renovação de plano
- Histórico de mudanças de plano

#### Notificações de vencimento do plano
Alertas sobre o vencimento próximo do plano.

- E-mail de aviso antes do vencimento
- Indicadores de aviso no dashboard
- Informação sobre o tempo restante para renovar
- Aviso de renovação nas configurações

#### Chave de API
Solicitar e gerenciar chaves de API a partir do dashboard.

- Gerar chaves de API
- Revogar chaves
- Interface de gerenciamento de chaves
- Uso da chave de API nas aplicações

#### Atividades e logs de auditoria
Rastreamento completo de atividades para responsabilização.

- Rastreamento de atividades das aplicações
- Logs de atividade dos bancos de dados
- Histórico de ações do usuário
- Data e detalhes de cada ação
- Exportação

### Recursos de banco de dados

#### Redesenho das configurações do banco de dados
Interface de gerenciamento de bancos de dados aprimorada.

- Seção de reset para operações de reinicialização do banco de dados
- Gerenciamento e exibição de credenciais
- Aba de visão geral com as informações do banco de dados
- Opções de backup e restauração

### Recursos de deploy

- Seleção de repositório do GitHub no fluxo de novo projeto
- Suporte a repositórios privados
- Seleção de branch
- Configuração automática de webhook

### Controle de acesso

#### Permissões por plano
Disponibilidade de funcionalidades de acordo com o plano selecionado.

- Auto-restart limitado aos planos pagos
- Gerenciador de arquivos restrito a determinados níveis
- Disponibilidade de domínio personalizado por plano
- Visibilidade das métricas por plano
- Funcionalidade de backup por plano
- Disponibilidade de deploy automático
- Bloqueio de funcionalidades baseado no plano
