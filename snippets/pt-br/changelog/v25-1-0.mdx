### Visão geral

Junho trouxe recursos fundamentais que transformaram a Vertra Cloud de um serviço básico de deploy em uma plataforma completa de gerenciamento de aplicações. A reconstrução completa do dashboard, a implementação do gerenciador de arquivos e o sistema de logs em tempo real formaram a base de todo o desenvolvimento futuro.

---

### Novas funcionalidades

#### Reconstrução do dashboard
Redesenho completo da interface principal de aplicações.

- Nova navegação em layout com barra lateral
- Organização mais limpa e intuitiva
- Design responsivo para todos os tamanhos de tela
- Indicadores de status em tempo real
- Gerenciamento de aplicações simplificado

#### Gerenciador de arquivos
Sistema completo de gerenciamento de arquivos para aplicações.

- Navegar e editar os arquivos da aplicação diretamente
- Exclusão em massa
- Suporte à edição de arquivos de configuração
- Upload e download de arquivos
- Navegação em árvore de diretórios
- Criação e edição de arquivos

#### Organizações
Estrutura de colaboração e gestão de equipes.

- Criar e gerenciar organizações
- Adicionar membros às organizações
- Controle de acesso baseado em funções
- Configurações no nível da organização
- Convites para membros
- Gerenciamento de permissões

#### Logs em tempo real
Transmissão de logs das aplicações ao vivo.

- Atualização de logs em tempo real enquanto as aplicações rodam
- Filtragem e busca nos logs
- Recuperação de logs históricos

#### Suporte ao idioma espanhol
Internacionalização para usuários de língua espanhola.

- Traduções completas para espanhol (ES)
- Seleção de idioma nas configurações do usuário
- Todo o texto da interface traduzido
- Modelos de e-mail em espanhol

#### Sistema de commits
Versionamento de aplicações e rastreamento de deploys.

- Criar commits de aplicações
- Reverter para commits anteriores
- Visualização do histórico de commits
- Rastreamento de deploys
- Gerenciamento de versões

#### Backups
Funcionalidade de backup e restauração de aplicações.

- Criar backups manuais
- Ver o histórico de backups
- Restaurar a partir de um backup
- Agendamento de backups
- Integração com a API

#### Nova landing page
Página inicial completamente redesenhada.

- Design e layout modernos
- Proposta de valor clara
- Destaques de funcionalidades
- Botões de chamada para ação
- Navegação melhorada

#### Página de preços
Estrutura inicial de preços e planos.

- Comparação de planos
- Lista de funcionalidades por nível
- Transparência de preços
- Diferenciação entre os níveis

#### Páginas adicionais
Novas páginas informativas da plataforma.

- Página de Termos de Serviço
- Página Sobre
- Página de suporte e contato
- Documentação de ajuda
