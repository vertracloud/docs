### Escolha para onde vão os arquivos enviados

A caixa **Enviar alterações** do gerenciador de arquivos tem um campo **Destino do commit**. Ele começa com a pasta que você tem aberta, e **Selecionar** permite escolher qualquer outra pasta da aplicação. Os arquivos são gravados nessa pasta. Um ZIP é extraído dentro dela e mesclado com os arquivos que já existem lá, então os arquivos que você não enviar são mantidos.

- API: `POST /v1/apps/{id}/files/upload` aceita um parâmetro de query `path` opcional com a pasta de destino, relativa à raiz da aplicação. Deixe vazio ou omita para enviar à raiz. Três novos códigos de erro podem ser retornados: `INVALID_PATH`, `FORBIDDEN_PATH` e `PATH_IS_FILE`.
- SDKs: JavaScript `apps.files.upload(id, file, filename, { path })`, Python `upload(..., path="src")` e Go `ApplicationFileUploadParams{Path: "src"}`.
- CLI: `vertra app commit --path src` envia para essa pasta.

### Arquivos enviados aparecem na hora ao reiniciar

Com **Reiniciar aplicação** marcado, os arquivos enviados só apareciam na lista depois que o reinício terminava. Agora aparecem assim que o upload é concluído.
