### Pastas e favoritos salvos por conta

Pastas e favoritos agora são salvos na conta, em vez de depender do armazenamento local do navegador ou do editor.

- A organização pessoal é separada da organização de cada workspace.
- Pastas podem ser criadas, renomeadas, ter a cor alterada e ser reordenadas.
- Aplicações e bancos de dados podem ser colocados em pastas e marcados como favoritos de forma independente.
- O dashboard, os workflows, a CLI, o MCP e a extensão do VS Code usam a mesma organização persistida.
- A lista de projetos e o Flow mostram o mesmo estado de pastas e favoritos; os grupos do canvas do próprio Flow continuam locais e independentes.
- As ações são registradas no histórico de atividades, inclusive quando feitas por meio de uma chave de API.

Os grupos do Flow são outra coisa: eles organizam elementos no canvas local. Não há sincronização nem migração entre grupos do Flow e pastas de recursos.

### Flags de reinício: reinstalar dependências e forçar build

[Reiniciar aplicação](/pt-br/api-reference/endpoint/apps/restart) agora aceita dois campos opcionais no corpo:

- `reinstall_dependencies` reinstala as dependências da aplicação do zero, ignorando o cache de instalação. É o mesmo que **Reinstalar Dependências** no gerenciador de arquivos do dashboard.
- `force_build` executa de novo o comando de build da aplicação, mesmo que nenhum arquivo de código tenha mudado desde o último build. É o mesmo que **Forçar build** no dashboard.

Isso substitui a rota separada de instalação de dependências. Enviar qualquer uma das flags conta como um slot no limite horário de deploys do plano.

### Extensão do VS Code 1.0

A extensão da Vertra Cloud para o VS Code chega à versão 1.0, disponível no VS Code Marketplace e no Open VSX, além de um arquivo `.vsix` para instalação manual.

O arquivo `vertracloud.config` na pasta vinculada agora tem suporte dedicado: autocompletar de campos, descrições ao passar o mouse e avisos inline quando um valor está ausente ou malformado. Os logs em tempo real agora vão para um canal de saída do editor, em vez de um terminal integrado.

As demais ações de gerenciamento de aplicações continuam disponíveis no dashboard.

Veja [Gerencie a Vertra Cloud pelo VS Code](/pt-br/vscode-extension) para a lista completa de recursos.
