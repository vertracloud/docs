### Visão geral

Maio marca o início da Vertra Cloud com o lançamento do dashboard inicial. Esta versão fundamental traz o gerenciamento básico de aplicações, a conexão com bancos de dados e a base para todos os recursos seguintes.

---

### Novidades

#### Dashboard
Página inicial do dashboard para gerenciamento de aplicações e bancos de dados.

- Ver todas as aplicações implantadas
- Ver todos os bancos de dados conectados
- Visão geral rápida do status
- Listagem e filtragem de projetos
- Gerenciamento básico de recursos

#### Detalhes do banco de dados
Interface de gerenciamento dos bancos de dados conectados.

- Ver as informações do banco de dados
- Exibição das credenciais de conexão
- Estatísticas de uso do banco de dados
- Gerenciamento de configuração
- Integração com a API

#### Detalhes da aplicação
Gerenciamento de aplicações e visualização de arquivos.

- Visão geral da aplicação
- Integração com o gerenciador de arquivos
- Navegação por abas a partir de parâmetros da URL
- Logs da aplicação
- Status do deploy

#### Páginas de aplicações e bancos de dados
Páginas de listagem dedicadas para organização.

- Página de aplicações com todas as aplicações
- Página de bancos de dados com todos os bancos de dados
- Filtragem e ordenação
- Ações rápidas por recurso

#### Campo de domínio personalizado
Suporte inicial a domínio personalizado no modelo de aplicação.

- Configuração de domínio personalizado nas aplicações
- Validação de domínio
- Orientação para configuração de DNS
- Base para os recursos de domínio personalizado

---

### Configuração de desenvolvimento

#### Ferramentas de qualidade de código
Padrões profissionais de desenvolvimento.

- Configuração do ESLint para análise de código
- Configuração do Prettier para formatação de código
- Verificações automatizadas de qualidade de código
- Aplicação consistente do estilo de código

#### Design system
Configuração personalizada do Tailwind.

- Tailwind CSS para estilização
- Sistema de cores personalizado com as cores da marca
- Design tokens e utilitários
- Framework de design responsivo
