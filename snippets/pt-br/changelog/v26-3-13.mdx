### Páginas de CLI e VS Code para desenvolvedores

As ferramentas para desenvolvedores da Vertra Cloud agora têm páginas próprias:

- A página da **CLI** cobre instalação, diagnósticos antes do deploy e comandos de logs, aplicações, bancos de dados e automação, com saída em JSON.
- A página da **extensão oficial do VS Code 1.0** cobre instalação, conexão por conta ou chave de API e os recursos de deploy, logs, métricas, arquivos remotos, bancos de dados e snapshots dentro do editor.

Abra [CLI](/pt-br/cli) ou [Extensão do VS Code](/pt-br/vscode-extension) para começar.

### Nova aparência para notificações

As notificações ficaram mais compactas, com ícones baseados no contexto e transições suaves nos temas claro e escuro.

- Novos estilos neutro, suave, com contorno e sólido para mensagens de sucesso, erro, informação e atualização.
- Suporte a ações, botão de fechar e barra de progresso para operações que informam o próprio progresso.
- As animações respeitam a preferência de movimento reduzido do dispositivo.
