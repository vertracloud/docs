### Visão geral

Dezembro trouxe suporte a novos runtimes de linguagem e aprimorou o sistema promocional com o cupom de fim de ano VERTRA30. As melhorias na entrega de e-mails garantem uma comunicação melhor com os usuários em toda a plataforma.

---

### Novas funcionalidades

#### Suporte à linguagem Go
Adicionado o runtime Go para aplicações de alta performance.

- Suporte à linguagem Go para deploy
- Compilação automática em Go
- Gerenciamento de dependências de módulos Go
- Tempos de build rápidos
- Ideal para microsserviços e ferramentas de linha de comando

#### Suporte à linguagem PHP
Adicionado o runtime PHP 8.x para aplicações web.

- Suporte ao runtime PHP 8.x
- Compatibilidade com os principais frameworks web em PHP
- Suporte a configuração de Apache/Nginx
- Gerenciamento de pacotes PHP via Composer
- Hospedagem de aplicações web

#### Sistema de cupons
Suporte a códigos promocionais com desconto nos pedidos.
