### Visão geral

Janeiro de 2026 marcou o lançamento oficial da beta pública da Vertra Cloud, com uma API REST completa e documentação abrangente. A plataforma se abriu para a comunidade com recursos de colaboração em equipe.

---

### Funcionalidades

#### API v1
A primeira versão pública da API REST da Vertra Cloud.

- API REST abrangente para todas as operações da plataforma
- Documentação completa da referência da API
- Exemplos de requisição e resposta
- Autenticação por chave de API
- Limites de requisições e gerenciamento de cotas

#### Workspaces
Colaboração em equipe com controle de acesso baseado em funções.

- Criar e gerenciar workspaces para equipes
- 5 funções predefinidas: Dono, Administrador, Desenvolvedor, Operador e Visualizador
- Gerenciamento de permissões por função
- Convite e gerenciamento de membros
- Isolamento e segurança entre workspaces

#### Beta pública
Lançamento oficial do período de beta aberta.

- Plataforma aberta para o cadastro público de usuários
- Testes beta e coleta de feedback
- Suporte à comunidade de usuários
- Melhorias de estabilidade e desempenho com base no feedback

#### Documentação
Documentação completa da API e da plataforma.

- Site da documentação em docs.vertracloud.app
- Referência da API com todos os endpoints
- Exemplos de código e tutoriais
- Guias de primeiros passos
- Perguntas frequentes e solução de problemas
