### Visão geral

Novembro trouxe melhorias críticas de infraestrutura e um grande redesenho do modelo de preços. O novo sistema de auto-restart evita loops de falha, o novo plano Intermediary amplia o acesso, e a hospedagem de sites estáticos possibilita deploys apenas de frontend.

---

### Novas funcionalidades

#### Auto-restart
Reinício inteligente do container com detecção de falhas, para evitar loops de falha.

- Monitora o status do container continuamente
- Reinicia somente em falhas reais de execução (crashes), e não em erros de configuração ou de sintaxe
- Evita loops infinitos de reinício que desperdiçariam recursos
- Estabilização automática para problemas transitórios

#### Arquivo .vertraignore
Controle de quais arquivos e pastas são excluídos do deploy automático.

- Funciona de forma semelhante ao `.gitignore`, para o deploy
- Evita o envio de arquivos desnecessários
- Otimiza a velocidade do deploy e reduz o tamanho do pacote

#### Commits aprimorados
Fluxo de commits aprimorado, para mais estabilidade e confiabilidade.

- Processo de deploy simplificado
- Melhor rastreamento de commits e opções de rollback
- Maior confiabilidade dos deploys

#### Hospedagem de sites estáticos
Nova opção de linguagem para hospedar aplicações puramente de frontend.

- Deploy direto de sites em HTML, CSS e JavaScript
- Opção de linguagem `static` na criação de projetos
- Ideal para sites estáticos, SPAs e documentação
- Servir os arquivos automaticamente com os tipos MIME corretos

#### Nova estrutura de planos
Níveis de preço redesenhados, com alocações de recursos claras.

- **Plano Intermediary** — R\$ 18,99/mês com suporte a domínio personalizado
- **Plano PRO** — Domínio personalizado incluído, hospedagem de até 2 APIs por R\$ 5,99/mês
- vCPU alocadas atualizadas por nível de plano
- Proposta de valor mais clara em cada nível

#### Pagamentos com cartão de crédito
Interface inicial para o método de pagamento com cartão de crédito.

- Base para o processamento de cartões de crédito
- Preparação para opções de pagamento mais completas
- Checkout mais agradável

#### Baixar .env
Exporta as variáveis de ambiente do projeto como um arquivo.

- Baixa todas as variáveis de ambiente de uma vez
- Prático para configurar o desenvolvimento local
- Acesso offline seguro à configuração
