### Histórico de atividades mais completo

O histórico de atividades da conta e de cada projeto ganhou mais eventos: alterações de arquivos pelo gerenciador de arquivos (salvar, excluir, mover, enviar), deploys, restaurações de snapshot e alterações de domínio.

Cada atividade agora mostra quem a disparou, com um filtro próprio para navegar pela origem.

### Chaves de API com escopos e IPs permitidos

Até agora, uma conta tinha uma única chave de API com acesso total. Agora você pode criar até **10 chaves**, cada uma com um nome, um conjunto de permissões (aplicações, bancos de dados, snapshots, conta, workspaces, notificações — com os atalhos "somente leitura", "leitura e escrita" e "acesso total") e, opcionalmente, uma lista de IPs permitidos. A verificação usa o IP de origem real, não um cabeçalho que o próprio cliente envia. Uma chave usada só por um servidor de CI, por exemplo, pode ser restrita a criar deploys e não ver mais nada — e travada no IP desse servidor.

O segredo de uma chave nova (`vc_live_...`) aparece só uma vez, na criação ou na rotação; depois disso só o início e o fim continuam visíveis. Chaves geradas antes desta mudança continuam funcionando normalmente, com acesso total.

A geração antiga (o botão único de "gerar chave") continua disponível para scripts e para a CLI.
