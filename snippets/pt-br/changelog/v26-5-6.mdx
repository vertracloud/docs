### Login e segurança da conta

#### Login por e-mail com código de 8 caracteres

O código do e-mail de login agora tem 8 caracteres, mostrados em dois blocos (`K7M2-QXAB`).

- **Cole de qualquer lugar.** Clique em qualquer ponto da etapa do código e cole, ou use o botão **Colar código**. O traço e as letras minúsculas são aceitos.
- **Abra a caixa de entrada com um clique.** A etapa do código tem um atalho para o seu provedor de e-mail.
- **O link do e-mail só preenche o código.** Você ainda clica em **Entrar** para concluir.
- **E-mail mais seguro.** O e-mail avisa para nunca compartilhar o código e que a Vertra nunca o pede por e-mail, telefone ou chat.

#### Confirmação por e-mail em ações sensíveis

No painel, estas ações agora pedem um código enviado ao seu e-mail:

- conectar uma conta Google, GitHub ou Discord (o GitHub só na primeira conexão);
- criar uma chave de API;
- fazer downgrade do plano;
- remover um cartão salvo;
- desligar a renovação automática;
- excluir um workspace;
- resetar a senha de um banco de dados.

Isso vale só para o painel. Requisições feitas com chave de API não são afetadas.

#### E-mails e sessões

- **Novos e-mails** avisam quando uma conexão com Google, GitHub ou Discord é adicionada ou removida.
- **O aviso de novo acesso** agora também dispara quando você entra de um país que ainda não tinha usado.
- **Sair agora encerra a sessão também na Vertra,** não só no navegador.

### Pagamentos com cartão são pausados após recusas repetidas

Depois de várias tentativas recusadas, adicionar ou pagar com cartão fica pausado por um tempo, e a mensagem informa quanto esperar.

### Chaves de API: mudanças para revisar

- **Baixar o código do app exige `apps:files`.** Baixar a aplicação (`GET /v1/apps/{id}/download`, removida na v26.5.8) agora exige a permissão `apps:files` no lugar de `apps:read`. Chaves criadas só com `apps:read` não baixam mais o código: crie uma chave com `apps:files`.
- **Mudar como o app inicia exige `apps:files`.** [Atualizar configuração da aplicação](/api-reference/endpoint/apps/updateconfig) (`PATCH /v1/apps/{id}/config`) agora também exige `apps:files` quando a requisição muda `start_command`, `build_command` ou `main_file`. Os outros campos da configuração não mudam.
- **Removida:** `POST /v1/users/me/generate-api-key`. Use `POST /v1/users/me/api-keys` para criar chaves.
