### Runtimes atualizados para as versões mais recentes

Go, Python, Ruby, .NET e Elixir lançaram novas versões de correção, que incluem correções de segurança feitas pelos próprios projetos. As aplicações nessas linguagens passam a rodar nelas:

| Linguagem | Antes | Agora |
| --- | --- | --- |
| Go | 1.26.10 · 1.27.3 | 1.26.11 · 1.27.4 |
| Python | 3.11.17 · 3.12.15 · 3.13.17 | 3.11.18 · 3.12.16 · 3.13.18 |
| Ruby | 3.3.12 · 3.4.11 | 3.3.13 · 3.4.12 |
| .NET | SDK 10.0.402 | SDK 10.0.404 |
| Elixir | 1.20.4 | 1.20.5 |

- **Quando vale:** a aplicação passa para a versão nova no próximo restart ou deploy. Uma aplicação que segue rodando fica na versão com que subiu até lá.
- **Versão fixada mantém a linha:** uma aplicação fixada com `VERSION` passa para o patch novo da mesma linha (por exemplo, `3.12.15` vira `3.12.16`). Não é preciso mudar o `vertracloud.config`.
- **Primeiro restart:** o primeiro restart na versão nova pode levar um pouco mais que o normal.

### Bun 1.4 passa a ser a versão recomendada

O Bun 1.4.4 agora é a versão recomendada e também a mais recente. Aplicações Bun novas, e as existentes sem `VERSION` no `vertracloud.config`, rodam na 1.4.4 a partir do próximo restart ou deploy. O Bun 1.3.14 segue disponível: declare `VERSION=1.3` para continuar nele.

### Deno 2.8 removido

O Deno 2.8.3 não está mais disponível, porque a linha 2.8 deixou de receber correções. Aplicações no Deno 2.8 rodam na 2.9.8 a partir do próximo restart ou deploy, e `VERSION=2.8` agora resolve para a versão recomendada.
