### Visão geral

Fevereiro de 2026 trouxe recursos essenciais de gerenciamento de bancos de dados e ferramentas de desenvolvimento integradas. A extensão oficial para VSCode, o suporte a bancos de dados gerenciados e os recursos de segurança aprimorados tornam a Vertra Cloud uma plataforma completa para desenvolvimento full-stack.

---

### Novas funcionalidades

#### Extensão para VSCode
Extensão oficial da Vertra Cloud para o VS Code.

- Deploy direto pelo editor
- Gerenciamento de aplicações a partir do VS Code
- Visualização de logs em tempo real na barra lateral
- Exibição rápida de status e métricas
- Criação de projetos integrada
- Disponível no VS Code Marketplace

#### Bancos de dados gerenciados
Hospedagem de bancos de dados pronta para produção, com gerenciamento automático.

- **PostgreSQL 17**
- **MongoDB 8.0**

#### Certificados TLS automáticos
Conexões com bancos de dados criptografadas desde o início.

- Geração automática de certificados TLS
- Gerenciamento da renovação de certificados
- Suporte a certificados de cliente
- Exigência de conexões seguras

#### Suporte ao MySQL
Hospedagem de bancos de dados MySQL 8.0.

- MySQL 8.0 com os recursos mais recentes
- Autenticação X509 obrigatória por segurança

### Melhorias

#### Entrega de e-mails
Desempenho do sistema de e-mails otimizado.

- Velocidade de entrega aprimorada dos magic links por e-mail
- Melhor roteamento de e-mails
- Latência de entrega reduzida
- Mais confiabilidade

#### Correções de domínio personalizado
Problemas de configuração de DNS resolvidos.

- Corrigidos erros 404 em algumas configurações de domínio personalizado
- Tratamento aprimorado da propagação de DNS
- Melhor provisionamento de certificados para domínios personalizados

#### Gerenciamento de bancos de dados
Tratamento aprimorado de certificados e credenciais.

- Corrigidos casos extremos na geração de certificados
- Melhor exibição e gerenciamento de credenciais
- Teste de conexão com o banco de dados aprimorado
