### Páginas para cada linguagem e banco de dados

#### Uma página por linguagem

O site agora tem **`/runtimes`**, a lista das dez linguagens que a plataforma executa, e uma página dedicada para cada uma: JavaScript, TypeScript, Python, Go, Rust, Java, Bun, PHP, Ruby e sites estáticos.

Cada página responde ao que as pessoas perguntam antes de se cadastrar:

- **Quais versões existem**, qual é a recomendada e qual é a mais recente, com o valor exato de `VERSION` para o `vertracloud.config`.
- **O que a plataforma faz automaticamente** para aquele runtime: instalação de dependências durante o build, reinício automático, logs e métricas em tempo real.
- **O que as pessoas rodam** com ele: bots, APIs, workers, sites.
- **A configuração mínima**, em um bloco para copiar.
- **As perguntas mais comuns**, com respostas curtas, as mesmas que chegam ao suporte.

A tabela comparativa no topo mostra as dez lado a lado, para quem ainda está escolhendo.

#### Uma página por banco de dados

Os quatro bancos de dados gerenciados ganharam páginas próprias em `/databases`: **PostgreSQL**, **MySQL**, **MongoDB** e **Redis**. Cada uma cobre a versão, a porta, o modo de autenticação e o formato do host, um comando de conexão pronto com TLS e o que cada operação do dashboard faz, inclusive o que um reset destrutivo apaga.

A página `/databases` continua sendo a visão geral do serviço; as novas páginas são para quem já sabe qual motor quer.

#### Em três idiomas

Todas as páginas existem em português, inglês e espanhol, com a URL de cada idioma declarada para os mecanismos de busca. O FAQ de cada página também é publicado como dados estruturados, para poder aparecer diretamente nos resultados de busca.

#### Onde encontrá-las

As dez linguagens e os quatro bancos de dados aparecem no rodapé de todas as páginas, em colunas próprias, e as linguagens também aparecem no menu **Recursos** do topo, sem passar pelo hub.

#### Limpeza

Páginas-protótipo que nunca foram anunciadas saíram do ar junto com alguns arquivos de imagem não usados. Nenhuma URL publicada antes foi removida.
