Visual workflow automation. The template runs n8n 2.44.7 with the Code node in **JavaScript and Python** in the same container, an optional worker in queue mode and community nodes.

<Card title="Step-by-step guide: n8n from zero to your first workflow" icon="book-open" href="/templates/guides/n8n">
  Choose the mode, create the owner, webhooks, Python and JavaScript, SMTP, credentials, backups and rollback.
</Card>

## What it creates

| Mode | Creates | Memory |
|---|---|---|
| **Managed Postgres** (default) | The n8n app and a managed Postgres. | 2 GB |
| **Built-in SQLite** | The n8n app only. | 1 GB |
| **Scale with workers** | The n8n app, one worker, Postgres and Redis. | 3.5 GB |

It is an image template: it needs a plan with Docker images and one free [image slot](/templates/overview#image-slots). See [Plans and limits](/plans-and-limits).

## What the wizard asks

| Question | What it does |
|---|---|
| How will n8n run? | The mode above. |
| Parallel executions on the worker | Only with workers. Default 5. |
| Schedule time zone | America/Sao_Paulo, UTC, America/New_York or Europe/Lisbon. |
| Modules allowed in the Code node | **Safe** (default) or **All**. |
| Send n8n emails? | Optional SMTP for invitations and password reset. |

## What you get

The app address, and the next step: open it and create the **owner** account right away. Secrets (the encryption key and the runners token) are generated for you.

## Variables

| Variable | What it does |
|---|---|
| `N8N_ENCRYPTION_KEY` | Encrypts credentials; keep a copy. Never change it on a running app. |
| `N8N_WEBHOOK_URL`, `N8N_EDITOR_BASE_URL`, `N8N_HOST` | The app's public address. |
| `VERTRA_CODE_MODULES` | `safe` or `all`: the modules the Code node may import. |
| `GENERIC_TIMEZONE`, `TZ` | Schedule time zone. |
| `EXECUTIONS_DATA_MAX_AGE`, `EXECUTIONS_DATA_PRUNE_MAX_COUNT` | History retention: 168 hours and 5,000 executions. |
| `N8N_WORKER_CONCURRENCY` | Parallel executions on the worker (workers mode). |
| `N8N_SMTP_*`, `N8N_EMAIL_MODE` | Email for invitations and password reset. |

## Resources and limits

- Port 5678; first boot 25 to 60 seconds. Editor memory use about 300 to 540 MiB, worker 330 to 560 MiB.
- Data in `/app/.n8n`; community nodes in `/app/.n8n/nodes`.
- One worker at most; zero-downtime deploy is off; rollback returns the data too.
- Execution history is deleted after 7 days or 5,000 executions.
