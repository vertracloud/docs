Vertra Cloud publishes eight official templates: n8n, OpenClaw, Hermes Agent, Evolution API, Open WebUI, Uptime Kuma and a Discord bot starter in JavaScript and in Python. Open **Templates** in the dashboard to see them in the gallery with your free memory and image slots, run `vertra template list`, or browse the [public gallery](https://vertracloud.app/templates), which needs no account. Each one asks only for what it needs and generates its own secrets.

All of them have the **Vertra** badge. The six that run an image need a plan with Docker images and one free image slot each; the two Discord bots run on a language runtime and use no slot. See [What are templates](/templates/overview) for how the required plan is computed and [Plans and limits](/plans-and-limits) for the numbers.

## AI agents and assistants

| Template | What it is | What it creates |
|---|---|---|
| [**OpenClaw**](/templates/catalog/openclaw) | Personal AI assistant with a browser, control panel and channels (Telegram, Discord, Slack, WhatsApp). You bring your own model key. | One app (image). |
| [**Hermes Agent**](/templates/catalog/hermes-agent) | AI agent that learns from use, with a panel, a chat in the browser and channels (Telegram, Discord, Slack, WhatsApp). | One app (image). |
| [**Open WebUI**](/templates/catalog/open-webui) | A chat interface with AI for your team. You bring your own model key. | One app (image), plus a Postgres database if you choose managed storage. |

## Automation and APIs

| Template | What it is | What it creates |
|---|---|---|
| [**n8n**](/templates/catalog/n8n) | Visual workflow automation with Python and JavaScript Code nodes, workers and community nodes. | One app, or a stack with Postgres, and Postgres, Redis and a worker if you scale with workers (image). |
| [**Evolution API**](/templates/catalog/evolution-api) | WhatsApp API with instances, webhooks and integrations. | A stack with the app and a Postgres database, and Redis if you choose it as cache (image). |

## Monitoring

| Template | What it is | What it creates |
|---|---|---|
| [**Uptime Kuma**](/templates/catalog/uptime-kuma) | Monitor sites and services with alerts and a status page. Your data stays on your app. | One app (image). |

## Bots

| Template | What it is | What it creates |
|---|---|---|
| [**Discord bot (JavaScript)**](/templates/catalog/discord-bot-js) | A Discord bot with discord.js and a `/ping` command, a starting point for your bot. | One app (code), with no web. |
| [**Discord bot (Python)**](/templates/catalog/discord-bot-python) | A Discord bot with discord.py and a `/ping` command, a starting point for your bot. | One app (code), with no web. |

The code of the Discord bot templates is yours to edit; editing it detaches the app from the template, so it stops receiving new versions. The templates that run an image have no editable code: you change their memory and the answers to their questions.

## Step-by-step guides

n8n, OpenClaw and Hermes Agent have a dedicated guide each, from the first screen to a working setup: [n8n](/templates/guides/n8n), [OpenClaw](/templates/guides/openclaw) and [Hermes Agent](/templates/guides/hermes-agent). Every template also has its own page in this section, with what it creates, the questions it asks and its variables.

## Where to see them

The gallery is in the dashboard under **Templates**, where it shows which ones fit your plan; the [public gallery](https://vertracloud.app/templates) lists them for everyone. To use one, follow [Use a template](/templates/use/using-a-template). To publish your own, see [Create templates](/templates/create/overview).
