## What is Vertra Cloud?

Vertra Cloud is a Brazilian application hosting platform (PaaS): deploy from GitHub or a zip file,
isolated containers, managed databases, file storage, snapshots, a CLI and a VS Code extension.
Discord, WhatsApp and Telegram bots are first-class workloads. The platform builds the image, runs
the container, routes the subdomain, issues the certificates and keeps the snapshots.

## What does the platform include?

Ten runtimes, four managed database engines, real-time metrics and logs, custom domains with
automatic SSL, lifecycle validation during deploys and restarts, an MCP server for your AI agent,
team workspaces and a VS Code extension.

## Which databases are available?

Four managed engines — PostgreSQL 17, MongoDB 8.0, Redis 7 and MySQL 8.0 — each with mandatory TLS
and certificates the platform generates and rotates for you.

<CardGroup cols={2}>
  <Card title="PostgreSQL" icon="elephant">
    **Version:** 17 &nbsp;|&nbsp; **Port:** 5432

    Relational database with SQL, JSONB and extensions support. Mandatory TLS with automatic certificates.
  </Card>
  <Card title="MongoDB" icon="leaf">
    **Version:** 8.0.11 &nbsp;|&nbsp; **Port:** 27017

    NoSQL document-oriented database. Mandatory TLS with platform-signed CA.
  </Card>
  <Card title="Redis" icon="bolt">
    **Version:** 7 (Bookworm) &nbsp;|&nbsp; **Port:** 6379

    High-performance in-memory store for caching and pub/sub. Mandatory TLS.
  </Card>
  <Card title="MySQL" icon="database">
    **Version:** 8.0 &nbsp;|&nbsp; **Port:** 3306

    Relational database with mandatory X509 authentication and auto-generated TLS certificates.
  </Card>
</CardGroup>

## What do the plans include?

Plans run from Free (R\$0, currently "suspended") to Enterprise-32 (R\$191.99/month, 32 GB of RAM) —
each tier adds more RAM, vCPU and API requests, plus
features like web publishing, backups, custom domains and workspaces further up. The full table —
price, RAM, vCPU, projects and API limit for every plan — lives on
[Plans and limits](/plans-and-limits), which is kept in sync with the platform's billing code; this
page does not repeat it.
