## ¿Qué es Vertra Cloud?

Vertra Cloud es una plataforma brasileña de alojamiento de aplicaciones (PaaS): despliegue desde GitHub o desde un archivo zip,
contenedores aislados, bases de datos gestionadas, almacenamiento de archivos, snapshots, una CLI y una extensión de VS Code.
Los bots de Discord, WhatsApp y Telegram son cargas de trabajo de primera clase. La plataforma construye la imagen, ejecuta
el contenedor, enruta el subdominio, emite los certificados y guarda los snapshots.

## ¿Qué incluye la plataforma?

Trece runtimes, cuatro motores de bases de datos gestionadas, métricas y logs en tiempo real, varios dominios personalizados con
SSL automático, validación del ciclo de vida durante los despliegues y los reinicios, un servidor MCP para tu agente de IA,
workspaces de equipo y una extensión de VS Code.

## ¿Qué bases de datos están disponibles?

Cuatro motores gestionados (PostgreSQL 18/17, MongoDB 8.0/9.0, Redis 8.2/7.2 y MySQL 9.7/8.4), cada uno con TLS obligatorio
y certificados que la plataforma genera y rota por ti.

<CardGroup cols={2}>
  <Card title="PostgreSQL" icon="elephant">
    **Versiones:** 18 (recomendada), 17

    Base de datos relacional con compatibilidad con SQL, JSONB y extensiones. TLS obligatorio con certificados automáticos.
  </Card>
  <Card title="MongoDB" icon="leaf">
    **Versiones:** 8.0 (recomendada), 9.0

    Base de datos NoSQL orientada a documentos. TLS obligatorio con una CA firmada por la plataforma.
  </Card>
  <Card title="Redis" icon="bolt">
    **Versiones:** 8.2 (recomendada), 7.2

    Almacén en memoria de alto rendimiento para caché y pub/sub. TLS obligatorio.
  </Card>
  <Card title="MySQL" icon="database">
    **Versiones:** 9.7 (recomendada, LTS), 8.4 (LTS)

    Base de datos relacional con autenticación X509 obligatoria y certificados TLS generados automáticamente.
  </Card>
</CardGroup>

## ¿Qué incluyen los planes?

Los planes van de Economy (R\$ 1,99/mes) a Enterprise-32 (R\$ 191,99/mes, 32 GB de RAM);
cada nivel añade más RAM, vCPU y peticiones a la API, además de
funciones como la publicación web, las copias de seguridad, los dominios personalizados y los workspaces en los niveles superiores. La tabla completa
(precio, RAM, vCPU, proyectos y límite de API de cada plan) está en
[Planes y límites](/es-es/plans-and-limits), que se mantiene sincronizada con el código de facturación de la plataforma; esta
página no la repite.
