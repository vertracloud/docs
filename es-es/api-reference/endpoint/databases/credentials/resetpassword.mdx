---
title: Restablecer la contraseña de una base de datos
sidebarTitle: Restablecer contraseña
api: POST https://api.vertracloud.app/v1/databases/{id}/credentials/reset
authMethod: bearer
description: Restablece la contraseña de una base de datos concreta a partir de su ID.
---

{/* @see { password: string } — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  El ID de la base de datos cuya contraseña se va a restablecer.
</ParamField>

### Respuesta

<ResponseField name="response" type="object">
  La respuesta con la nueva contraseña.

  <Expandable title="Mostrar objeto">

  <ResponseField name="password" type="string">
    La nueva contraseña de la base de datos.
  </ResponseField>

  <ResponseField name="restart_required" type="boolean">
    `true` cuando al menos una aplicación de un stack conectado debe reiniciarse para leer la nueva contraseña.
  </ResponseField>

  <ResponseField name="apps_to_restart" type="string[]">
    Los IDs de esas aplicaciones. Vacío cuando `restart_required` es `false`.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "password": "a1b2c3d4e5f6g7h8",
    "restart_required": false,
    "apps_to_restart": []
  }
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP que no está en su lista de permitidas, o no tiene el ámbito que requiere la ruta (`403`).
  - `ACCESS_DENIED`: El recurso pertenece a otra cuenta, o no tienes el permiso de workspace necesario para él (`403`).
  - `DATABASE_NOT_FOUND_OR_FORBIDDEN`: La base de datos indicada no existe o el usuario no tiene acceso.
  - `INVALID_PLAN_CONFIG`: La configuración del plan de la base de datos no es válida.
  - `FAILED_TO_REBUILD_DATABASE`: No se pudo reconstruir la base de datos con la nueva contraseña.
</ResponseField>

<ResponseField name="message" type="string">
  Un mensaje descriptivo con más detalles sobre el error.
</ResponseField>

<ResponseExample>

```json Error Response (403)
{
  "code": "ACCESS_DENIED"
}
```

```json Error Response (404)
{
  "code": "DATABASE_NOT_FOUND_OR_FORBIDDEN"
}
```

```json Error Response (500)
{
  "code": "FAILED_TO_REBUILD_DATABASE"
}
```

</ResponseExample>
