---
title: Actualizar una base de datos
sidebarTitle: Actualizar base de datos
api: PUT https://api.vertracloud.app/v1/databases/{id}
authMethod: bearer
description: Actualiza el nombre, la descripción o la RAM de una base de datos por su ID.
---

{/* @see APIDatabase — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  El ID de la base de datos que se va a actualizar.
</ParamField>


<ParamField query="workspace_id" type="string">
  Si la base de datos pertenece a un workspace, el ID del workspace.
</ParamField>

<ParamField body="name" type="string">
  El nuevo nombre de la base de datos. De 1 a 50 caracteres.
</ParamField>

<ParamField body="description" type="string | null">
  La nueva descripción, de hasta 128 caracteres. Una cadena vacía o `null` la borra.
</ParamField>

<ParamField body="ram" type="number">
  La nueva RAM en MB, un entero positivo. Debe caber en la memoria libre del plan y respetar el mínimo del motor (512 MB para Redis, 1024 MB para los demás).
</ParamField>

### Respuesta

<ResponseField name="response" type="object">
  Los detalles actualizados de la base de datos.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">

  </ResponseField>

  <ResponseField name="cluster" type="number">
    El ID del clúster de la base de datos.
  </ResponseField>

  <ResponseField name="type" type="number">
    El tipo de la base de datos.
  </ResponseField>

  <ResponseField name="name" type="string">
    El nombre de la base de datos.
  </ResponseField>

  <ResponseField name="description" type="string">
    La descripción de la base de datos.
  </ResponseField>

  <ResponseField name="owner_id" type="string">

  </ResponseField>

  <ResponseField name="owner_plan" type="string | null">

  <ResponseField name="ram" type="number">

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `VALIDATION_ERROR`: Un campo del cuerpo o de la consulta no superó la validación (`400`).
  - `INVALID_RAM_LIMIT`: La RAM solicitada está fuera de lo que permiten el motor y el plan (`400`).
  - `MEMORY_LIMIT_EXCEEDED`: El plan no tiene suficiente memoria libre para la nueva RAM (`400`).
  - `ACCESS_DENIED`: Tu cuenta no puede actuar sobre esta base de datos (`403`).
  - `DATABASE_NOT_FOUND`: La base de datos no existe (`404`).
  - `OPERATION_IN_PROGRESS`: Hay otra operación del ciclo de vida en curso sobre esta base de datos (`409`).
</ResponseField>
