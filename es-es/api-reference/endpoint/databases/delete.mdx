---
title: Eliminar una base de datos
sidebarTitle: Eliminar base de datos
api: DELETE https://api.vertracloud.app/v1/databases/{id}
authMethod: bearer
description: Elimina una base de datos por su ID de inmediato, sin crear un snapshot. Crea uno antes si quieres una copia. Requiere el ámbito databases:delete.
---
Eliminar una base de datos por la API la elimina de inmediato y **no crea un snapshot**. Si quieres una copia, llama antes a
[Crear snapshot](/api-reference/endpoint/apps/snapshots/create). (El diálogo de eliminación del panel ofrece
**Crear snapshot antes de borrar**, desmarcada por defecto.) Una clave de API necesita el ámbito `databases:delete`.

<ParamField path="id" type="string" required>
  El ID de la base de datos que se va a eliminar.
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la base de datos pertenece a un workspace, el ID del workspace.
</ParamField>

### Respuesta

<ResponseField name="response" type="string">
  El ID de la base de datos eliminada.
</ResponseField>

<ResponseExample>

```json Response
{
  "response": "00000000000000000000000000000001"
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  - `DATABASE_NOT_FOUND`: La base de datos no existe (`404`).
  - `ACCESS_DENIED`: Tu cuenta no puede actuar sobre esta base de datos (`403`).
  - `OPERATION_IN_PROGRESS`: Hay otra operación del ciclo de vida en curso en esta base de datos (`409`).
  - `INTERNAL_SERVER_ERROR`: La plataforma no pudo eliminar la base de datos; vuelve a intentarlo más tarde (`500`).
</ResponseField>
