---
title: Eliminar una base de datos
sidebarTitle: Eliminar base de datos
api: DELETE https://api.vertracloud.app/v1/databases/{id}
authMethod: bearer
description: Elimina una base de datos por su ID, al momento y para siempre. Crea un snapshot antes si puedes necesitar sus datos. Requiere el ámbito databases:delete.
---
Elimina la base de datos al momento. Es permanente: no hay vuelta atrás, así que [crea un snapshot](/es-es/api-reference/endpoint/apps/snapshots/create)
antes si puedes necesitar sus datos. Los snapshots que ya tengas siguen disponibles. Una clave de API necesita el ámbito `databases:delete`.

<ParamField path="id" type="string" required>
  El ID de la base de datos que se va a eliminar.
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la base de datos pertenece a un workspace, el ID del workspace.
</ParamField>

### Respuesta

<ResponseField name="response" type="string">
  El ID de la base de datos eliminada.
</ResponseField>

<ResponseExample>

```json Response
{
  "response": "00000000000000000000000000000001"
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  - `DATABASE_NOT_FOUND`: La base de datos no se encontró (`404`).
  - `ACCESS_DENIED`: Eres miembro de un workspace sin el permiso para esta acción, o no enviaste el `workspace_id` (`403`).
  - `OPERATION_IN_PROGRESS`: Hay otra operación del ciclo de vida en curso en esta base de datos (`409`).
  - `INTERNAL_SERVER_ERROR`: La plataforma no pudo eliminar la base de datos; vuelve a intentarlo más tarde (`500`).
</ResponseField>
