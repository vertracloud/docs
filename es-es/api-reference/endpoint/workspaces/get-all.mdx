---
title: Listar workspaces
sidebarTitle: Listar
api: GET https://api.vertracloud.app/v1/workspaces
authMethod: bearer
description: Lista cada workspace del que la cuenta autenticada es propietaria o miembro.
---

{/* @see APIWorkspace, RESTGetAPIWorkspacesResponse — @vertracloud/api-types */}
Disponible para cualquier cuenta con sesión iniciada: no necesitas `members:read` en ningún workspace para listar
aquellos a los que perteneces. Una clave de API necesita el scope `workspaces:read`.

### Respuesta

  <Expandable title="Mostrar objeto">

  <ResponseField name="name" type="string" />

  <ResponseField name="owner_id" type="string" />
  <ResponseField name="owner" type="object">`{ display_name }` del propietario.</ResponseField>
  <ResponseField name="members_count" type="number" />
  <ResponseField name="deleted_at" type="string | null" format="date-time">Marca de eliminación lógica. Siempre `null` aquí: los workspaces eliminados no aparecen en la lista.</ResponseField>
  <ResponseField name="created_at" type="string" format="date-time" />
  <ResponseField name="updated_at" type="string" format="date-time" />

</ResponseField>
