title: Eliminar miembro
sidebarTitle: Eliminar
api: DELETE https://api.vertracloud.app/v1/workspaces/{id}/members/{user_id}
authMethod: bearer
description: Quita a un miembro del workspace. Requiere `members:manage`, o que el miembro se vaya por sí mismo.
---

{/* @see RESTDeleteAPIWorkspaceMemberResponse — @vertracloud/api-types */}
Hay dos formas de pasar: quien llama tiene `members:manage`, **o** `user_id` es el propio ID de quien llama (el caso de
«salir del workspace»). Una clave de API necesita el scope `workspaces:write`.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>
<ParamField path="user_id" type="string" required>ID de usuario del miembro.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quien llama no tiene `members:manage` y no se está quitando a sí mismo. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
