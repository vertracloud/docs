sidebarTitle: Eliminar
api: DELETE https://api.vertracloud.app/v1/workspaces/{id}/roles/{role_id}
authMethod: bearer
description: Elimina un rol. Requiere `roles:manage`; se rechaza mientras esté asignado a un miembro o a una invitación pendiente.
---

{/* @see RESTDeleteAPIWorkspaceRoleResponse — @vertracloud/api-types */}
Requiere `roles:manage`. Una clave de API necesita el scope `workspaces:write`.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>
<ParamField path="role_id" type="string" required>ID del rol.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quien llama no tiene `roles:manage`. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
| 404 | `WORKSPACE_ROLE_NOT_FOUND` | `role_id` no pertenece a este workspace. |
| 409 | `WORKSPACE_ROLE_IN_USE` | Un miembro tiene este rol, o existe una invitación pendiente con él. Reasigna o revoca primero. |
