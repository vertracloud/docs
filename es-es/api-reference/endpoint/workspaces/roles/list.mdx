description: Lista los roles de un workspace. Requiere el permiso `members:read`.
---

{/* @see APIWorkspaceRole, RESTGetAPIWorkspaceRolesResponse — @vertracloud/api-types */}
Requiere `members:read` (no es un `roles:read` aparte: leer la lista de roles viene incluido con leer los miembros).
Una clave de API necesita el scope `workspaces:read`.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quien llama no tiene `members:read`. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
