{/* @see RESTDeleteAPIWorkspaceResponse — @vertracloud/api-types */}
<Note>
  Una clave de API necesita el scope `workspaces:delete`. No tiene el sufijo `read` ni `write`, así que los presets
  `read` y `write` nunca lo incluyen: solo lo incluye `full` o una selección personalizada. La verificación de
  propietario sigue aplicando: una clave actúa como la cuenta que la posee.
</Note>

La eliminación es lógica: se quitan los miembros, los roles, las invitaciones y los vínculos de aplicaciones y bases
de datos, y el nombre queda libre para reutilizarse en un workspace nuevo.

### Ruta

<ParamField path="id" type="string" required>
  ID del workspace.
</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | Se llamó con una clave de API que no tiene el scope `workspaces:delete`. |
| 403 | `WORKSPACE_OWNER_ONLY` | Quien llama no es el propietario. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o ya fue eliminado. |
