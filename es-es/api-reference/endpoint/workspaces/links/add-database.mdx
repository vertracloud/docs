{/* @see RESTPostAPIWorkspaceResourceLinkResponse — @vertracloud/api-types */}
Mismas reglas que [Vincular aplicación](/es-es/api-reference/endpoint/workspaces/links/add-app): solo el propietario,
scope `workspaces:write` para una clave de API, y la base de datos debe pertenecer a quien llama.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>
<ParamField path="db_id" type="string" required>ID de la base de datos. Debe pertenecer a quien llama.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quien llama no es el propietario del workspace. |
| 403 | `PLAN_RESTRICTED_FEATURE` | El plan del propietario está congelado. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
| 404 | `DATABASE_NOT_FOUND` | La base de datos no existe o no pertenece a quien llama. |
