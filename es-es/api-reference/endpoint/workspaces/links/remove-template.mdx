{/* @see RESTDeleteAPIWorkspaceTemplateStackLinkResponse — @vertracloud/api-types */}
Mueve la plantilla de vuelta a tu cuenta. Lo mismo se aplica a un stack en `DELETE https://api.vertracloud.app/v1/workspaces/{id}/stacks/{stack_id}`. Mismas reglas que [Desvincular aplicación](/es-es/api-reference/endpoint/workspaces/links/remove-app): solo el propietario, y una clave de API necesita el scope `workspaces:write`. No se elimina nada.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>
<ParamField path="template_id" type="string" required>ID de la plantilla. Para un stack, usa `/stacks/{stack_id}` con el ID del stack en su lugar.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quien llama no es el propietario del workspace. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
| 404 | `TEMPLATE_NOT_FOUND` | La plantilla no está vinculada a este workspace. |
| 404 | `STACK_NOT_FOUND` | El stack no está vinculado a este workspace. |
