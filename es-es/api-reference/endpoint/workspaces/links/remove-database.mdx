Mismas reglas que [Desvincular aplicación](/es-es/api-reference/endpoint/workspaces/links/remove-app).

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>
<ParamField path="db_id" type="string" required>ID de la base de datos.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quien llama no es el propietario del workspace. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
| 404 | `DATABASE_NOT_FOUND` | La base de datos no está vinculada a este workspace. |
