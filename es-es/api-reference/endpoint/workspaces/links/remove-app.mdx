description: Quita una aplicación del workspace. Solo el propietario. No elimina la app.
---

{/* @see RESTDeleteAPIWorkspaceResourceLinkResponse — @vertracloud/api-types */}
Solo el **propietario** del workspace. Una clave de API necesita el scope `workspaces:write`. La aplicación en sí no se
toca: deja de estar asociada a este workspace y vuelve a ser un proyecto personal del propietario.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>
<ParamField path="app_id" type="string" required>ID de la aplicación.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quien llama no es el propietario del workspace. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
| 404 | `APP_NOT_FOUND` | La aplicación no está vinculada a este workspace. |
