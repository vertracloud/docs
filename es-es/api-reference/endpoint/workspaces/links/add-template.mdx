{/* @see RESTPostAPIWorkspaceTemplateStackLinkResponse — @vertracloud/api-types */}
Mueve una de tus plantillas privadas al workspace. Las mismas reglas se aplican a un stack en `POST https://api.vertracloud.app/v1/workspaces/{id}/stacks/{stack_id}`; un stack solo se mueve cuando todos sus miembros ya están en el workspace. Mismas reglas que [Vincular aplicación](/es-es/api-reference/endpoint/workspaces/links/add-app): solo el propietario, scope `workspaces:write` para una clave de API, y el recurso debe pertenecer a quien llama.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>
<ParamField path="template_id" type="string" required>ID de la plantilla. Para un stack, usa `/stacks/{stack_id}` con el ID del stack en su lugar.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quien llama no es el propietario del workspace. |
| 403 | `PLAN_RESTRICTED_FEATURE` | El plan del propietario está congelado. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
| 404 | `TEMPLATE_NOT_FOUND` | La plantilla no existe o no pertenece a quien llama. |
| 404 | `STACK_NOT_FOUND` | El stack no existe o no pertenece a quien llama. |
| 409 | `STACK_MEMBER_CONFLICT` | Un miembro del stack no está en el workspace. |
