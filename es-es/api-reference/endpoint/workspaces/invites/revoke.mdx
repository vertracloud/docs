api: DELETE https://api.vertracloud.app/v1/workspaces/{id}/invites/{invite_id}

description: Revoca una invitación pendiente. Requiere `members:manage`; una clave de API necesita el scope `workspaces:invites`.
---

{/* @see RESTDeleteAPIWorkspaceInviteResponse — @vertracloud/api-types */}
<Note>
  Una clave de API necesita el scope `workspaces:invites` (solo en el preset `full` o en una selección personalizada).
  Crear invitaciones sigue siendo exclusivo del panel.
</Note>

Requiere `members:manage`.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>
<ParamField path="invite_id" type="string" required>ID de la invitación.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | Se llamó con una clave de API que no tiene el scope `workspaces:invites`. |
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quien llama no tiene `members:manage`. |
| 404 | `WORKSPACE_INVITE_NOT_FOUND` | La invitación no existe, ya fue revocada, aceptada o agotada, o pertenece a otro workspace. |
