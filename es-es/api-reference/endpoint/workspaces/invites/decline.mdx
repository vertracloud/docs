{/* @see RESTPostAPIWorkspaceInviteDeclineResponse — @vertracloud/api-types */}
<Note>
  Una clave de API necesita el scope `workspaces:invites` y actúa como la cuenta que la posee: una invitación por correo
  solo coincide si el correo de esa cuenta es el invitado. Mismo límite de 10/min por sesión + IP que
  [Previsualizar invitación](/es-es/api-reference/endpoint/workspaces/invites/preview).
</Note>

### Ruta

<ParamField path="token" type="string" required>El token de la invitación.</ParamField>

### Respuesta

Respuesta vacía si todo sale bien.

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | Se llamó con una clave de API que no tiene el scope `workspaces:invites`. |
| 404 | `WORKSPACE_INVITE_NOT_FOUND` | El token no existe, o la invitación ya fue revocada, aceptada o agotada. |
| 410 | `WORKSPACE_INVITE_EXPIRED` | La invitación existió, pero ya venció. |
