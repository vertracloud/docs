---
title: Listar invitaciones
sidebarTitle: Listar
api: GET https://api.vertracloud.app/v1/workspaces/{id}/invites
authMethod: bearer
description: Lista las invitaciones pendientes y pasadas. Requiere `members:manage`; una clave de API necesita el scope `workspaces:invites`.
---

{/* @see APIWorkspaceInvite, RESTGetAPIWorkspaceInvitesResponse — @vertracloud/api-types */}
<Note>
  Una clave de API necesita el scope `workspaces:invites` (solo en el preset `full` o en una selección personalizada).
  Crear invitaciones sigue siendo exclusivo del panel.
</Note>

Requiere el permiso `members:manage`.

### Ruta

<ParamField path="id" type="string" required>ID del workspace.</ParamField>

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | Se llamó con una clave de API que no tiene el scope `workspaces:invites`. |
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quien llama no tiene `members:manage`. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
