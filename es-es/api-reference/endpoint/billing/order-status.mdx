---
title: "Obtener el estado de un pedido"
sidebarTitle: "Estado del pedido"
api: GET https://api.vertracloud.app/v1/orders/{orderId}/status
authMethod: bearer
description: "Devuelve el estado actual de un único pedido."
---
<ParamField path="orderId" type="string" required>
  El ID del pedido.
</ParamField>

### Respuesta

<ResponseField name="response" type="object">
  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    El ID del pedido.
  </ResponseField>

  <ResponseField name="status" type="string">
    Estado del pedido. Valores posibles: `unpaid`, `paid`, `cancelled`, `expired`.
  </ResponseField>

  <ResponseField name="price" type="number">
    El precio final cobrado, una vez aplicado el descuento del cupón, si lo hay.
  </ResponseField>

  <ResponseField name="expires_at" type="string | null">
    Cuándo caduca el pedido sin pagar, en ISO 8601 (72 horas después de crearse el pedido). `null` cuando
    el pedido no tiene caducidad.
  </ResponseField>

  <ResponseField name="allowed_payment_methods" type="string[]">
    Métodos de pago que acepta el pedido (`pix`, `card`). El plan Economy devuelve `["pix"]`.
  </ResponseField>

  <ResponseField name="related_to" type="object">
    El plan al que se aplica el pedido.

    <Expandable title="Mostrar objeto">
    <ResponseField name="plan" type="object">
      <Expandable title="Mostrar objeto">
      <ResponseField name="name" type="string">El nombre del plan.</ResponseField>
      <ResponseField name="months" type="integer">Duración en meses (1, 3 o 12).</ResponseField>
      </Expandable>
    </ResponseField>
    </Expandable>
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "id": "order-abc123",
    "status": "unpaid",
    "price": 24.9,
    "expires_at": "2026-10-16T12:00:00.000Z",
    "allowed_payment_methods": ["pix"],
    "related_to": { "plan": { "name": "PRO", "months": 1 } }
  }
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP que no está en su lista de permitidas, o no tiene el ámbito que requiere la ruta (`403`).
  - `USER_NOT_FOUND`: No se encontró el usuario autenticado.
  - `ORDER_NOT_FOUND`: El pedido indicado no existe.
  - `FORBIDDEN`: El pedido no pertenece al usuario autenticado.
  - `INTERNAL_SERVER_ERROR`: Se produjo un error inesperado en el servidor.
</ResponseField>

<ResponseExample>

```json Error Response (404)
{
  "code": "ORDER_NOT_FOUND"
}
```

```json Error Response (403)
{
  "code": "FORBIDDEN"
}
```

</ResponseExample>
