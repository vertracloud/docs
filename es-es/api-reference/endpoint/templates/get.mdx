{/* @see APITemplateDetail, RESTGetAPITemplateQuery, RESTGetAPITemplateResponse — @vertracloud/api-types */}
Devuelve una plantilla, con todo lo necesario para pedir al usuario sus respuestas y mostrarle qué pasa después. Las plantillas públicas **no requieren autenticación**. Una plantilla privada solo es visible para su propietario o, cuando pertenece a un workspace, para los miembros que pueden leer las aplicaciones del workspace; para cualquier otra persona es el mismo `404` que una plantilla inexistente. Con una sesión o una clave de API (ámbito `templates:read`), la respuesta también incluye el bloque `account`. Una plantilla cerrada nunca incluye código. Las lecturas están limitadas a 60 peticiones por minuto por cliente.

<ParamField path="template_id" type="string" required>
  El ID o el slug de la plantilla. Las plantillas ocultas y obsoletas se sirven aquí aunque la galería no las liste (consulta `visibility`).
</ParamField>

<ParamField query="workspace_id" type="string">
  El workspace de una plantilla privada. Es necesario para resolver una plantilla de workspace por **slug**; por ID es opcional.
</ParamField>

### Respuesta

<ResponseField name="response" type="object">
  La plantilla. Tiene **todos los campos de los elementos que devuelve [Listar plantillas](/es-es/api-reference/endpoint/templates/list)** (`id`, `slug`, `origin`, `visibility`, `name`, `description`, `category`, `tags`, `icon_url`, `author_display`, `links`, `landing`, `featured`, `current_version`, `services`, `creates_stack`, `ram_min_total`, `byok`, `required_plan`, `code_view`, `uses_count`, `owner`, `github`, `created_at`, `updated_at` y, cuando estás autenticado, `account`), más los que siguen.

  <Expandable title="Mostrar objeto">

  <ResponseField name="inputs" type="object[]">
    Las preguntas que responde el usuario al usar la plantilla. Envía las respuestas en `inputs` de [Desplegar plantilla](/es-es/api-reference/endpoint/templates/deploy), por `id` de pregunta.

    <Expandable title="Mostrar objeto">

    <ResponseField name="id" type="string">
      El ID de la pregunta, único en la plantilla.
    </ResponseField>

    <ResponseField name="type" type="string">
      `text`, `secret`, `select`, `boolean`, `number`, `url` o `email`.
    </ResponseField>

    <ResponseField name="label" type="object">
      La pregunta en los tres idiomas.
    </ResponseField>

    <ResponseField name="help" type="object">
      Explicación opcional, en los tres idiomas.
    </ResponseField>

    <ResponseField name="required" type="boolean">
      Opcional; `false` cuando no aparece.
    </ResponseField>

    <ResponseField name="default" type="string | number | boolean">
      Respuesta por defecto opcional.
    </ResponseField>

    <ResponseField name="validation" type="object">
      Límites opcionales de la respuesta: `regex`, `min`, `max`, `min_length` y `max_length`.
    </ResponseField>

    <ResponseField name="generate" type="string">
      Para preguntas `secret`: `random:<n>` o `uuid`. La plataforma genera el valor cuando la respuesta se deja vacía.
    </ResponseField>

    <ResponseField name="editable" type="boolean">
      `false` junto con `generate` significa que el valor generado no puede reemplazarse.
    </ResponseField>

    <ResponseField name="when" type="object">
      La pregunta solo aplica cuando la respuesta a otra coincide: `input` (el ID de la otra pregunta) y `equals`.
    </ResponseField>

    <ResponseField name="options" type="object[]">
      Para preguntas `select`. Cada opción tiene `value`, un `label` opcional y `sets` opcionales, que son lo que cambia al elegirla: `services` (un ID de servicio a `on` u `off`), `env` (variables por servicio) y `ram_extra` (memoria extra en MB por servicio).
    </ResponseField>

    </Expandable>
  </ResponseField>

  <ResponseField name="permissions" type="object">
    Lo que puedes hacer con una aplicación creada desde la plantilla. Todos los valores son booleanos: `code_view`, `code_edit`, `ram_change`, `ram_below_min`, `ram_above_max`, `env_add`, `commands_edit`, `terminal`, `save_as_template` y `detach` (`true` cuando editar el código desvincula la aplicación de la plantilla; solo en plantillas abiertas). Consulta [Plantillas cerradas](/es-es/templates/use/closed-templates).
  </ResponseField>

  <ResponseField name="outputs" type="object[]">
    Lo que se muestra al final de un despliegue. Cada una tiene `label`, `value` (un texto o un texto por idioma, que puede ser un marcador de posición), `secret` y `once` (el valor se muestra una vez y nunca más).
  </ResponseField>

  <ResponseField name="readme" type="object | null">
    La documentación de la plantilla en Markdown, por idioma, o `null`.
  </ResponseField>

  <ResponseField name="changelog" type="object | null">
    El changelog de la última versión, por idioma, o `null`.
  </ResponseField>

  </Expandable>
</ResponseField>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `VALIDATION_ERROR`: Un parámetro no es válido (`400`).
  - `API_KEY_SCOPE_DENIED`: La clave de API no tiene el ámbito `templates:read` (`403`).
  - `TEMPLATE_NOT_FOUND`: La plantilla no existe, fue eliminada o no es visible para ti (`404`).
  - `WORKSPACE_NOT_FOUND`: El workspace de `workspace_id` no existe o no formas parte de él (`404`).
  - `RATE_LIMIT_EXCEEDED`: Demasiadas peticiones (`429`).
  - `INTERNAL_SERVER_ERROR`: Fallo inesperado (`500`).
</ResponseField>
