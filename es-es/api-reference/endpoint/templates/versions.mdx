{/* @see APITemplateVersion, RESTGetAPITemplateVersionsResponse — @vertracloud/api-types */}
Devuelve las versiones listas de una plantilla, de la más nueva a la más antigua, hasta 100. Las versiones nunca cambian después de publicarse. La visibilidad es la de [Obtener plantilla](/es-es/api-reference/endpoint/templates/get): las plantillas públicas no necesitan autenticación, una privada solo es visible para su propietario o para los lectores del workspace, y cualquier otro recibe `TEMPLATE_NOT_FOUND`. Con una clave de API el scope es `templates:read`. Las lecturas están limitadas a 60 peticiones por minuto y por cliente.

<ParamField path="template_id" type="string" required>
  El ID de la plantilla o su slug.
</ParamField>

<ParamField query="workspace_id" type="string">
  El workspace de una plantilla privada. Hace falta para resolver una plantilla del workspace por slug.
</ParamField>

Puedes desplegar una versión anterior solo cuando la plantilla lo permite; ver `version` en [Desplegar plantilla](/es-es/api-reference/endpoint/templates/deploy).

### Respuesta

<ResponseField name="response" type="object[]">
  Un array de versiones.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    El ID de la versión.
  </ResponseField>

  <ResponseField name="version" type="string">
    La versión semántica, como `1.2.0`.
  </ResponseField>

  <ResponseField name="security" type="boolean">
    `true` para una release de seguridad. Los propietarios de aplicaciones en una versión anterior reciben aviso.
  </ResponseField>

  <ResponseField name="created_at" type="string" format="date-time">
    Cuándo se publicó la versión.
  </ResponseField>

  <ResponseField name="changelog" type="object | null">
    Qué cambió, como texto por idioma (`pt-br`, `en`, `es`), o `null`.
  </ResponseField>

  <ResponseField name="manifest" type="object | null">
    El manifiesto de la versión: `id`, `version`, `name`, `description`, `category`, `tags`, `inputs`, `services`, `permissions`, `outputs` y los demás campos descritos en la [referencia del manifiesto](/es-es/templates/create/manifest-reference). Los valores de las variables ocultas nunca se incluyen. Es `null` cuando la plantilla está cerrada y tú no eres su propietario.
  </ResponseField>

  </Expandable>
</ResponseField>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `VALIDATION_ERROR`: Un parámetro no es válido (`400`).
  - `API_KEY_SCOPE_DENIED`: La clave de API no tiene el scope `templates:read` (`403`).
  - `TEMPLATE_NOT_FOUND`: La plantilla no existe, fue eliminada o no es visible para ti (`404`).
  - `WORKSPACE_NOT_FOUND`: El workspace de `workspace_id` no existe o no formas parte de él (`404`).
  - `RATE_LIMIT_EXCEEDED`: Demasiadas peticiones (`429`).
  - `INTERNAL_SERVER_ERROR`: Fallo inesperado (`500`).
</ResponseField>
