{/* @see RESTPostAPITemplateShareLinkBody, RESTPostAPITemplateShareLinkResponse — @vertracloud/api-types */}
Esta llamada crea un enlace para compartir una plantilla privada y responde `201` con el enlace y su token. **El token solo se muestra en esta respuesta y no puede recuperarse**: guárdalo ahora. Solo se guarda un hash de él, y la respuesta no se guarda en caché. Un token empieza por `vtpl_`.

Un enlace tiene uno de dos modos. Un enlace `use` permite a quien lo abre crear sus propias aplicaciones desde la plantilla, sin copiarla. Un enlace `full_copy` le da una plantilla privada propia, independiente de la tuya, que cuenta contra su límite de 5 plantillas privadas. `full_copy` necesita `share.full_copy` en `true` en la plantilla, y no está disponible para una [plantilla cerrada](/es-es/templates/use/closed-templates) ni para una versión que tenga variables `env_hidden`. Lee [Enlaces para compartir](/es-es/templates/create/share-links) antes de elegir.

Necesita el ámbito `templates:write` cuando se llama con una clave de API. Solo el propietario de la plantilla puede crear enlaces; en un workspace, un miembro ni siquiera puede listarlos. Quienes reciben el enlace ven el aviso "No verificado por Vertra" en la vista previa.

<ParamField path="template_id" type="string" required>
  El ID de la plantilla.
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la plantilla pertenece a un workspace, el ID del workspace.
</ParamField>

<ParamField body="mode" type="string">
  `use` o `full_copy`. Por defecto, `use`.
</ParamField>

<ParamField body="max_uses" type="integer">
  El número máximo de usos. Si no se indica, no hay límite. Un uso se cuenta cuando alguien empieza a crear desde el enlace; un uso rechazado o deshecho se devuelve.
</ParamField>

<ParamField body="expires_in_days" type="integer">
  El número de días hasta que el enlace caduca. Si no se indica, el enlace no caduca.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.vertracloud.app/v1/templates/tpl-abc123def456/share-links \
  -H "Authorization: Bearer $VERTRA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "mode": "use", "max_uses": 10, "expires_in_days": 7 }'
```

</RequestExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `API_KEY_SCOPE_DENIED`: La clave de API no tiene el ámbito `templates:write` (`403`).
  - `TEMPLATE_NOT_FOUND`: La plantilla no existe, está eliminada o no es tuya (`404`).
  - `TEMPLATE_SAVE_NOT_ALLOWED`: Se pidió `full_copy` y la plantilla no lo permite (`share.full_copy` no es `true`) (`403`).
  - `TEMPLATE_CLOSED`: Se pidió `full_copy` para una plantilla cerrada (`403`).
  - `VALIDATION_ERROR`: `max_uses` o `expires_in_days` no es un entero positivo (`400`).
  - `WORKSPACE_OWNER_ONLY`: Solo el propietario del workspace crea enlaces para sus plantillas.
</ResponseField>


</ResponseExample>
