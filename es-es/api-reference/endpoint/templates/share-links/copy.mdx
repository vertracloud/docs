{/* @see RESTPostAPITemplateShareCopyBody, RESTPostAPITemplateShareCopyResponse — @vertracloud/api-types */}
Esta llamada convierte un enlace `full_copy` en una plantilla privada que te pertenece y responde `201` con ella. Después nada vincula la copia con el autor: si el autor elimina la plantilla, la imagen o la cuenta, tu copia no cambia, y no recibes actualizaciones del original. El código y cualquier imagen se copian a tu cuenta; los secretos que el autor ocultó nunca llegan con ella, y el nombre del autor se mantiene como crédito. La copia cuenta contra tu límite de 5 plantillas privadas y, en una plantilla con imágenes, ocupa un slot de imagen por cada imagen distinta.

Requiere una cuenta (una sesión o una clave de API con el ámbito `templates:write`). Se aplican las reglas de plan de [Crear una plantilla privada](/es-es/api-reference/endpoint/templates/create), y en un workspace solo su propietario puede recibir una copia. El permiso se comprueba en el momento de la llamada: si el autor quitó `share.full_copy` después de crear el enlace, la llamada falla con `SHARE_LINK_REVOKED` y no se gasta ningún uso. Un enlace `use` se rechaza aquí con `400`: usa [Usar enlace](/es-es/api-reference/endpoint/templates/share-links/deploy).

<ParamField path="token" type="string" required>
  El token del enlace.
</ParamField>

<ParamField body="workspace_id" type="string">
  El workspace que será propietario de la copia. Si no se indica, la copia es tuya.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.vertracloud.app/v1/share/templates/vtpl_EXAMPLE_TOKEN/copy \
  -H "Authorization: Bearer $VERTRA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

</RequestExample>

### Respuesta

La plantilla privada de [Crear una plantilla privada](/es-es/api-reference/endpoint/templates/create), con `201 Created`. Su `slug` es el original, o el primero libre de entre `<slug>-copy`, `<slug>-copy-2` y así sucesivamente; `author_display` acredita al autor original.

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `API_KEY_SCOPE_DENIED`: La clave de API no tiene el ámbito `templates:write` (`403`).
  - `SHARE_LINK_NOT_FOUND`: El token tiene un formato no válido, no existe, o su plantilla fue eliminada (`404`).
  - `SHARE_LINK_REVOKED`: El enlace fue revocado, o el autor ya no permite copias completas (`410`).
  - `SHARE_LINK_EXPIRED`, `SHARE_LINK_EXHAUSTED`: El enlace caducó o alcanzó su `max_uses` (`410`).
  - `TEMPLATE_PRIVATE_LIMIT_REACHED`: Ya tienes 5 plantillas privadas.
  - `PLAN_DOES_NOT_SUPPORT_CUSTOM_IMAGES`: Tu plan no permite crear plantillas.
  - `TEMPLATE_IMAGE_SLOTS_EXHAUSTED`: La copia necesita más slots de imagen de los que tienes libres.
  - `WORKSPACE_OWNER_ONLY`: Solo el propietario del workspace recibe una copia en él.
</ResponseField>
