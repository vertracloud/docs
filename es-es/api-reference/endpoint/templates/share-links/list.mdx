{/* @see RESTGetAPITemplateShareLinksResponse — @vertracloud/api-types */}
Esta llamada lista todos los enlaces para compartir de una plantilla privada, incluidos los revocados y los caducados, para que veas cómo se usa cada uno. Los tokens nunca se vuelven a devolver: cada enlace muestra solo los últimos 4 caracteres (`last4`) para distinguirlos.

Necesita el ámbito `templates:read` cuando se llama con una clave de API. Solo el propietario de la plantilla puede listar sus enlaces; un miembro del workspace no puede.

<ParamField path="template_id" type="string" required>
  El ID de la plantilla.
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la plantilla pertenece a un workspace, el ID del workspace.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.vertracloud.app/v1/templates/tpl-abc123def456/share-links \
  -H "Authorization: Bearer $VERTRA_API_KEY"
```

</RequestExample>

### Respuesta

<ResponseField name="response" type="object[]">
  Los enlaces.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    El ID del enlace.
  </ResponseField>

  <ResponseField name="template_id" type="string">
    La plantilla a la que pertenece el enlace.
  </ResponseField>

  <ResponseField name="mode" type="string">
    `use` o `full_copy`.
  </ResponseField>

  <ResponseField name="last4" type="string">
    Los últimos 4 caracteres del token, para distinguir los enlaces.
  </ResponseField>

  <ResponseField name="uses" type="integer">
    Cuántas veces se usó el enlace.
  </ResponseField>

  <ResponseField name="max_uses" type="integer | null">
    El número máximo de usos, o `null` si no hay límite.
  </ResponseField>

  <ResponseField name="expires_at" type="string | null" format="date-time">
    Cuándo caduca el enlace, o `null` si no caduca.
  </ResponseField>

  <ResponseField name="revoked_at" type="string | null" format="date-time">
    Cuándo lo revocó el autor, o `null`.
  </ResponseField>

  <ResponseField name="created_at" type="string" format="date-time">
    Cuándo se creó el enlace.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": [
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `API_KEY_SCOPE_DENIED`: La clave de API no tiene el ámbito `templates:read` (`403`).
  - `TEMPLATE_NOT_FOUND`: La plantilla no existe o no es tuya (`404`).
  - `WORKSPACE_OWNER_ONLY`: Solo el propietario del workspace lista los enlaces de sus plantillas.
</ResponseField>

<ResponseExample>

```json Error Response
{
  "code": "TEMPLATE_NOT_FOUND"
}
```

</ResponseExample>
