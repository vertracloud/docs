---
title: Actualizar perfil de usuario
sidebarTitle: Actualizar perfil
api: PATCH https://api.vertracloud.app/v1/users/me
authMethod: bearer
description: Actualiza el nombre, el idioma y las preferencias de invitaciones a workspaces del usuario autenticado. Requiere el scope account:write.
---
Envía al menos un campo. Una clave de API necesita el scope `account:write`.

<ParamField body="name" type="string">
  El nombre visible.
</ParamField>

<ParamField body="language" type="string">
  El idioma de la interfaz: `pt-br`, `en-us` o `es-es`. Cualquier otro valor devuelve `400 INVALID_PAYLOAD`.
</ParamField>

<ParamField body="workspace_invites_enabled" type="boolean">
  Si otras personas pueden invitarte a sus workspaces.
</ParamField>

### Respuesta

<ResponseField name="response" type="object">
  El perfil actualizado: `id`, `name`, `email`, `language`, `workspace_invites_enabled`,
  `created_at` y `updated_at`.
</ResponseField>

### Respuestas de error

<ResponseField name="code" type="string">
  - `INVALID_PAYLOAD`: No se envió ningún campo, o un campo tiene el tipo incorrecto (`400`).
</ResponseField>
