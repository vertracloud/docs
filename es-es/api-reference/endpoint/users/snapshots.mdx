---
title: Listar todos los snapshots de la cuenta
sidebarTitle: Todos los snapshots
api: GET https://api.vertracloud.app/v1/users/snapshots
authMethod: bearer
description: Lista cada snapshot de las aplicaciones o bases de datos de la cuenta, agrupados por recurso. Requiere el scope snapshots:read.
---
Devuelve los snapshots de cada aplicación (o de cada base de datos) que te pertenece, agrupados por recurso. Para
listar los snapshots de un solo recurso, usa [Obtener snapshots](/es-es/api-reference/endpoint/apps/snapshots/getall).

<ParamField query="scope" type="string">
  `applications` (por defecto) o `databases`.
</ParamField>

### Respuesta

<ResponseField name="response" type="array">
  Una entrada por recurso que tenga al menos un snapshot.

  <Expandable title="Mostrar objeto">

  <ResponseField name="resource_id" type="string">El ID de la aplicación o base de datos.</ResponseField>
  <ResponseField name="current_resource_name" type="string | null">El nombre actual del recurso, o `null` si ya no existe.</ResponseField>
  <ResponseField name="type" type="number">`1` para aplicaciones, `2` para bases de datos.</ResponseField>
  <ResponseField name="snapshots" type="array">
    Los snapshots del recurso: `id`, `resource_id`, `resource_name` (el nombre cuando se tomó el snapshot), `size` y `date`.
  </ResponseField>

  </Expandable>
</ResponseField>
