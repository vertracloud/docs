---
title: Listar runtimes
sidebarTitle: Runtimes
api: GET https://api.vertracloud.app/v1/apps/runtimes
authMethod: bearer
description: Devuelve el catálogo de lenguajes/runtimes compatibles y sus versiones disponibles, para usarlo al crear una aplicación.
---
### Respuesta

<ResponseField name="response" type="object">
  Un mapa del nombre de cada lenguaje a su entrada de runtime.

  <Expandable title="Mostrar objeto">

  <ResponseField name="recommended" type="string">
    La versión recomendada para las aplicaciones nuevas.
  </ResponseField>

  <ResponseField name="latest" type="string">
    La última versión disponible.
  </ResponseField>

  <ResponseField name="specific" type="array">
    Otras versiones exactas que se pueden fijar. Vacío en los runtimes sin fijación de versión (por ejemplo, `static`).
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "javascript": { "recommended": "22.23.4", "latest": "24.22.1", "specific": ["22.23.4", "24.22.1"] },
    "python": { "recommended": "3.13.17", "latest": "3.13.17", "specific": ["3.11.17", "3.12.15", "3.13.17"] },
    "deno": { "recommended": "2.9.8", "latest": "2.9.8", "specific": ["2.8.3", "2.9.8"] },
    "static": { "recommended": "latest", "latest": "latest", "specific": [] }
  }
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP fuera de su lista de permitidas, o no tiene el scope que requiere la ruta (`403`).
  - `INTERNAL_SERVER_ERROR`: Se produjo un error inesperado en el servidor.
</ResponseField>

<ResponseExample>

```json Error Response (401)
{
  "code": "AUTH_TOKEN_MISSING"
}
```

</ResponseExample>
