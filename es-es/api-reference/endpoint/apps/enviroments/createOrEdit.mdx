---
title: Crear o editar variables de entorno de la aplicación
sidebarTitle: Crear/editar variables de entorno
api: POST https://api.vertracloud.app/v1/apps/{id}/envs
authMethod: bearer
description: Crea o actualiza las variables de entorno de una aplicación a partir de su ID.
---

{/* @see APIApplicationEnvironment[] — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  El ID de la aplicación para la que se crearán o actualizarán las variables de entorno.
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la aplicación pertenece a un workspace, el ID de ese workspace. Obligatorio para los miembros del workspace que actúan sobre una aplicación que no les pertenece.
</ParamField>

<ParamField body="environments" type="array" required>
  Un array de objetos de variable de entorno.

  <Expandable title="Mostrar objeto">

  <ParamField name="key" type="string" required>
    La clave de la variable de entorno (máximo 255 caracteres).
  </ParamField>

  <ParamField name="value" type="string" required>
    El valor de la variable de entorno (máximo 3.072 caracteres).
  </ParamField>

  <ParamField name="note" type="string">
    Una nota o descripción opcional de la variable de entorno.
  </ParamField>

  </Expandable>
</ParamField>

### Respuesta

<ResponseField name="response" type="array">
  Un array de objetos de variable de entorno después de crearlos o actualizarlos.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    El ID de la variable de entorno.
  </ResponseField>

  <ResponseField name="key" type="string">
    La clave de la variable de entorno.
  </ResponseField>

  <ResponseField name="value" type="string">
    El valor de la variable de entorno (descifrado).
  </ResponseField>

  <ResponseField name="note" type="string | null">
    La nota o descripción opcional de la variable de entorno.
  </ResponseField>

  <ResponseField name="created_at" type="string" format="date-time">
    La fecha y hora en que se creó la variable de entorno.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": [
    {
      "id": "env123",
      "key": "API_KEY",
      "value": "secret123",
      "note": "API key for external service",
      "created_at": "2026-03-14T19:58:00Z"
    },
    {
      "id": "env456",
      "key": "DATABASE_URL",
      "value": "mysql://user:pass@database-host/db",
      "note": null,
      "created_at": "2026-03-14T19:58:00Z"
    }
  ]
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP fuera de su lista de permitidas, o no tiene el scope que requiere la ruta (`403`).
  - `ACCESS_DENIED`: El recurso pertenece a otra cuenta, o no tienes el permiso de workspace necesario para él (`403`).
  - `FORBIDDEN`: El usuario no tiene permiso para acceder a la aplicación.
  - `APP_NOT_FOUND`: La aplicación indicada no existe.
  - `INVALID_BODY`: El cuerpo de la petición no es un array válido o está vacío.
  - `INVALID_ENVIRONMENT`: Una o más variables de entorno no son válidas o usan claves prohibidas.
  - `VALIDATION_ERROR`: Una `key` tiene más de 255 caracteres o un `value` más de 3.072 caracteres (`400`); `details.path` apunta al campo.
  - `ENV_LIMIT_EXCEEDED`: El número total de variables de entorno supera el límite de 256.
</ResponseField>

<ResponseField name="message" type="string">
  Una descripción detallada con información adicional sobre el error.
</ResponseField>

<ResponseExample>

```json Error Response (404)

}
```

```json Error Response (400)

  "code": "INVALID_BODY"
}
```

</ResponseExample>
