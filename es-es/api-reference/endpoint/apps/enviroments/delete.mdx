---
title: Eliminar una variable de entorno de la aplicación
sidebarTitle: Eliminar variable de entorno
api: DELETE https://api.vertracloud.app/v1/apps/{id}/envs/{envId}
authMethod: bearer
description: Elimina una variable de entorno de una aplicación a partir del ID de la variable.
---

{/* @see success/error — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  El ID de la aplicación.
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la aplicación pertenece a un workspace, el ID de ese workspace. Obligatorio para los miembros del workspace que actúan sobre una aplicación que no les pertenece.
</ParamField>

<ParamField path="envId" type="string" required>
  El ID de la variable de entorno, tal como lo devuelve [Listar variables de entorno](/es-es/api-reference/endpoint/apps/enviroments/get). No tiene cuerpo de petición.
</ParamField>

### Respuesta

Si todo va bien, responde `200` con `{ "response": null }`. La variable se elimina de la configuración de la aplicación; reinicia la aplicación para que el proceso en ejecución deje de verla.

```json Response
{
  "response": null
}
```

### Respuestas de error

<ResponseField name="code" type="string">
  - `APP_NOT_FOUND`: La aplicación no existe (`404`).
  - `ACCESS_DENIED`: Tu cuenta no puede actuar sobre esta aplicación (`403`).
  - `ENV_NOT_FOUND`: No hay ninguna variable con ese ID en esta aplicación (`404`).
</ResponseField>
