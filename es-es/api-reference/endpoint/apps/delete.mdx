---
Eliminar una aplicación por la API la elimina de inmediato y **no crea un snapshot**. Si quieres una copia, llama antes a
[Crear snapshot](/api-reference/endpoint/apps/snapshots/create). (El diálogo de eliminación del panel ofrece
**Crear snapshot antes de borrar**, desmarcada por defecto.)


{/* @see success/error — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  El ID de la aplicación que se va a eliminar.
</ParamField>

### Respuesta

<ResponseField name="response" type="null">
  Siempre `null`: la aplicación se eliminó.
</ResponseField>

<ResponseExample>

```json Response
{
  "response": null
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP fuera de su lista de permitidas, o no tiene el scope que requiere la ruta (`403`).
  - `ACCESS_DENIED`: El recurso pertenece a otra cuenta, o no tienes el permiso de workspace necesario para él (`403`).
  - `APP_NOT_FOUND`: La aplicación indicada no existe.
  - `APP_SHIELD_COOLDOWN`: Vertra Shield pausó la aplicación; no se puede eliminar hasta que termine la pausa (`403`). `details.until` indica cuándo.
  - `APP_ID_REQUIRED`: No se indicó el ID de la aplicación.
  - `INTERNAL_SERVER_ERROR`: No se pudo eliminar la aplicación (`500`).
  - `OPERATION_IN_PROGRESS`: Ya se está ejecutando otra operación de ciclo de vida sobre la misma aplicación (`409`). No se eliminó nada: espera unos segundos y vuelve a intentarlo. Consulta [Códigos de error comunes](/es-es/api-reference/introduction#qué-códigos-de-error-puede-devolver-la-api).
</ResponseField>

<ResponseField name="message" type="string">
  Una descripción detallada con información adicional sobre el error.
</ResponseField>
