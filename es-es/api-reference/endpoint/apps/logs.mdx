---
title: Logs de la aplicación
sidebarTitle: Logs de la aplicación
api: GET https://api.vertracloud.app/v1/apps/{id}/logs
authMethod: bearer
description: Devuelve los logs de una aplicación a partir de su ID.
---

{/* @see string — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  El ID de la aplicación cuyos logs quieres obtener. Si la aplicación pertenece a un workspace, pasa su ID en el parámetro de consulta `workspace_id`.
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la aplicación pertenece a un workspace, el ID del workspace. Es obligatorio para los miembros del workspace que actúen sobre una aplicación que no les pertenece.
</ParamField>

### Respuesta

<ResponseField name="response" type="string">
  El contenido de los logs de la aplicación indicada.
</ResponseField>

}

</ResponseExample>
