---
title: Estado de todas las aplicaciones
sidebarTitle: Estado de todas las aplicaciones
api: GET https://api.vertracloud.app/v1/apps/status
authMethod: bearer
description: Devuelve el estado de todas las aplicaciones del usuario autenticado o de un workspace concreto.
---

{/* @see APIApplicationStatusShort[] — @vertracloud/api-types */}
<ParamField query="workspace_id" type="string">
  El ID del workspace del que se quiere obtener el estado de las aplicaciones, si aplica.
</ParamField>

### Respuesta

<ResponseField name="response" type="array">
  Un array con un objeto de estado por cada aplicación.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    El ID de la aplicación.
  </ResponseField>

  <ResponseField name="cpu" type="string">
    Porcentaje de uso de CPU (por ejemplo, `25.5%`).
  </ResponseField>

  <ResponseField name="ram" type="string">
    Uso de RAM (por ejemplo, `512 MB`).
  </ResponseField>

  <ResponseField name="running" type="boolean">
    Indica si la aplicación está en ejecución.
  </ResponseField>

  <ResponseField name="installing" type="boolean">
    Presente y `true` mientras se instalan las dependencias o la aplicación se reconstruye. Durante ese tiempo, `running` puede ser `false` aunque haya trabajo en curso.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": [
    {
      "id": "app-abc123def456",
      "cpu": "25.50%",
      "ram": "512.00 MB",
      "running": true
    },
    {
      "id": "app-xyz789mno012",
      "cpu": "0.00%",
      "ram": "0.00 MB",
      "running": false
    }
  ]
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP fuera de su lista de permitidas, o no tiene el scope que requiere la ruta (`403`).
  - `WORKSPACE_NOT_FOUND`: El workspace indicado no existe.
  - `USER_NOT_IN_WORKSPACE`: El usuario no es miembro del workspace indicado.
</ResponseField>

<ResponseField name="message" type="string">
  Una descripción detallada con información adicional sobre el error.
</ResponseField>

<ResponseExample>

```json Error Response (403)
{
  "code": "API_KEY_SCOPE_DENIED"
}
```

```json Error Response (404)
{
  "code": "WORKSPACE_NOT_FOUND"
}
```

```json Error Response (403)
{
  "code": "USER_NOT_IN_WORKSPACE"
}
```

</ResponseExample>
