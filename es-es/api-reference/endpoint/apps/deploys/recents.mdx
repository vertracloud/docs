---
title: Obtener despliegues recientes
sidebarTitle: Despliegues recientes
api: GET https://api.vertracloud.app/v1/apps/{app_id}/deploys
authMethod: bearer
description: Devuelve los 20 despliegues más recientes de una aplicación concreta.
---

{/* @see deployments list — @vertracloud/api-types */}
<ParamField path="app_id" type="string" required>
El ID de la aplicación de la que se quieren obtener los despliegues recientes.
</ParamField>

### Respuesta

<ResponseField name="response" type="array">
Un array de objetos de despliegue.

<Expandable title="Mostrar objeto">
  <ResponseField name="app_id" type="string">
  El ID de la aplicación.
  </ResponseField>

  <ResponseField name="commit_id" type="string">
  El ID del commit del despliegue.
  </ResponseField>

  <ResponseField name="message" type="string">
  Mensaje del commit.
  </ResponseField>

  <ResponseField name="pusher" type="string">
  El nombre de usuario de la persona que disparó el despliegue.
  </ResponseField>

  <ResponseField name="branch" type="string">
  La rama que se desplegó.
  </ResponseField>

  <ResponseField name="created_at" type="string">
  Marca de tiempo ISO de cuándo se produjo el despliegue.
  </ResponseField>
</Expandable>
</ResponseField>

<ResponseExample>
```json
{
  "response": [
    {
      "app_id": "123",
      "commit_id": "abc123",
      "message": "Fix deployment bug",
      "pusher": "user1",
      "branch": "main",
      "created_at": "2026-03-14T20:00:00.000Z"
    }
  ]
}
```
</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
Códigos de error posibles:
- `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
- `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP fuera de su lista de permitidas, o no tiene el scope que requiere la ruta (`403`).
- `INTEGRATION_NOT_FOUND`: No se encontró la aplicación ni sus despliegues.
</ResponseField>

<ResponseField name="message" type="string">
  Una descripción detallada con información adicional sobre el error.
</ResponseField>

<ResponseExample>
```json
{
  "code": "INTEGRATION_NOT_FOUND"
}
```
</ResponseExample>
