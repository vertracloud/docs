---
title: Eliminar webhook de despliegue
sidebarTitle: Eliminar webhook
api: DELETE https://api.vertracloud.app/v1/apps/{app_id}/deploys/webhook
authMethod: bearer
description: Elimina un webhook de despliegue existente de una aplicación.
---

{/* @see success/error — @vertracloud/api-types */}
<ParamField path="app_id" type="string" required>
El ID de la aplicación de la que se eliminará el webhook.
</ParamField>

### Respuesta

Si todo va bien, responde `200` con `{ "response": null }`.

<ResponseExample>
```json
{
  "response": null
}
```
</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
Códigos de error posibles:
- `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
- `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP fuera de su lista de permitidas, o no tiene el scope que requiere la ruta (`403`).
- `ACCESS_DENIED`: El recurso pertenece a otra cuenta, o no tienes el permiso de workspace necesario para él (`403`).
- `PLAN_RESTRICTED_FEATURE`: El plan del usuario no admite el despliegue automático.
- `MISSING_APP_ID`: No se indicó el ID de la aplicación.
- `APP_NOT_FOUND`: No se encontró el webhook de integración de la aplicación.
- `INSTALLATION_NOT_FOUND`: No se encontró la instalación de GitHub del usuario.
</ResponseField>

<ResponseField name="message" type="string">
  Una descripción detallada con información adicional sobre el error.
</ResponseField>

<ResponseExample>
```json
{
  "code": "APP_NOT_FOUND"
}
```
</ResponseExample>
