title: Obtener el log de una release de la aplicación
sidebarTitle: Obtener log de la release
api: GET https://api.vertracloud.app/v1/apps/{id}/releases/{release_id}/log
authMethod: bearer
description: Devuelve el log de fallos registrado para una release de la aplicación, o null si no hay log o ha expirado.
---

{/* @see APIApplicationReleaseLog — @vertracloud/api-types */}
Devuelve el log de fallos registrado para una release, para que puedas ver por qué falló o se cayó tras arrancar. El `content` es `null` cuando la release no tiene log o el log ha expirado. Consulta `has_log` en la [lista de releases](/es-es/api-reference/endpoint/apps/releases/list) para saberlo de antemano.

<ParamField path="id" type="string" required>
  El ID de la aplicación. Si la aplicación pertenece a un workspace, pasa su ID en el parámetro de consulta `workspace_id`.
</ParamField>

<ParamField path="release_id" type="string" required>
  El ID de la release, tal como lo devuelve la [lista de releases](/es-es/api-reference/endpoint/apps/releases/list).
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la aplicación pertenece a un workspace, el ID del workspace.
</ParamField>

Requiere el scope `apps:read` cuando se llama con una clave de API.

### Respuesta

<ResponseField name="response" type="object">
  Contiene el log de la release.

  <Expandable title="Mostrar objeto">

  <ResponseField name="content" type="string | null">
  El texto del log, o `null` cuando no hay log para esta release o ha expirado.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>
```json Response
{
  "response": {
    "content": "Error: Cannot find module 'express'\n    at Module._resolveFilename"
  }
}
```

```json Response (no log)
{
  "response": {
    "content": null
  }
}
```
</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
Códigos de error posibles:
- `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
- `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP fuera de su lista de permitidas, o no tiene el scope que requiere la ruta (`403`).
- `APP_NOT_FOUND`: La aplicación no existe, o no pertenece a esta cuenta ni a este workspace (`404`).
- `RELEASE_NOT_FOUND`: La release no existe, o pertenece a otra aplicación (`404`).
</ResponseField>

<ResponseField name="message" type="string">
  Un mensaje descriptivo con más detalles sobre el error.
</ResponseField>

<ResponseExample>
```json
{
  "code": "RELEASE_NOT_FOUND"
}
```
</ResponseExample>
