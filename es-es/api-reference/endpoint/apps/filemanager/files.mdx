---
title: Obtener archivos de la aplicación
sidebarTitle: Obtener archivos
api: GET https://api.vertracloud.app/v1/apps/{id}/files
authMethod: bearer
description: Devuelve la lista de archivos y carpetas de una aplicación a partir de su ID.
---

{/* @see APIApplicationFile[] — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  El ID de la aplicación de la que se obtendrán los archivos. Si la aplicación pertenece a un workspace, pasa su ID en el parámetro de query `workspace_id`.
</ParamField>

<ParamField query="workspace_id" type="string">
  Si la aplicación pertenece a un workspace, el ID de ese workspace. Los miembros con el rol Propietario, Administrador o Desarrollador pueden usar el gestor de archivos en una aplicación del workspace que no les pertenece; sin este parámetro, solo puede hacerlo el propietario de la aplicación.
</ParamField>

<ParamField query="path" type="string">
  La ruta relativa desde la que listar los archivos. Por defecto, el directorio raíz (`/`).
</ParamField>

### Respuesta

<ResponseField name="response" type="array">
  Un array de objetos de archivo o carpeta.

  <Expandable title="Mostrar objeto">

  <ResponseField name="name" type="string">
    El nombre del archivo o de la carpeta.
  </ResponseField>

  <ResponseField name="path" type="string">
    La ruta completa del archivo o de la carpeta.
  </ResponseField>

  <ResponseField name="type" type="string">
    `"file"` o `"directory"`.
  </ResponseField>

  <ResponseField name="size" type="string">
    El tamaño del archivo, legible para personas (por ejemplo, `"12.34 KB"`). Solo aparece en las entradas de tipo `"file"`; las carpetas no tienen tamaño.
  </ResponseField>

  <ResponseField name="last_modified" type="string" format="date-time">
    La fecha y hora de la última modificación del archivo o de la carpeta.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": [
    {
      "type": "file",
      "name": "index.js",
      "path": "/index.js",
      "size": "1.24 KB",
      "last_modified": "2026-03-14T19:58:00Z"
    },
    {
      "type": "directory",
      "name": "src",
      "path": "/src",
      "last_modified": "2026-03-14T19:58:00Z"
    }
  ]
}
```

</ResponseExample>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: Falta la cabecera `Authorization`, la clave de API no es válida o la sesión del panel fue revocada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: La clave de API se usa desde una IP fuera de su lista de permitidas, o no tiene el scope que requiere la ruta (`403`).
  - `ACCESS_DENIED`: El recurso pertenece a otra cuenta, o no tienes el permiso de workspace necesario para él (`403`).
  - `FORBIDDEN`: El usuario no tiene permiso para acceder a la aplicación.
  - `APP_NOT_FOUND`: La aplicación indicada no existe.
  - `PLAN_RESTRICTED_FEATURE`: El plan del usuario no admite el acceso al gestor de archivos.
  - `INTERNAL_SERVER_ERROR`: No se pudo obtener la lista de archivos.
</ResponseField>

<ResponseField name="message" type="string">
  Una descripción detallada con información adicional sobre el error.
</ResponseField>

<ResponseExample>

```json Error Response (403)
{
  "code": "ACCESS_DENIED"

```

```json Error Response (404)
{
  "code": "APP_NOT_FOUND"
}
```

```json Error Response (403)
{
  "code": "PLAN_RESTRICTED_FEATURE"
}
```

</ResponseExample>
