{/* @see RESTGetAPIPlansResponse, APIPlansCatalog — @vertracloud/api-types */}
Devuelve los planes que puedes comprar hoy, con el precio, la memoria, la vCPU, los límites y las funciones de cada uno, y los periodos de facturación con sus descuentos. La ruta es pública: no necesita clave de API ni sesión, así que puedes llamarla antes de que exista una cuenta. Está limitada a 60 peticiones por minuto por dirección IP, y la respuesta puede guardarse en caché durante 60 segundos.

Úsala para montar una tabla de precios o para validar los nombres de plan que envías en [Crear pedido](/es-es/api-reference/endpoint/billing/create-order). El importe que se cobra de verdad a una cuenta sale de [Cotizar pedido](/es-es/api-reference/endpoint/billing/quote-order), porque puede incluir un cupón o un precio mantenido de un plan anterior.

### Respuesta

<ResponseField name="response" type="object">
  <Expandable title="Toggle object">

  <ResponseField name="grid" type="string">
    La parrilla de planes vigente: `v3` es la actual. `legacy` es la parrilla anterior, que solo se devuelve antes de que la actual salga a la venta.
  </ResponseField>

  <ResponseField name="cycles" type="object[]">
    Los periodos de facturación que puedes comprar y su descuento sobre el precio mensual.

    <Expandable title="Toggle object">
    <ResponseField name="months" type="integer">`1`, `3`, `6` or `12`.</ResponseField>
    <ResponseField name="discount_percent" type="number">Descuento sobre el precio mensual: 0, 10, 15 y 25 para 1, 3, 6 y 12 meses.</ResponseField>
    </Expandable>
  </ResponseField>

  <ResponseField name="plans" type="object[]">
    Los planes a la venta, del más pequeño al más grande.

    <Expandable title="Toggle object">
    <ResponseField name="name" type="string">El nombre del plan, el valor que envías en `plan` al crear un pedido, como `starter-1`, `pro-4`, `business-12` o `enterprise-32`.</ResponseField>
    <ResponseField name="family" type="string | null">`starter`, `pro`, `business` o `enterprise`. `null` para un plan de la parrilla anterior.</ResponseField>
    <ResponseField name="legacy" type="boolean">`true` para un plan de la parrilla anterior, que ya no se vende. Es `false` en todos los planes cuando `grid` es `v3`.</ResponseField>
    <ResponseField name="memory_mb" type="integer">La memoria que la cuenta puede asignar entre sus aplicaciones y bases de datos, en MB.</ResponseField>
    <ResponseField name="max_vcpus_per_app" type="number">El máximo de vCPU que puede usar una aplicación en el plan.</ResponseField>
    <ResponseField name="price" type="number">El precio mensual en BRL, sin ningún descuento de periodo. El precio de un periodo es `price` por `months` por `(1 - discount_percent / 100)`, redondeado al céntimo.</ResponseField>
    <ResponseField name="payment_methods" type="string[]">`pix` y `card`.</ResponseField>

    <ResponseField name="limits" type="object">
      <Expandable title="Toggle object">
      <ResponseField name="deploys_per_hour" type="integer">Despliegues por hora.</ResponseField>
      <ResponseField name="requests_per_minute" type="integer">Peticiones a la API por minuto con una clave de API.</ResponseField>
      <ResponseField name="requests_per_day" type="integer">Peticiones a la API por día con una clave de API.</ResponseField>
      <ResponseField name="max_domains" type="integer">Dominios personalizados por aplicación.</ResponseField>
      <ResponseField name="max_domain_ports" type="integer">Puertos además del 80 que puede servir una aplicación con dominios.</ResponseField>
      <ResponseField name="manual_backups_per_day" type="integer">Copias de seguridad manuales por cuenta y día.</ResponseField>
      <ResponseField name="workspace_members" type="integer">Miembros de un workspace.</ResponseField>
      <ResponseField name="workspace_roles" type="integer">Roles personalizados de un workspace.</ResponseField>
      <ResponseField name="release_versions" type="integer">Versiones guardadas para rollback.</ResponseField>
      <ResponseField name="release_retention_days" type="integer">Días que se conserva una versión.</ResponseField>
      <ResponseField name="max_custom_images" type="integer">Imágenes Docker personalizadas. `0` cuando el plan no tiene.</ResponseField>
      <ResponseField name="blob" type="object">
        Límites de Blob Storage: `quota_bytes`, `max_rules`, `max_custom_domains`, `image_transformations_per_month` y `s3_requests_per_10s`.
      </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="features" type="object">
      Booleanos de lo que incluye el plan: `web_published`, `daily_backups`, `create_backup`, `advanced_metrics`, `create_workspace`, `custom_domain`, `custom_subdomain`, `file_manager`, `database_manager`, `auto_deploy`, `rollback`, `auto_rollback`, `zero_downtime`, `delete_snapshot`, `powered_by_badge`, `blob_metadata`, `blob_share_password`, `blob_unlimited_upload_rate`, `blob_no_cache` y `blob_short_expiration`.
    </ResponseField>
    </Expandable>
  </ResponseField>

  </Expandable>
</ResponseField>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `RATE_LIMIT_EXCEEDED`: Más de 60 peticiones en un minuto desde la misma dirección IP (`429`). `details.retry_after` indica la espera.
  - `INTERNAL_SERVER_ERROR`: Se produjo un error inesperado del servidor.
</ResponseField>
