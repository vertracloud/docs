{/* @see RESTGetAPIStacksResponse, APIStack — @vertracloud/api-types */}
Devuelve todos los stacks que posees, o los stacks de un workspace cuando pasas `workspace_id`. Un stack agrupa aplicaciones, bases de datos y carpetas de Blob, y las conexiones entre ellos. Consulta [Stacks](/es-es/templates/use/stacks) para ver el concepto.

Requiere el scope `stacks:read` cuando se llama con una clave de API.

<ParamField query="workspace_id" type="string">
  Lista los stacks de este workspace en lugar de los tuyos. Los miembros del workspace pueden leer los stacks; solo el propietario puede modificarlos.
</ParamField>

### Response

<ResponseField name="response" type="object[]">
  Un array de stacks. Cada elemento tiene la misma forma que el objeto que devuelve [Obtener stack](/es-es/api-reference/endpoint/stacks/get).
</ResponseField>

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | La clave no tiene `stacks:read`. |
| 404 | `WORKSPACE_NOT_FOUND` | El workspace no existe o no eres miembro. |
