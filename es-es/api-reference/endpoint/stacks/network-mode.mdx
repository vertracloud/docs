description: Define cómo se alcanzan entre sí los miembros de un stack. El único modo aceptado es `public`.
---

{/* @see RESTPostAPIStackNetworkModeBody, RESTPostAPIStackNetworkModeResponse — @vertracloud/api-types */}
Solo se acepta `public`: los miembros usan las direcciones públicas de los servicios, y las bases de datos se alcanzan con certificados de cliente. Cualquier otro valor falla con `STACK_NETWORK_MODE_UNAVAILABLE`. Requiere el scope `stacks:write` cuando se llama con una clave de API.

<ParamField path="stack_id" type="string" required>
  El ID del stack.
</ParamField>

<ParamField query="workspace_id" type="string">
  El workspace al que pertenece el stack, cuando actúas sobre él como propietario del workspace.
</ParamField>

<ParamField body="network_mode" type="string" required>
  `public`.
</ParamField>

### Response

El stack, como en [Obtener stack](/es-es/api-reference/endpoint/stacks/get).

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 400 | `STACK_NETWORK_MODE_UNAVAILABLE` | El modo no es `public`. |
| 403 | `WORKSPACE_OWNER_ONLY` | Eres miembro del workspace, no su propietario. |
| 404 | `STACK_NOT_FOUND` | El stack no existe o pertenece a otra cuenta. |
