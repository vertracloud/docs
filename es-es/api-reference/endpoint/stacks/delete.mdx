title: Eliminar stack

api: DELETE https://api.vertracloud.app/v1/stacks/{stack_id}
authMethod: bearer
description: Disuelve un stack y conserva sus miembros, o elimina el stack junto con todos sus miembros y, opcionalmente, sus archivos de Blob.
---

{/* @see RESTDeleteAPIStackBody, RESTDeleteAPIStackResponse — @vertracloud/api-types */}
Elige entre dos modos. **`dissolve`** elimina solo el stack: las aplicaciones y las bases de datos quedan como recursos sueltos, sin las variables ni los certificados gestionados, y los archivos de Blob se conservan. **`delete_all`** elimina también a todos los miembros, cada uno según su propia regla de eliminación (con la snapshot de seguridad cuando existe). En ambos casos se revoca la clave de API que creó la plataforma para la carpeta de Blob del stack.

<Warning>
  `delete_all` no se puede deshacer y elimina aplicaciones y bases de datos. Confirma el nombre y revisa antes los miembros con [Obtener stack](/es-es/api-reference/endpoint/stacks/get).
</Warning>

Requiere el scope `stacks:delete` cuando se llama con una clave de API. Con `delete_all`, la clave también necesita `apps:delete` y `databases:delete`, y `blob:write` cuando eliminas los archivos de Blob (`blob: "delete"`). Sin ellos, la llamada falla con `API_KEY_SCOPE_DENIED`.

<ParamField path="stack_id" type="string" required>
  El ID del stack.
</ParamField>

<ParamField query="workspace_id" type="string">
  El workspace al que pertenece el stack, cuando actúas sobre él como propietario del workspace.
</ParamField>

<ParamField body="mode" type="string" required>
  `dissolve` o `delete_all`.
</ParamField>

<ParamField body="confirm_name" type="string" required>
  Debe ser igual al nombre del stack.
</ParamField>

<ParamField body="blob" type="string" default="keep">
  Qué hacer con los archivos de la carpeta de Blob del stack cuando `mode` es `delete_all`: `keep` los deja donde están, `delete` los elimina. `dissolve` siempre los conserva.
</ParamField>

### Response

<ResponseField name="response" type="object">
  <Expandable title="Mostrar objeto">

  <ResponseField name="deleted_apps" type="string[]">IDs de las aplicaciones eliminadas. Vacío con `dissolve`.</ResponseField>
  <ResponseField name="deleted_databases" type="string[]">IDs de las bases de datos eliminadas. Vacío con `dissolve`.</ResponseField>
  <ResponseField name="deleted_blob" type="boolean">`true` cuando se eliminaron los archivos de la carpeta de Blob.</ResponseField>

  </Expandable>
</ResponseField>

{

    "deleted_databases": ["db-abc123def456"],

<RequestExample>

```bash cURL
curl -X DELETE https://api.vertracloud.app/v1/stacks/stk-abc123def456 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "mode": "delete_all", "confirm_name": "shop", "blob": "keep" }'
```

</RequestExample>

### Errores

| Estado | Código | Cuándo |
|---|---|---|
| 400 | `STACK_NAME_MISMATCH` | `confirm_name` no es el nombre del stack. |
| 403 | `API_KEY_SCOPE_DENIED` | La clave no tiene `stacks:delete`, o con `delete_all` no tiene `apps:delete`, `databases:delete` o `blob:write`; `details.required` indica el scope que falta. |
| 403 | `WORKSPACE_OWNER_ONLY` | Eres miembro del workspace, no su propietario. |
| 404 | `STACK_NOT_FOUND` | El stack no existe o pertenece a otra cuenta. |
