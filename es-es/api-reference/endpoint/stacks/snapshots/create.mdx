{/* @see RESTPostAPIStackSnapshotResponse, APIStackSnapshotAccepted — @vertracloud/api-types */}
Toma una snapshot de cada aplicación y base de datos del stack y las agrupa. Cada miembro es una snapshot manual común: aparece en la lista de snapshots de su aplicación o base de datos, usa la cuota de snapshots manuales de la cuenta y se conserva 30 días. La snapshot corre en segundo plano y la solicitud responde **`202`** en cuanto se acepta; todavía no se tomó nada. Requiere el scope `stacks:write` cuando se llama con una clave de API.

<ParamField path="stack_id" type="string" required>
  El ID del stack.
</ParamField>

<ParamField query="workspace_id" type="string">
  El workspace al que pertenece el stack, cuando actúas sobre él como propietario del workspace.
</ParamField>

### Respuesta

La cuota y las comprobaciones de **todos** los miembros se hacen antes del `202`: si un miembro no puede tener snapshot (sin cuota, plan sin snapshots manuales, restauración o despliegue en curso), la solicitud responde con el error de ese miembro, no se inicia nada y la cuota usada se devuelve. Consulta [Crear snapshot de aplicación](/es-es/api-reference/endpoint/apps/snapshots/create) para esos códigos.

Sigue cada `job_id` en [Obtener job de snapshot](/es-es/api-reference/endpoint/apps/snapshots/jobs/get) (`GET /v1/users/{id}/snapshots/jobs/{job_id}`, donde `{id}` es el `resource_id` del job) hasta que su `status` sea `ready` o `failed`. El `id` de la snapshot del stack aparece en [Listar snapshots del stack](/es-es/api-reference/endpoint/stacks/snapshots/list) como `pending` y pasa a `ready` cuando todos los jobs están `ready`; solo entonces puede restaurarse. Si un miembro falla, la snapshot del stack no se lista, y las snapshots de los miembros que salieron bien siguen en sus listas como snapshots comunes.

### Errores

| Status | Código | Cuándo |
|---|---|---|
| 403 | `PLAN_NOT_ALLOWED` | El plan no incluye snapshots manuales. |
| 403 | `WORKSPACE_OWNER_ONLY` | Eres miembro del workspace, no el propietario. |
| 404 | `STACK_NOT_FOUND` | El stack no se encontró. |
| 404 | `STACK_MEMBER_NOT_FOUND` | El stack no tiene aplicación ni base de datos. |
| 409 | `OPERATION_IN_PROGRESS` | Ya hay una snapshot de este stack en curso. |
| 429 | `SNAPSHOT_RATE_LIMITED` | Un miembro no tiene cuota de snapshots manuales o tuvo una snapshot hace menos de 3 minutos. |
