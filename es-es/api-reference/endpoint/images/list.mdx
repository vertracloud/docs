{/* @see APICustomImage[], RESTGetAPICustomImagesResult — @vertracloud/api-types */}
Requiere el scope `images:read` cuando se llama con una clave de API.

<ParamField query="workspace_id" type="string">
  Lista las imágenes de ese workspace en lugar de las propias de la cuenta.
</ParamField>

### Response

<ResponseField name="response" type="array">
  Un array de imágenes.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    El ID de la imagen.
  </ResponseField>

  <ResponseField name="name" type="string">
    El nombre de la imagen.
  </ResponseField>

  <ResponseField name="description" type="string | null">
    La descripción de la imagen (texto libre, de hasta 128 caracteres), o `null` si no tiene ninguna.
  </ResponseField>

  <ResponseField name="owner" type="string">
    `account` para tus imágenes, `system` para las imágenes que proporciona la plataforma (estas no se pueden modificar ni eliminar).
  </ResponseField>

  <ResponseField name="kind" type="string">
    `own` para una imagen que construiste tú, o `template_copy` para la copia de la imagen de una plantilla que [usar una plantilla](/es-es/templates/use/using-a-template) dejó en tu cuenta. Una copia ocupa un hueco de imagen y solo se puede usar a través de su plantilla.
  </ResponseField>

  <ResponseField name="origin" type="object | null">
    En el caso de un `template_copy`, la plantilla de la que procede: `template_id`, `template_name` (por idioma) y `author_display` (`null` para una plantilla de la plataforma). `null` para tus propias imágenes.
  </ResponseField>

  <ResponseField name="status" type="string">
    Estado del último build: `building`, `success` o `failed`. Una reconstrucción fallida no cambia la versión actual: las aplicaciones siguen ejecutando la última que funcionó.
  </ResponseField>

  <ResponseField name="error" type="string | null">
    Motivo legible del último build fallido, o `null`.
  </ResponseField>

  <ResponseField name="digest" type="string | null">
    Digest (`sha256:...`) de la versión actual, o `null` mientras ningún build haya tenido éxito.
  </ResponseField>

  <ResponseField name="uncompressed_bytes" type="integer | null">
    Tamaño de la versión actual, sin comprimir, en bytes.
  </ResponseField>

  <ResponseField name="layer_count" type="integer | null">
    Número de capas de la versión actual.
  </ResponseField>

  <ResponseField name="suggested_port" type="integer | null">
    Puerto sugerido para una aplicación nueva sobre esta imagen: el primer `EXPOSE` del `Dockerfile` del contexto de build más reciente, o `80`. `null` en el caso de una imagen creada antes de que existiera este campo.
  </ResponseField>

  <ResponseField name="apps" type="object[]">
    Las aplicaciones creadas a partir de esta imagen. Cada una tiene `id`, `name`, `version_id` (la versión de la imagen que ejecuta, o `null`) y `outdated` (`true` cuando la imagen tiene una versión más nueva; la aplicación pasa a ella en el siguiente reinicio o despliegue que pidas).
  </ResponseField>

  <ResponseField name="github" type="object | null">
    El repositorio y la rama de GitHub vinculados (`repository` como `owner/name`, `branch`), o `null` si la imagen no está vinculada.
  </ResponseField>

  <ResponseField name="current_version_id" type="string | null">
    La versión actual de la imagen, o `null` mientras ningún build haya tenido éxito.
  </ResponseField>

  <ResponseField name="created_at" type="string" format="date-time">
    Cuándo se creó la imagen.
  </ResponseField>

  <ResponseField name="updated_at" type="string" format="date-time">
    Cuándo se actualizó por última vez la imagen.
  </ResponseField>

  </Expandable>
</ResponseField>

### Error Responses

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `API_KEY_SCOPE_DENIED`: La clave de API no tiene el scope necesario (`403`).
  - `INTERNAL_SERVER_ERROR`: Fallo inesperado (`500`).
</ResponseField>

<ResponseExample>

```json Error Response
{
  "code": "API_KEY_SCOPE_DENIED"
}
```

</ResponseExample>
