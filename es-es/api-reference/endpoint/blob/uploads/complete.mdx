{/* @see RESTPostAPIBlobUploadCompleteResponse, APIBlobObject — @vertracloud/api-types */}

Completa una subida directa. La API comprueba que todas las partes están almacenadas, que el tamaño total coincide, que el checksum coincide si lo enviaste y que el contenido no es un ejecutable. Después crea el objeto y lo devuelve. Hasta que esta llamada se realiza con éxito, el objeto no existe.

**Ámbito:** `blob:write`. Acepta un token de subida.

**Token de subida:** esta ruta también acepta un token de subida (`Authorization: Bearer vcup_...`) en lugar de una clave de API.

<ParamField path="upload_id" type="string" required>
  El ID de la subida.
</ParamField>

<ParamField query="workspace_id" type="string">
  El ID del workspace, cuando el blob pertenece a un workspace. La llamada actúa sobre el blob del propietario del workspace y necesita el permiso de workspace `blob:read` (`blob:manage` en las rutas que modifican datos). Omítelo para actuar sobre tu propio blob.
</ParamField>

### Ejemplo de petición

```bash
curl -X POST "https://blob.vertracloud.app/v1/uploads/7c1d2e3f-4a5b-4c6d-8e7f-0a1b2c3d4e5f/complete" \
  -H "Authorization: Bearer $VERTRA_API_KEY"
```

### Respuesta

<ResponseField name="response" type="object">
  El objeto Blob creado.
  <Expandable title="propiedades">
  <ResponseField name="id" type="string">ID estable del objeto. Nunca cambia, aunque cambien la ruta, la visibilidad o la caducidad.</ResponseField>
  <ResponseField name="path" type="string">Ruta completa dentro de la cuenta, por ejemplo `images/avatars/joao.png`.</ResponseField>
  <ResponseField name="size" type="number">Tamaño en bytes.</ResponseField>
  <ResponseField name="content_type" type="string">Tipo MIME, deducido en el servidor a partir de la extensión del archivo.</ResponseField>
  <ResponseField name="etag" type="string">Etiqueta de entidad del contenido almacenado.</ResponseField>
  <ResponseField name="sha256" type="string | null">SHA-256 del contenido en hexadecimal, cuando la subida envió un checksum. `null` en caso contrario.</ResponseField>
  <ResponseField name="visibility" type="string">`public` (se puede leer mediante su URL pública) o `private` (necesita un enlace temporal o un enlace para compartir).</ResponseField>
  <ResponseField name="url" type="string | null">URL pública. `null` mientras el objeto sea privado.</ResponseField>
  <ResponseField name="cache_control" type="string | null">`immutable`, `max-age=<seconds>` o `no-cache` (`no-cache` requiere Enterprise-26 o superior). `null` significa el valor por defecto.</ResponseField>
  <ResponseField name="content_disposition" type="string">`inline` (lo muestra el navegador) o `attachment` (se descarga). HTML, SVG y XML siempre son `attachment`.</ResponseField>
  <ResponseField name="filename" type="string | null">Nombre sugerido al descargar. `null` usa el último segmento de `path`.</ResponseField>
  <ResponseField name="metadata" type="object">Hasta 5 claves, cada una `[a-z0-9-]{1,64}`, 512 bytes en total. Enterprise-12 o superior; `{}` en los demás planes.</ResponseField>
  <ResponseField name="expires_at" type="string | null">Momento en que el objeto se elimina, como marca de tiempo ISO 8601. `null` significa que no caduca.</ResponseField>
  <ResponseField name="created_at" type="string">Fecha de creación en ISO 8601.</ResponseField>
  <ResponseField name="updated_at" type="string">Fecha ISO 8601 del último cambio.</ResponseField>
  </Expandable>
</ResponseField>

### Respuestas de error

<ResponseField name="code" type="string">
  El código de error que indica el motivo del fallo. Valores posibles:
  - `AUTH_TOKEN_MISSING` (`401`): No se envió la cabecera `Authorization`.
  - `API_KEY_INVALID` (`401`): La clave de API no existe, fue revocada o su secreto no coincide.
  - `API_KEY_SCOPE_DENIED` (`403`): La clave no tiene el ámbito que necesita esta ruta (`blob:read` o `blob:write`); `details.required` lo indica.
  - `WORKSPACE_PERMISSION_DENIED` (`403`): Solo con `workspace_id`: no eres miembro o tu rol no tiene el permiso de blob.
  - `WORKSPACE_NOT_FOUND` (`404`): Solo con `workspace_id`: no existe ningún workspace con ese ID o no eres miembro.
  - `BLOB_UPLOAD_TOKEN_INVALID` (`401`): El token de subida no existe, ha caducado o fue revocado (solo con un token de subida).
  - `BLOB_UPLOAD_NOT_FOUND` (`404`): No hay ninguna subida con ese ID en esta cuenta, o ya se completó o se canceló.
  - `BLOB_UPLOAD_EXPIRED` (`410`): Se superó el tiempo límite de la subida. Inicia una nueva subida.
  - `BLOB_UPLOAD_INCOMPLETE` (`409`): Faltan partes, o el tamaño almacenado no coincide con el `size` declarado.
  - `BLOB_CHECKSUM_MISMATCH` (`400`): El contenido almacenado no coincide con el `checksum_sha256` enviado al inicio.
  - `BLOCKED_FILE_TYPE` (`422`): El contenido es un ejecutable, detectado por sus bytes.
  - `BLOB_OBJECT_ALREADY_EXISTS` (`409`): Otro objeto ocupó `path` mientras la subida estaba en curso, y `overwrite` no es `true`.
</ResponseField>
