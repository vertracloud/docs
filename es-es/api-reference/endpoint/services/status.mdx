title: Comprobar el estado de la infraestructura
sidebarTitle: Comprobar estado
api: GET https://api.vertracloud.app/v1/status
authMethod: none
description: Comprueba si la infraestructura está completamente operativa.
---

{/* @see APIStatus — @vertracloud/api-types */}
### Response

<ResponseField name="status" type="string">
  Indica el estado actual de la infraestructura. Valores posibles: `healthy`,
  `unknown`, `degraded`.
</ResponseField>

<ResponseField name="response" type="string">
  Un mensaje que describe el estado de la infraestructura. Valores posibles: `All systems
  operational`, `Some systems are degraded`, `Some systems are down`.
</ResponseField>

<ResponseExample>

```json Response
{
  "status": "healthy",
  "response": "All systems operational"
}
```

</ResponseExample>
