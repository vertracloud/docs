## ¿Qué es Vertra Cloud?

Vertra Cloud es una plataforma brasileña de alojamiento de aplicaciones (PaaS): despliegue desde GitHub o desde un archivo zip,
contenedores aislados, bases de datos gestionadas, almacenamiento de archivos, snapshots, una CLI y una extensión de VS Code.
Los bots de Discord, WhatsApp y Telegram son cargas de trabajo de primera clase. Tú escribes el código; la plataforma
construye la imagen, ejecuta el contenedor, enruta el subdominio y guarda los snapshots.

Esta es la documentación oficial: cómo desplegar, qué incluye cada plan, cómo funcionan las bases de datos
gestionadas y la referencia completa de la API REST pública.

## ¿Qué puedes ejecutar en Vertra Cloud?

Aplicaciones en 13 runtimes, cuatro motores de bases de datos gestionadas, sitios estáticos y dinámicos, y
workers en segundo plano, como los bots, cada uno en su propio contenedor, con memoria y almacenamiento dedicados.
