## Requisitos

- Node.js instalado en local
- Cuenta en [Vertra Cloud](https://vertracloud.app)

## Estructura del proyecto

```
my-api/
├── src/
│   ├── index.js
│   ├── routes/
│   │   └── users.js
│   └── middleware/
│       └── auth.js
├── package.json
└── vertracloud.config
```

## Configuración

### package.json

```json
{
  "name": "my-api",
  "version": "1.0.0",
  "main": "src/index.js",
  "scripts": {
    "start": "node src/index.js"
  },
  "dependencies": {
    "express": "^4.18.0",
    "cors": "^2.8.5",
    "dotenv": "^16.3.0"
  }
}
```

### vertracloud.config

```ini
MAIN=src/index.js
START=npm start
VERSION=recommended
```

## Ejemplo completo

```javascript
const express = require('express');
const cors = require('cors');

const app = express();
const port = process.env.PORT || 80;

app.use(cors());
app.use(express.json());

app.get('/', (req, res) => {
  res.json({ message: 'API online on Vertra Cloud' });
});

app.get('/health', (req, res) => {
  res.json({ status: 'healthy', uptime: process.uptime() });
});

app.get('/api/users', (req, res) => {
  res.json({ users: [] });
});

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).json({ error: 'Internal server error' });
});

app.listen(port, '0.0.0.0', () => {
  console.log(`API running on port ${port}`);
});
```

<Warning>
  Usa siempre `'0.0.0.0'` como host en `app.listen()`. El enlace predeterminado a `localhost` no acepta conexiones externas dentro del contenedor.
</Warning>

## Deploy

<Tabs>
  <Tab title="Dashboard">
    1. Comprime el proyecto en un `.zip` (las carpetas como `node_modules`, `venv` y `target` se eliminan automáticamente) o súbelo a GitHub.
    2. En el panel, haz clic en **Nuevo Proyecto** y sube el `.zip` o pega la URL del repositorio.
    3. En **Build**, revisa el runtime (**JavaScript**), el archivo principal (`index.js`) y la memoria. Los comandos de inicio y de build están en **Ajustes avanzados**.
    4. Añade tus variables de entorno en **Variables de Entorno**.
    5. En **Red**, activa la **publicación web** para que la aplicación reciba una dirección `*.vertraweb.app` (plan Pro o superior, 512 MB de memoria). La aplicación debe escuchar en el puerto 80.
    6. Revisa y despliega. Sigue la salida en la pestaña **Logs**.
  </Tab>
  <Tab title="CLI">
    ```bash
    vertra upload
    vertra logs -f
    ```
    Consulta la [CLI](/es-es/cli) para la instalación y el inicio de sesión.
  </Tab>
  <Tab title="VS Code">
    Abre la carpeta con la extensión de Vertra Cloud instalada y ejecuta **Deploy current project**. Consulta la [extensión de VS Code](/es-es/vscode-extension).
  </Tab>
</Tabs>

La guía completa está en [Primer despliegue](/es-es/how-to-host).

## Conexión a una base de datos

Las bases de datos de Vertra exigen TLS **y** el certificado de cliente. Coloca en tu proyecto los tres archivos de la pestaña
**Certificados** de la base de datos y léelos al abrir el pool:

```javascript
const fs = require('fs');
const { Pool } = require('pg');

const pool = new Pool({
  host: process.env.DB_HOST,
  port: Number(process.env.DB_PORT), // única por base de datos, cópiala desde el panel
  user: 'postgres',
  password: process.env.DB_PASSWORD,
  database: 'postgres',
  ssl: {
    ca: fs.readFileSync('certificate.pem'),
    cert: fs.readFileSync('certificate.crt'),
    key: fs.readFileSync('certificate.key'),
    rejectUnauthorized: true,
  },
});
```

Los ejemplos de MongoDB, Redis y MySQL están en [¿Cómo me conecto a cada motor?](/es-es/databases#cómo-me-conecto-a-cada-motor).

## Notas

- En aplicaciones **TypeScript**, compila antes del despliegue y apunta `MAIN` al archivo `.js` compilado
- Usa **variables de entorno** para la configuración de la base de datos y los secretos
- El **reinicio automático** está activado por defecto en todas las aplicaciones
- Configura un endpoint `/health` para la monitorización
