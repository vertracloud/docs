La API de Blob Storage está en `https://blob.vertracloud.app/v1` y usa la misma clave de API de la plataforma, en el header `Authorization: Bearer`. La referencia de cada endpoint está en inglés, igual para todos los idiomas.

Antes de llamar a la API, consulta [Autenticación](/es-es/blob/authentication) para ver los alcances y los tokens de subida.
