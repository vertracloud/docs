Vertra Cloud publica ocho plantillas oficiales: n8n, OpenClaw, Hermes Agent, Evolution API, Open WebUI, Uptime Kuma y un starter de bot de Discord en JavaScript y otro en Python. Abre **Plantillas** en el panel para verlas en la galería con tu memoria libre y tus cupos de imagen, ejecuta `vertra template list` o consulta la [galería pública](https://vertracloud.app/templates), que no exige cuenta. Cada una pide solo lo que necesita y genera sus propios secretos.

Todas tienen la insignia **Vertra**. Los seis que ejecutan una imagen necesitan un plan con imágenes Docker y un cupo de imagen libre cada uno; los dos bots de Discord se ejecutan en un runtime de lenguaje y no usan cupo. Consulta [Qué son las plantillas](/es-es/templates/overview) para saber cómo se calcula el plan necesario y [Planes y límites](/es-es/plans-and-limits) para los números.

## Agentes y asistentes de IA

| Plantilla | Qué es | Qué crea |
|---|---|---|
| [**OpenClaw**](/es-es/templates/catalog/openclaw) | Asistente personal de IA con navegador, panel de control y canales (Telegram, Discord, Slack, WhatsApp). Tú aportas tu propia clave de modelo. | Una app (imagen). |
| [**Hermes Agent**](/es-es/templates/catalog/hermes-agent) | Agente de IA que aprende con el uso, con un panel, un chat en el navegador y canales (Telegram, Discord, Slack, WhatsApp). | Una app (imagen). |
| [**Open WebUI**](/es-es/templates/catalog/open-webui) | Una interfaz de chat con IA para tu equipo. Tú aportas tu propia clave de modelo. | Una app (imagen), más una base de datos Postgres si eliges almacenamiento gestionado. |

## Automatización y APIs

| Plantilla | Qué es | Qué crea |
|---|---|---|
| [**n8n**](/es-es/templates/catalog/n8n) | Automatización visual de flujos de trabajo con nodos Code en Python y JavaScript, workers y community nodes. | Una app, o un stack con Postgres, y Postgres, Redis y un worker si escalas con workers (imagen). |
| [**Evolution API**](/es-es/templates/catalog/evolution-api) | API de WhatsApp con instancias, webhooks e integraciones. | Un stack con la app y una base de datos Postgres, y Redis si lo eliges como caché (imagen). |

## Monitorización

| Plantilla | Qué es | Qué crea |
|---|---|---|
| [**Uptime Kuma**](/es-es/templates/catalog/uptime-kuma) | Monitoriza sitios y servicios con alertas y una página de estado. Tus datos se quedan en tu app. | Una app (imagen). |

## Bots

| Plantilla | Qué es | Qué crea |
|---|---|---|
| [**Discord bot (JavaScript)**](/es-es/templates/catalog/discord-bot-js) | Un bot de Discord con discord.js y un comando `/ping`, un punto de partida para tu bot. | Una app (código), sin web. |
| [**Discord bot (Python)**](/es-es/templates/catalog/discord-bot-python) | Un bot de Discord con discord.py y un comando `/ping`, un punto de partida para tu bot. | Una app (código), sin web. |

El código de las plantillas de bots de Discord es tuyo para editarlo; al editarlo, la app se desvincula de la plantilla y deja de recibir nuevas versiones. Las plantillas que ejecutan una imagen no tienen código editable: cambias su memoria y las respuestas a sus preguntas.

## Guías paso a paso

n8n, OpenClaw y Hermes Agent tienen cada uno una guía dedicada, desde la primera pantalla hasta una configuración que funciona: [n8n](/es-es/templates/guides/n8n), [OpenClaw](/es-es/templates/guides/openclaw) y [Hermes Agent](/es-es/templates/guides/hermes-agent). Cada plantilla tiene además su propia página en esta sección, con lo que crea, las preguntas que hace y sus variables.

## Dónde verlas

La galería está en el panel, en **Plantillas**, donde muestra cuáles encajan con tu plan; la [galería pública](https://vertracloud.app/templates) las lista para todo el mundo. Para usar una, sigue [Usar una plantilla](/es-es/templates/use/using-a-template). Para publicar las tuyas, consulta [Crear plantillas](/es-es/templates/create/overview).
