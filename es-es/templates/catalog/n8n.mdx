Automatización visual de workflows. La plantilla ejecuta n8n 2.44.7 con el nodo Code en **JavaScript y Python** en el mismo contenedor, un worker opcional en modo cola y nodos de la comunidad.

<Card title="Guía paso a paso: n8n de cero a tu primer workflow" icon="book-open" href="/es-es/templates/guides/n8n">
  Elige el modo, crea el propietario, webhooks, Python y JavaScript, SMTP, credenciales, copias de seguridad y rollback.
</Card>

## Qué crea

| Modo | Crea | Memoria |
|---|---|---|
| **Managed Postgres** (predeterminado) | La aplicación n8n y un Postgres gestionado. | 2 GB |
| **Built-in SQLite** | Solo la aplicación n8n. | 1 GB |
| **Scale with workers** | La aplicación n8n, un worker, Postgres y Redis. | 3,5 GB |

Es una plantilla de imagen: necesita un plan con imágenes Docker y un [cupo de imagen](/es-es/templates/overview#cupos-de-imagen) libre. Consulta [Planes y límites](/es-es/plans-and-limits).

## Qué pregunta el asistente

| Pregunta | Qué hace |
|---|---|
| How will n8n run? | El modo de arriba. |
| Parallel executions on the worker | Solo con workers. Predeterminado 5. |
| Schedule time zone | America/Sao_Paulo, UTC, America/New_York o Europe/Lisbon. |
| Modules allowed in the Code node | **Safe** (predeterminado) o **All**. |
| Send n8n emails? | SMTP opcional para invitaciones y restablecimiento de contraseña. |

## Qué obtienes

La dirección de la aplicación y el siguiente paso: ábrela y crea de inmediato la cuenta de **propietario**. Los secretos (la clave de cifrado y el token de los runners) se generan por ti.

## Variables

| Variable | Qué hace |
|---|---|
| `N8N_ENCRYPTION_KEY` | Cifra las credenciales; guarda una copia. No la cambies nunca en una aplicación en ejecución. |
| `N8N_WEBHOOK_URL`, `N8N_EDITOR_BASE_URL`, `N8N_HOST` | La dirección pública de la aplicación. |
| `VERTRA_CODE_MODULES` | `safe` o `all`: los módulos que el nodo Code puede importar. |
| `GENERIC_TIMEZONE`, `TZ` | Zona horaria de las programaciones. |
| `EXECUTIONS_DATA_MAX_AGE`, `EXECUTIONS_DATA_PRUNE_MAX_COUNT` | Retención del historial: 168 horas y 5.000 ejecuciones. |
| `N8N_WORKER_CONCURRENCY` | Ejecuciones en paralelo en el worker (modo con workers). |
| `N8N_SMTP_*`, `N8N_EMAIL_MODE` | Correo para invitaciones y restablecimiento de contraseña. |

## Recursos y límites

- Puerto 5678; primer arranque de 25 a 60 segundos. Uso de memoria del editor de unos 300 a 540 MiB, del worker de 330 a 560 MiB.
- Datos en `/app/.n8n`; nodos de la comunidad en `/app/.n8n/nodes`.
- Un worker como máximo; el despliegue sin caída está desactivado; el rollback devuelve también los datos.
- El historial de ejecuciones se borra a los 7 días o a las 5.000 ejecuciones.
