Un asistente personal de IA con panel de control, canales de mensajería y un navegador opcional. La plantilla ejecuta OpenClaw 2026.10.7 con Chromium headless dentro del contenedor. Tú traes la clave del modelo: Vertra Cloud no aloja un modelo.

## Qué crea

Una aplicación (imagen) con el panel en la dirección de la aplicación. **Memoria: 3 GB como mínimo con el navegador** (4 GB recomendados) o 2 GB sin él (3 GB recomendados). Necesita un plan con imágenes Docker y un [cupo de imagen](/es-es/templates/overview#cupos-de-imagen) libre; consulta [Planes y límites](/es-es/plans-and-limits).

## Qué pregunta el asistente

| Pregunta | Qué hace |
|---|---|
| Model provider | OpenAI, Anthropic, Google Gemini, OpenRouter o un endpoint compatible con OpenAI. |
| Provider API key | Se guarda solo en las variables cifradas de la aplicación. |
| Endpoint base URL | Solo con un endpoint compatible; termina en `/v1`. |
| Model (optional) | Vacío significa el predeterminado del proveedor; obligatorio con un endpoint compatible. |
| Can the assistant use a browser? | Sí (predeterminado) o no. Se aplica en el primer arranque. |
| Telegram, Discord, Slack | Token y quién puede hablar con el bot. Sin una lista de autorizados el canal no se activa. |

## Qué obtienes

La dirección de la aplicación, el **token del gateway** (mostrado una sola vez) y el siguiente paso. WhatsApp se empareja con un código QR en el panel.

## Variables

| Variable | Qué hace |
|---|---|
| `OPENCLAW_GATEWAY_TOKEN` | La credencial del panel. |
| `PUBLIC_ORIGIN` | La dirección pública de la aplicación. |
| `OPENCLAW_PROVIDER`, `OPENCLAW_MODEL`, `OPENCLAW_MODEL_ID` | Proveedor y modelo, recalculados en cada arranque. |
| `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, `OPENAI_COMPAT_API_KEY` | La clave del proveedor elegido; `OPENAI_COMPAT_BASE_URL` guarda el endpoint compatible. |
| `OPENCLAW_BROWSER` | `on` u `off`. |
| `OPENCLAW_BOOTSTRAP_PAIRING` | `off` desactiva la aprobación automática del primer navegador. |

## Recursos y límites

- Puerto 18789. Primer arranque de 30 a 45 segundos, y de 1 a 3 minutos con Discord o Slack.
- Estado en `/app/.openclaw`; los plugins de canales desde npm añaden unos 240 MB.
- El despliegue sin caída está desactivado; el rollback devuelve también los datos.
- El navegador del agente bloquea las redes privadas y locales.
