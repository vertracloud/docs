Un agente de IA que aprende con el uso, con un panel web, un chat opcional en el navegador y canales de mensajería. La plantilla ejecuta Hermes Agent v0.22.5 tras un único inicio de sesión. Tú traes la clave del modelo: Vertra Cloud no aloja un modelo.

## Qué crea

Una aplicación (imagen). **Memoria: 1,5 GB como mínimo**, 2 GB recomendados. Necesita un plan con imágenes Docker y un [cupo de imagen](/es-es/templates/overview#cupos-de-imagen) libre; consulta [Planes y límites](/es-es/plans-and-limits).

## Qué pregunta el asistente

| Pregunta | Qué hace |
|---|---|
| Model provider | OpenRouter (predeterminado), Anthropic, OpenAI, Google Gemini o un endpoint compatible con OpenAI. |
| Provider API key | Se guarda solo en las variables cifradas de la aplicación. |
| Base URL and model | La URL solo con un endpoint compatible (termina en `/v1`). Modelo vacío significa el predeterminado del proveedor; obligatorio con un endpoint compatible. |
| Browser chat (Hermes WebUI) | Opcional; unos 150 MB más de memoria. |
| Telegram, Discord, Slack, WhatsApp, email | Cada uno pide credenciales y la **lista de personas autorizadas a hablar con el agente**. |

## Qué obtienes

El panel en `<address>/admin/`, el usuario `admin` y una **contraseña** generada **mostrada una sola vez**, y el siguiente paso. WhatsApp se empareja con un código QR en el panel.

## Variables

| Variable | Qué hace |
|---|---|
| `HERMES_ADMIN_USER`, `HERMES_ADMIN_PASSWORD` | El único inicio de sesión (`admin` y la contraseña generada). |
| `HERMES_WEBUI` | `true` o `false`: el chat en el navegador. |
| `HERMES_MODEL_PROVIDER`, `HERMES_MODEL`, `HERMES_MODEL_CUSTOM`, `HERMES_BASE_URL` | Proveedor y modelo, aplicados en cada arranque. |
| `OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`, `OPENAI_COMPAT_API_KEY` | La clave del proveedor elegido. |
| `TELEGRAM_*`, `DISCORD_*`, `SLACK_*`, `WHATSAPP_*`, `EMAIL_*` | Las credenciales y la lista de autorizados de cada canal. |

## Recursos y límites

- Puerto 8080. Primer arranque de 15 a 30 segundos; los siguientes, unos 15 segundos.
- Estado en `/app/.hermes`. La imagen es grande, así que el primer despliegue tarda más.
- El despliegue sin caída está desactivado; el rollback devuelve también el estado.
- Un token de canal no válido aparece en el log de la aplicación: no lo compartas.
