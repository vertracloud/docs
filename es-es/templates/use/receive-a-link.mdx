Un enlace para compartir una plantilla permite que alguien te dé una plantilla privada sin publicarla. Ábrela, lee la vista previa y, si confías en el autor, crea la aplicación o el stack a partir de ella. La plantilla **no está verificada por Vertra**: viene de una persona, no del catálogo.

Necesitas una cuenta para crear cualquier cosa desde un enlace. La vista previa se abre sin iniciar sesión.

## La vista previa

Antes de crear nada, la página del enlace muestra:

- el autor;
- qué se creará (los servicios y la memoria total);
- el plan requerido y el cupo de imagen que usará;
- la insignia **No verificado por Vertra**;
- si el código es cerrado, un aviso: los valores que rellenas (por ejemplo, tu clave del proveedor de modelos) van a código que no puedes ver, y estás confiando en el autor.

Continúa solo si confías en quien te envió el enlace. Consulta [Plantillas cerradas](/es-es/templates/use/closed-templates).

## Dos tipos de enlace

El autor elige el tipo al crear el enlace.

| | Enlace de uso (por defecto) | Enlace de copia completa |
|---|---|---|
| Qué obtienes | Aplicaciones o un stack creados a partir de la plantilla, con tu propia copia de la imagen. | Una plantilla privada tuya: manifiesto, código, Dockerfile e imagen. |
| Código | Abierto o cerrado, según decidió el autor. | Siempre visible. |
| Actualizaciones del autor | Sí, cuando pulsas **Actualizar**. | No: tu copia es independiente. |
| Cupo de imagen | Uno. | Uno. |
| Cuenta contra | Los requisitos de la receta. | Tu límite de plantillas privadas, además de la receta. |

## La copia de la imagen y tu cupo

Cuando una plantilla de enlace ejecuta una imagen, la plataforma crea un registro de imagen **en tu cuenta**: una copia de la imagen, de modo que no se reconstruye nada y no recibes ningún Dockerfile ni contexto de build. Usa **un cupo de imagen** de tu cuenta (consulta [Cupos de imagen](/es-es/templates/overview#cupos-de-imagen)); el autor conserva el suyo. La copia aparece en tu lista de imágenes como, por ejemplo, "Bot X (from Agency Y)".

Como la imagen es tuya, si el autor elimina después la imagen, la plantilla o su cuenta, no cambia nada para lo que has creado. El enlace deja de funcionar, pero tus copias siguen ejecutándose.

**Actualizar** copia la nueva versión a tu cuenta, siempre que el enlace y la plantilla sigan existiendo.

## Revocación

El autor puede **revocar** el enlace: no es posible ningún uso nuevo y no se ofrecen más actualizaciones. Lo que ya creaste sigue siendo tuyo y sigue ejecutándose. El autor nunca puede detener, eliminar ni leer nada de tu cuenta.

Un enlace también puede caducar, agotar sus usos o ser revocado, y la página indica cuál es el caso:

| Mensaje | Significado |
|---|---|
| `SHARE_LINK_NOT_FOUND` | El enlace no existe, o su plantilla fue retirada. |
| `SHARE_LINK_REVOKED` | El autor revocó el enlace. |
| `SHARE_LINK_EXPIRED` | El enlace superó su validez. |
| `SHARE_LINK_EXHAUSTED` | El enlace alcanzó su número máximo de usos. |

## Denunciar una plantilla

Una plantilla de enlace es una forma de distribuir el código de otra persona sin revisión, por lo que cada vista previa y cada aplicación creada a partir de una plantilla tiene un botón **Denunciar**. Elige un motivo (código malicioso, estafa o fraude, derechos de autor, secreto filtrado u otro), añade detalles de hasta 1000 caracteres sin contraseñas ni datos personales y envía. El equipo de Vertra lo revisa y al autor no se le dice quién denunció.

Para casos graves, o si tienes pruebas, escribe también a [abuse@vertracloud.app](mailto:abuse@vertracloud.app). Vertra Cloud puede revocar un enlace o una plantilla y, en caso de malware, detener todas las copias, aplicando sus términos de uso.

## Crear desde el enlace

Abre el enlace y avanza por el asistente, que funciona como el de [cualquier plantilla](/es-es/templates/use/using-a-template). En la CLI, usa `vertra template deploy --share <link-or-token> --name my-app`. Un enlace de copia completa da una plantilla, no un despliegue, así que la CLI lo rechaza para `deploy`.

Para la API, consulta [Preview a share link](/es-es/api-reference/endpoint/templates/share-links/preview), [Deploy from a share link](/es-es/api-reference/endpoint/templates/share-links/deploy), [Copy a template](/es-es/api-reference/endpoint/templates/share-links/copy) y [Report](/es-es/api-reference/endpoint/templates/share-links/report). Para crear tus propios enlaces, consulta [Enlaces para compartir](/es-es/templates/create/share-links).
