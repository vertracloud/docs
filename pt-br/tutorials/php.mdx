## Requisitos

- PHP 8.2+ instalado localmente
- Composer para gerenciamento de dependências
- Conta na [Vertra Cloud](https://vertracloud.app)

## Estrutura do projeto

```
my-api-php/
├── src/
│   └── routes.php
├── vendor/
├── public/
│   ├── index.php
│   └── .htaccess
├── composer.json
└── vertracloud.config
```

## Configuração

### composer.json

```json
{
  "name": "example/my-api-php",
  "description": "PHP API on Vertra Cloud",
  "type": "project",
  "require": {
    "php": ">=8.2",
    "illuminate/http": "^10.0",
    "guzzlehttp/guzzle": "^7.5"
  },
  "require-dev": {
    "phpunit/phpunit": "^10.0"
  },
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  },
  "scripts": {
    "start": "php -S 0.0.0.0:${PORT:-8000} -t public"
  }
}
```

<Note>
  A plataforma executa `composer install` automaticamente. Não inclua a pasta `vendor` no envio.
</Note>

### vertracloud.config

```ini
MAIN=public/index.php
START=php -S 0.0.0.0:$PORT -t public
VERSION=recommended
```

## Exemplo: API REST simples

### public/index.php

```php
<?php
header('Content-Type: application/json');

function json_response($data, $status = 200) {
    http_response_code($status);
    echo json_encode($data);
    exit;
}

if ($_SERVER['REQUEST_URI'] === '/' && $_SERVER['REQUEST_METHOD'] === 'GET') {
    json_response([
        'message' => 'API PHP on Vertra Cloud',
        'version' => '1.0.0'
    ], 200);
}

if ($_SERVER['REQUEST_URI'] === '/health' && $_SERVER['REQUEST_METHOD'] === 'GET') {
    json_response([
        'status' => 'healthy',
        'service' => 'php-api'
    ], 200);
}

json_response(['error' => 'Not found'], 404);
?>
```

## Deploy

<Tabs>
  <Tab title="Painel">
    1. Compacte o projeto em um `.zip` (pastas como `node_modules`, `venv` e `target` são removidas automaticamente) ou envie para o GitHub.
    2. No painel, clique em **Novo Projeto** e envie o `.zip` ou cole a URL do repositório.
    3. Em **Build**, confira o runtime (**PHP**), o arquivo principal (`public/index.php`) e a memória. Os comandos de start e de build ficam em **Configurações Avançadas**.
    4. Adicione suas variáveis de ambiente em **Ambiente**.
    5. Em **Rede**, ative a **publicação web** para que a aplicação receba um endereço `*.vertraweb.app` (plano Pro ou superior, 512 MB de memória). A aplicação precisa escutar na porta 80.
    6. Revise e faça o deploy. Acompanhe a saída na aba **Logs**.
  </Tab>
  <Tab title="CLI">
    ```bash
    vertra upload
    vertra logs -f
    ```
    Veja [CLI](/pt-br/cli) para instalação e login.
  </Tab>
  <Tab title="VS Code">
    Abra a pasta com a extensão da Vertra Cloud instalada e execute **Fazer deploy do projeto atual**. Veja [Extensão do VS Code](/pt-br/vscode-extension).
  </Tab>
</Tabs>

O passo a passo completo está em [Primeiro deploy](/pt-br/how-to-host).

## Observações

- **Dependências**: use o Composer para gerenciar as dependências
- **Variáveis de ambiente**: acesse via `$_SERVER['...']` ou use bibliotecas como `vlucas/phpdotenv`
- **Logs**: escreva em stdout/stderr para que apareçam nos logs do painel
- **Sessões**: configure sessões em memória ou com Redis, se necessário
- **Segurança**: use `header('Content-Type: application/json')` em APIs
- Escute em `0.0.0.0` na porta `$PORT`
