## Requisitos

- Node.js instalado localmente
- Conta na [Vertra Cloud](https://vertracloud.app)

## Estrutura do projeto

```
my-api/
├── src/
│   ├── index.js
│   ├── routes/
│   │   └── users.js
│   └── middleware/
│       └── auth.js
├── package.json
└── vertracloud.config
```

## Configuração

### package.json

```json
{
  "name": "my-api",
  "version": "1.0.0",
  "main": "src/index.js",
  "scripts": {
    "start": "node src/index.js"
  },
  "dependencies": {
    "express": "^4.18.0",
    "cors": "^2.8.5",
    "dotenv": "^16.3.0"
  }
}
```

### vertracloud.config

```ini
MAIN=src/index.js
START=npm start
VERSION=recommended
```

## Exemplo completo

```javascript
const express = require('express');
const cors = require('cors');

const app = express();
const port = process.env.PORT || 80;

app.use(cors());
app.use(express.json());

app.get('/', (req, res) => {
  res.json({ message: 'API online on Vertra Cloud' });
});

app.get('/health', (req, res) => {
  res.json({ status: 'healthy', uptime: process.uptime() });
});

app.get('/api/users', (req, res) => {
  res.json({ users: [] });
});

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).json({ error: 'Internal server error' });
});

app.listen(port, '0.0.0.0', () => {
  console.log(`API running on port ${port}`);
});
```

<Warning>
  Sempre use `'0.0.0.0'` como host em `app.listen()`. O bind padrão em `localhost` não aceita conexões externas dentro do container.
</Warning>

## Deploy

<Tabs>
  <Tab title="Dashboard">
    1. Compacte o projeto em um `.zip` (pastas como `node_modules`, `venv` e `target` são removidas automaticamente) ou envie-o ao GitHub.
    2. No dashboard, clique em **Novo Projeto** e envie o `.zip` ou cole a URL do repositório.
    3. Em **Build**, confira o runtime (**JavaScript**), o arquivo principal (`index.js`) e a memória. Os comandos de start e build ficam em **Configurações avançadas**.
    4. Adicione suas variáveis de ambiente em **Variáveis de Ambiente**.
    5. Em **Rede**, ative a **publicação na web** para que a aplicação receba um endereço `*.vertraweb.app` (plano Pro ou superior, 512 MB de memória). A aplicação precisa escutar na porta 80.
    6. Revise e faça o deploy. Acompanhe a saída na aba **Logs**.
  </Tab>
  <Tab title="CLI">
    ```bash
    vertra upload
    vertra logs -f
    ```
    Veja a [CLI](/pt-br/cli) para instalação e login.
  </Tab>
  <Tab title="VS Code">
    Abra a pasta com a extensão da Vertra Cloud instalada e execute **Deploy current project**. Veja a [extensão do VS Code](/pt-br/vscode-extension).
  </Tab>
</Tabs>

O passo a passo completo está em [Primeiro deploy](/pt-br/how-to-host).

## Conectando a um banco de dados

Os bancos da Vertra Cloud exigem TLS **e** o certificado de cliente. Coloque os três arquivos da aba
**Certificados** do banco no seu projeto e leia-os ao abrir o pool:

```javascript
const fs = require('fs');
const { Pool } = require('pg');

const pool = new Pool({
  host: process.env.DB_HOST,
  port: Number(process.env.DB_PORT), // única por banco, copie-a do dashboard
  user: 'postgres',
  password: process.env.DB_PASSWORD,
  database: 'postgres',
  ssl: {
    ca: fs.readFileSync('certificate.pem'),
    cert: fs.readFileSync('certificate.crt'),
    key: fs.readFileSync('certificate.key'),
    rejectUnauthorized: true,
  },
});
```

Os exemplos de MongoDB, Redis e MySQL estão em [Como me conecto a cada motor?](/pt-br/databases#como-me-conecto-a-cada-motor).

## Observações

- Para aplicações **TypeScript**, compile antes do deploy e aponte `MAIN` para o arquivo `.js` compilado
- Use **variáveis de ambiente** para a configuração do banco e para segredos
- O **reinício automático** vem ativado por padrão em todas as aplicações
- Configure um endpoint `/health` para monitoramento
