Um assistente pessoal de IA com painel de controle, canais de mensagem e um navegador opcional. O template executa o OpenClaw 2026.10.7 com Chromium headless dentro do container. Você traz a chave do modelo: a Vertra Cloud não hospeda modelo.

## O que ele cria

Um app (imagem) com o painel no endereço do app. **Memória: 3 GB no mínimo com o navegador** (4 GB recomendado) ou 2 GB sem ele (3 GB recomendado). Exige um plano com imagens Docker e uma [vaga de imagem](/pt-br/templates/overview#vagas-de-imagem) livre; veja [Planos e limites](/pt-br/plans-and-limits).

## O que o assistente pergunta

| Pergunta | O que faz |
|---|---|
| Model provider | OpenAI, Anthropic, Google Gemini, OpenRouter ou um endpoint compatível com a OpenAI. |
| Provider API key | Guardada apenas nas variáveis criptografadas do app. |
| Endpoint base URL | Somente com um endpoint compatível; termina em `/v1`. |
| Model (optional) | Vazio significa o padrão do provedor; obrigatório com um endpoint compatível. |
| Can the assistant use a browser? | Yes (padrão) ou no. Vale a partir da primeira inicialização. |
| Telegram, Discord, Slack | Token e quem pode falar com o bot. Sem uma lista de permitidos, o canal não é ativado. |

## O que você recebe

O endereço do app, o **gateway token** (mostrado uma única vez) e o próximo passo. O WhatsApp é pareado por QR code no painel.

## Variáveis

| Variável | O que faz |
|---|---|
| `OPENCLAW_GATEWAY_TOKEN` | A credencial do painel. |
| `PUBLIC_ORIGIN` | O endereço público do app. |
| `OPENCLAW_PROVIDER`, `OPENCLAW_MODEL`, `OPENCLAW_MODEL_ID` | Provedor e modelo, recalculados a cada inicialização. |
| `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, `OPENAI_COMPAT_API_KEY` | A chave do provedor escolhido; `OPENAI_COMPAT_BASE_URL` guarda o endpoint compatível. |
| `OPENCLAW_BROWSER` | `on` ou `off`. |
| `OPENCLAW_BOOTSTRAP_PAIRING` | `off` desliga a aprovação automática do primeiro navegador. |

## Recursos e limites

- Porta 18789. Primeiro boot de 30 a 45 segundos, e de 1 a 3 minutos com Discord ou Slack.
- Estado em `/app/.openclaw`; os plugins dos canais vindos do npm somam cerca de 240 MB.
- O deploy sem downtime está desligado; o rollback devolve os dados também.
- O navegador do agente bloqueia redes privadas e locais.
