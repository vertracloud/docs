Um agente de IA que aprende com o uso, com painel web, chat opcional no navegador e canais de mensagem. O template executa o Hermes Agent v0.22.5 atrás de um único login. Você traz a chave do modelo: a Vertra Cloud não hospeda modelo.

## O que ele cria

Um app (imagem). **Memória: 1,5 GB no mínimo**, 2 GB recomendado. Exige um plano com imagens Docker e uma [vaga de imagem](/pt-br/templates/overview#vagas-de-imagem) livre; veja [Planos e limites](/pt-br/plans-and-limits).

## O que o assistente pergunta

| Pergunta | O que faz |
|---|---|
| Model provider | OpenRouter (padrão), Anthropic, OpenAI, Google Gemini ou um endpoint compatível com a OpenAI. |
| Provider API key | Guardada apenas nas variáveis criptografadas do app. |
| Base URL and model | A URL somente com um endpoint compatível (termina em `/v1`). Modelo vazio significa o padrão do provedor; obrigatório com um endpoint compatível. |
| Browser chat (Hermes WebUI) | Opcional; cerca de 150 MB de memória a mais. |
| Telegram, Discord, Slack, WhatsApp, email | Cada um pede credenciais e a **lista de pessoas autorizadas a falar com o agente**. |

## O que você recebe

O painel em `<address>/admin/`, o usuário `admin` e uma **senha gerada mostrada uma única vez**, e o próximo passo. O WhatsApp é pareado por QR code no painel.

## Variáveis

| Variável | O que faz |
|---|---|
| `HERMES_ADMIN_USER`, `HERMES_ADMIN_PASSWORD` | O login único (`admin` e a senha gerada). |
| `HERMES_WEBUI` | `true` ou `false`: o chat no navegador. |
| `HERMES_MODEL_PROVIDER`, `HERMES_MODEL`, `HERMES_MODEL_CUSTOM`, `HERMES_BASE_URL` | Provedor e modelo, aplicados a cada inicialização. |
| `OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`, `OPENAI_COMPAT_API_KEY` | A chave do provedor escolhido. |
| `TELEGRAM_*`, `DISCORD_*`, `SLACK_*`, `WHATSAPP_*`, `EMAIL_*` | As credenciais e a lista de permitidos de cada canal. |

## Recursos e limites

- Porta 8080. Primeiro boot de 15 a 30 segundos; as inicializações seguintes levam cerca de 15 segundos.
- Estado em `/app/.hermes`. A imagem é grande, então o primeiro deploy demora mais.
- O deploy sem downtime está desligado; o rollback devolve o estado também.
- Um token de canal inválido aparece no log do app: não o compartilhe.
