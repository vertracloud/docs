Um bot do Discord mínimo em JavaScript com discord.js 14.27.0 e um comando `/ping`. Este é um **template de código**: o código é seu, aberto e editável, e a Vertra Cloud executa o que está em `src/`.

## O que ele cria

Um app (código) no runtime de JavaScript, **sem endereço web**: o bot só faz conexões de saída. Precisa de pelo menos **100 MB** de memória (256 MB recomendados) e **nenhuma vaga de imagem**, então qualquer plano pode executá-lo. Veja [O que são templates](/pt-br/templates/overview).

- Ele faz login com o token do bot, registra o comando de barra `/ping` a cada inicialização e responde com a latência do gateway.
- Usa apenas o intent `Guilds`, então não há nenhum intent privilegiado para ativar.
- Sem token ou com um token errado, o processo encerra com código 1 e uma mensagem clara no log do app.
- Código-fonte em `src/index.js`; dependências em `src/package.json`.

## O que o assistente pergunta

| Pergunta | O que faz |
|---|---|
| Bot token | Vira a variável criptografada `DISCORD_TOKEN`. |

## Primeiros passos

<Steps>
  <Step title="Crie o bot e obtenha o token">
    No [Discord Developer Portal](https://discord.com/developers/applications) crie uma **New Application**, abra **Bot** e clique em **Reset Token**. Copie o valor: ele é mostrado uma única vez.
  </Step>
  <Step title="Cole no assistente">
    Cole o token quando o assistente pedir. Ele é guardado criptografado e nunca vai no código.
  </Step>
  <Step title="Convide o bot">
    Em **OAuth2 > URL Generator**, marque os escopos `bot` e `applications.commands`, abra a URL gerada e escolha o seu servidor.
  </Step>
  <Step title="Confira">
    Depois do deploy, o log do app mostra `Logged in as <bot name>`. No Discord, digite `/ping`: o bot responde `Pong!` com a latência. O comando global pode levar alguns minutos para aparecer na primeira vez.
  </Step>
</Steps>

## Faça do seu jeito

Abra `src/index.js`, adicione seus comandos e faça deploy de novo, ou reinicie se você editou no editor do app. Para adicionar bibliotecas, execute `npm install <package>` localmente e envie o `package.json` e o `package-lock.json` atualizados: a plataforma instala as dependências a cada deploy.

Editar o código desvincula o app do template, que então deixa de receber novas versões. Veja [Atualizar e fazer rollback](/pt-br/templates/use/updates-and-rollback#apps-desvinculados-e-templates-removidos).

## Limites e problemas comuns

- Duas cópias com o mesmo token responderiam duas vezes, então o deploy sem downtime está desligado.
- O mínimo é 100 MB, e 256 MB (o recomendado) bastam para um bot simples. Um bot em muitos servidores ou com um cache grande precisa de mais; você pode aumentar a memória.
- Os comandos globais do Discord demoram a propagar. Para testes, registre comandos de servidor no seu código.
- **`Login failed` no log.** `DISCORD_TOKEN` não é o token do bot. Redefina-o no Portal, atualize a variável e reinicie.
- **`/ping` não aparece.** Espere alguns minutos e confira se o convite tinha o escopo `applications.commands`.
- **O app não fica no ar.** Sem um token válido o processo encerra com código 1. Corrija o token e reinicie.
