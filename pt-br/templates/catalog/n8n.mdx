Automação visual de fluxos de trabalho. O template executa o n8n 2.44.7 com o nó Code em **JavaScript e Python** no mesmo container, um worker opcional em modo fila e nós da comunidade.

<Card title="Guia passo a passo: n8n do zero ao seu primeiro fluxo" icon="book-open" href="/pt-br/templates/guides/n8n">
  Escolha o modo, crie o dono, webhooks, Python e JavaScript, SMTP, credenciais, backups e rollback.
</Card>

## O que ele cria

| Modo | Cria | Memória |
|---|---|---|
| **Managed Postgres** (padrão) | O app do n8n e um Postgres gerenciado. | 2 GB |
| **Built-in SQLite** | Somente o app do n8n. | 1 GB |
| **Scale with workers** | O app do n8n, um worker, Postgres e Redis. | 3,5 GB |

É um template de imagem: exige um plano com imagens Docker e uma [vaga de imagem](/pt-br/templates/overview#vagas-de-imagem) livre. Veja [Planos e limites](/pt-br/plans-and-limits).

## O que o assistente pergunta

| Pergunta | O que faz |
|---|---|
| How will n8n run? | O modo acima. |
| Parallel executions on the worker | Somente com workers. Padrão 5. |
| Schedule time zone | America/Sao_Paulo, UTC, America/New_York ou Europe/Lisbon. |
| Modules allowed in the Code node | **Safe** (padrão) ou **All**. |
| Send n8n emails? | SMTP opcional para convites e redefinição de senha. |

## O que você recebe

O endereço do app e o próximo passo: abra-o e crie a conta de **dono** imediatamente. Os segredos (a chave de criptografia e o token dos runners) são gerados para você.

## Variáveis

| Variável | O que faz |
|---|---|
| `N8N_ENCRYPTION_KEY` | Criptografa as credenciais; guarde uma cópia. Nunca a altere em um app em execução. |
| `N8N_WEBHOOK_URL`, `N8N_EDITOR_BASE_URL`, `N8N_HOST` | O endereço público do app. |
| `VERTRA_CODE_MODULES` | `safe` ou `all`: os módulos que o nó Code pode importar. |
| `GENERIC_TIMEZONE`, `TZ` | Fuso horário dos agendamentos. |
| `EXECUTIONS_DATA_MAX_AGE`, `EXECUTIONS_DATA_PRUNE_MAX_COUNT` | Retenção do histórico: 168 horas e 5.000 execuções. |
| `N8N_WORKER_CONCURRENCY` | Execuções paralelas no worker (modo com workers). |
| `N8N_SMTP_*`, `N8N_EMAIL_MODE` | E-mail para convites e redefinição de senha. |

## Recursos e limites

- Porta 5678; primeiro boot de 25 a 60 segundos. Uso de memória do editor de cerca de 300 a 540 MiB, do worker de 330 a 560 MiB.
- Dados em `/app/.n8n`; nós da comunidade em `/app/.n8n/nodes`.
- No máximo um worker; o deploy sem downtime está desligado; o rollback devolve os dados também.
- O histórico de execuções é apagado após 7 dias ou 5.000 execuções.
