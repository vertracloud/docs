A Vertra Cloud publica oito templates oficiais: n8n, OpenClaw, Hermes Agent, Evolution API, Open WebUI, Uptime Kuma e um starter de bot do Discord em JavaScript e em Python. Abra **Templates** no dashboard para vê-los na galeria com sua memória livre e suas vagas de imagem, execute `vertra template list` ou consulte a [galeria pública](https://vertracloud.app/templates), que não exige conta. Cada um pede apenas o que precisa e gera os próprios segredos.

Todos têm o selo **Vertra**. Os seis que executam uma imagem precisam de um plano com imagens Docker e uma vaga de imagem livre cada; os dois bots do Discord rodam em um runtime de linguagem e não usam vaga. Veja [O que são templates](/pt-br/templates/overview) para saber como o plano exigido é calculado e [Planos e limites](/pt-br/plans-and-limits) para os números.

## Agentes e assistentes de IA

| Template | O que é | O que cria |
|---|---|---|
| [**OpenClaw**](/pt-br/templates/catalog/openclaw) | Assistente pessoal de IA com navegador, painel de controle e canais (Telegram, Discord, Slack, WhatsApp). Você traz a sua própria chave de modelo. | Um app (imagem). |
| [**Hermes Agent**](/pt-br/templates/catalog/hermes-agent) | Agente de IA que aprende com o uso, com painel, chat no navegador e canais (Telegram, Discord, Slack, WhatsApp). | Um app (imagem). |
| [**Open WebUI**](/pt-br/templates/catalog/open-webui) | Uma interface de chat com IA para a sua equipe. Você traz a sua própria chave de modelo. | Um app (imagem), mais um banco de dados Postgres se você escolher armazenamento gerenciado. |

## Automação e APIs

| Template | O que é | O que cria |
|---|---|---|
| [**n8n**](/pt-br/templates/catalog/n8n) | Automação visual de fluxos de trabalho com nós de código em Python e JavaScript, workers e nós da comunidade. | Um app, ou uma stack com Postgres, e Postgres, Redis e um worker se você escalar com workers (imagem). |
| [**Evolution API**](/pt-br/templates/catalog/evolution-api) | API de WhatsApp com instâncias, webhooks e integrações. | Uma stack com o app e um banco de dados Postgres, e Redis se você o escolher como cache (imagem). |

## Monitoramento

| Template | O que é | O que cria |
|---|---|---|
| [**Uptime Kuma**](/pt-br/templates/catalog/uptime-kuma) | Monitore sites e serviços com alertas e uma página de status. Seus dados ficam no seu app. | Um app (imagem). |

## Bots

| Template | O que é | O que cria |
|---|---|---|
| [**Discord bot (JavaScript)**](/pt-br/templates/catalog/discord-bot-js) | Um bot do Discord com discord.js e um comando `/ping`, ponto de partida para o seu bot. | Um app (código), sem web. |
| [**Discord bot (Python)**](/pt-br/templates/catalog/discord-bot-python) | Um bot do Discord com discord.py e um comando `/ping`, ponto de partida para o seu bot. | Um app (código), sem web. |

O código dos templates de bot do Discord é seu para editar; editá-lo desvincula o app do template, que então deixa de receber novas versões. Os templates que executam uma imagem não têm código editável: você altera a memória e as respostas às perguntas deles.

## Guias passo a passo

n8n, OpenClaw e Hermes Agent têm um guia dedicado cada, da primeira tela até uma configuração funcionando: [n8n](/pt-br/templates/guides/n8n), [OpenClaw](/pt-br/templates/guides/openclaw) e [Hermes Agent](/pt-br/templates/guides/hermes-agent). Todo template também tem a própria página nesta seção, com o que ele cria, as perguntas que faz e suas variáveis.

## Onde vê-los

A galeria fica no dashboard, em **Templates**, onde mostra quais cabem no seu plano; a [galeria pública](https://vertracloud.app/templates) os lista para todos. Para usar um, siga [Usar um template](/pt-br/templates/use/using-a-template). Para publicar o seu, veja [Criar templates](/pt-br/templates/create/overview).
