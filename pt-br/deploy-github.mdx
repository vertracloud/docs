Uma aplicação da Vertra Cloud pode ser criada a partir de um repositório do GitHub, público ou
privado, e atualizada automaticamente a cada push na branch que você escolher. Criar pelo GitHub
funciona em qualquer plano; o deploy automático exige o plano **Intermediary** ou superior.

## Criar a aplicação a partir do GitHub

<Steps>
  <Step title="Abra Novo Projeto">
    No dashboard, clique em **Novo Projeto** e escolha **Importar do GitHub**.
  </Step>
  <Step title="Informe o repositório">
    Cole a URL do repositório (`https://github.com/owner/repository`) ou use **Escolher entre os
    meus repositórios** para listar os repositórios da sua conta. Repositórios privados exigem
    conectar sua conta do GitHub, o que instala o app da Vertra Cloud nos repositórios que você
    autorizar.
  </Step>
  <Step title="Escolha a branch">
    A branch padrão do repositório já vem selecionada. Escolha outra branch e a árvore de arquivos
    e o código importado passam a ser dela.
  </Step>
  <Step title="Siga o fluxo normal">
    A partir daqui o fluxo é o mesmo de enviar um `.zip`: build, ambiente, rede, revisão e
    deploy. Veja [Primeiro deploy](/pt-br/how-to-host).
  </Step>
</Steps>

Para enviar uma nova versão depois, ative o deploy automático abaixo ou use `vertra deploy` na
[CLI](/pt-br/cli).

## Ativar o deploy automático

Com o deploy automático ativado, cada push na branch escolhida publica a nova versão: a plataforma
baixa o código daquele commit e faz o deploy. Sem branch escolhida, um push na `main` ou na
`master` faz o deploy.

1. Na aplicação, abra **Config → Deploy** e vá até **Deploy automático**.
2. Escolha a conta do GitHub e o repositório.
3. Escolha a branch. A branch padrão do repositório já vem selecionada. Se a lista de branches não
   puder ser carregada, o webhook segue a `main` ou a `master`.
4. Clique em **Ativar deploy automático**.

A Vertra Cloud cria o webhook no repositório para você; não é preciso configurar nada no
GitHub. A mesma seção mostra a branch atual e permite trocá-la; vincular de novo sem branch volta
para `main` ou `master`. Para desativar, use **Desativar**. O webhook também é removido
quando a aplicação é excluída.

<Note>
  Pushes em outras branches são ignorados. Webhooks criados antes da seleção de branch existir
  continuam seguindo `main` e `master`. Cada push conta para o
  [limite de deploys por hora](/pt-br/plans-and-limits#limite-de-deploys-por-hora) do plano; um push que chega depois de o
  limite ser excedido é descartado e registrado na aba **Atividades**.
</Note>

## Pela API

O deploy automático também pode ser criado, consultado e removido pela
[API de deploys](/pt-br/api-reference/endpoint/apps/deploys/webhookurl), com uma chave que tenha o
escopo `apps:write`.
