## O que é a Vertra Cloud?

A Vertra Cloud é uma plataforma brasileira de hospedagem de aplicações (PaaS): deploy a partir do GitHub ou de um arquivo zip,
containers isolados, bancos de dados gerenciados, armazenamento de arquivos, snapshots, uma CLI e uma extensão do VS Code.
Bots de Discord, WhatsApp e Telegram são cargas de trabalho de primeira classe. A plataforma constrói a imagem, executa
o container, roteia o subdomínio, emite os certificados e mantém os snapshots.

## O que a plataforma inclui?

Treze runtimes, quatro engines de bancos de dados gerenciados, métricas e logs em tempo real, vários domínios personalizados com
SSL automático, validação do ciclo de vida durante deploys e reinicializações, um servidor MCP para o seu agente de IA,
workspaces de equipe e uma extensão do VS Code.

## Quais bancos de dados estão disponíveis?

Quatro engines gerenciadas — PostgreSQL 18/17, MongoDB 8.0/9.0, Redis 8.2/7.2 e MySQL 9.7/8.4 — cada uma com TLS obrigatório
e certificados que a plataforma gera e rotaciona para você.

<CardGroup cols={2}>
  <Card title="PostgreSQL" icon="elephant">
    **Versões:** 18 (recomendada), 17

    Banco de dados relacional com suporte a SQL, JSONB e extensões. TLS obrigatório com certificados automáticos.
  </Card>
  <Card title="MongoDB" icon="leaf">
    **Versões:** 8.0 (recomendada), 9.0

    Banco de dados NoSQL orientado a documentos. TLS obrigatório com CA assinada pela plataforma.
  </Card>
  <Card title="Redis" icon="bolt">
    **Versões:** 8.2 (recomendada), 7.2

    Armazenamento em memória de alta performance para cache e pub/sub. TLS obrigatório.
  </Card>
  <Card title="MySQL" icon="database">
    **Versões:** 9.7 (recomendada, LTS), 8.4 (LTS)

    Banco de dados relacional com autenticação X509 obrigatória e certificados TLS gerados automaticamente.
  </Card>
</CardGroup>

## O que os planos incluem?

Os planos vão do Economy (R\$ 1,99/mês) ao Enterprise-32 (R\$ 191,99/mês, 32 GB de RAM) —
cada nível adiciona mais RAM, vCPU e requisições de API, além de
recursos como publicação na web, backups, domínios personalizados e workspaces nos níveis mais altos. A tabela completa —
preço, RAM, vCPU, projetos e limite de API de cada plano — está em
[Planos e limites](/pt-br/plans-and-limits), que é mantida em sincronia com o código de cobrança da plataforma; esta
página não a repete.
