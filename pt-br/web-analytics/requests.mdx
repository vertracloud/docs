A sub-aba Requisições é um log com uma linha por requisição, para você inspecionar uma visita específica em vez de totais. Está disponível no Pro e acima.

Os mesmos dados pela API: [Requisições da aplicação](/pt-br/api-reference/endpoint/apps/analytics/requests).

## Colunas

| Coluna | Significado |
|---|---|
| **Horário** | Quando a requisição chegou. |
| **ID da requisição** | Cada requisição tem um identificador único, exibido como texto selecionável no detalhe da requisição. |
| **Método e rota** | Por exemplo `GET /pricing`. |
| **Query** | A parte depois de `?`. Mascarada por padrão. |
| **Status** | O status que o visitante recebeu e o status que seu app devolveu ao responder. Diferem quando a borda respondeu sozinha, como numa requisição em cache ou bloqueada. |
| **Cache** | Se a resposta veio do cache da borda ou do seu app. |
| **Host** | Qual hostname foi pedido: o subdomínio ou um dos seus domínios personalizados. |
| **Tempo da borda e do container** | Os dois relógios explicados em [Desempenho](/pt-br/web-analytics/performance). |
| **País, data center, rede** | De onde o visitante se conectou e qual ponto da borda respondeu. |
| **IP** | O endereço do visitante. Mascarado por padrão. |
| **Dispositivo, sistema, navegador** | Obtidos do user agent do visitante. |
| **Bot** | A categoria, quando o visitante é um cliente automatizado conhecido. |
| **Origem (referrer), protocolo, tipo de conteúdo** | O restante do contexto da requisição. |

## Filtrar, ordenar e paginar

A tabela aceita os mesmos [filtros](/pt-br/web-analytics/traffic#filtros-cruzados) das outras sub-abas, então um clique em um status em Erros vira aqui uma lista exatamente dessas requisições. Ordene da mais nova para a mais antiga ou o contrário e navegue pelos resultados.

## IP e query mascarados

Endereços IP e query strings podem identificar uma pessoa ou carregar tokens, então o painel **oculta os dois por padrão**. Clique em **Mostrar dados** para revelá-los. A escolha vale para a sessão de tela atual e não é salva. A rota e o caminho nunca são ocultados. Veja [Privacidade](/pt-br/web-analytics/privacy).

## Amostra e atraso

Cada linha é uma requisição real, mas com tráfego alto a tabela é uma **amostra**, não todas as requisições. Linhas novas podem levar alguns minutos para aparecer. Um aviso aparece nos dois casos; veja [Amostragem e atraso](/pt-br/web-analytics/sampling-and-delay).
