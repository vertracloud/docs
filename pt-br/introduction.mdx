## O que é a Vertra Cloud?

A Vertra Cloud é uma plataforma brasileira de hospedagem de aplicações (PaaS): deploy a partir do GitHub ou de um arquivo zip,
containers isolados, bancos de dados gerenciados, armazenamento de arquivos, snapshots, uma CLI e uma extensão do VS Code.
Bots de Discord, WhatsApp e Telegram são cargas de trabalho de primeira classe. Você escreve o código; a plataforma
constrói a imagem, executa o container, roteia o subdomínio e mantém os snapshots.

Esta é a documentação oficial: como fazer deploy, o que cada plano inclui, como funcionam os bancos de
dados gerenciados e a referência completa da API REST pública.

## O que você pode executar na Vertra Cloud?

Aplicações em 13 runtimes, quatro engines de bancos de dados gerenciados, sites estáticos e dinâmicos e
workers em segundo plano, como bots — cada um em seu próprio container, com memória e armazenamento dedicados.
