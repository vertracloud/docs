Para **imagens públicas**, adicione parâmetros de query à URL do arquivo e a plataforma devolve uma cópia redimensionada ou convertida, servida pela CDN:

```text
https://blob.vertracloud.dev/<namespace>/images/logo.png?w=400&h=300&fit=cover&format=webp&q=80
```

| Parâmetro | Significado |
|---|---|
| `w`, `h` | Largura e altura de destino em pixels, de `1` a `4096` |
| `fit` | Como a imagem preenche a caixa: `scale-down`, `contain`, `cover`, `crop` ou `pad` |
| `format` | Formato de saída: `webp`, `avif`, `jpeg`, `png` ou `auto` (escolhe AVIF ou WebP pelo cabeçalho `Accept` do navegador) |
| `q` | Qualidade, de `1` a `100` |

Parâmetros inválidos ou desconhecidos são ignorados. Somente imagens públicas JPEG, PNG, WebP, AVIF e GIF são transformadas; SVG e outros arquivos são sempre servidos como foram guardados.

<CodeGroup>

```bash cURL
curl -o logo-400.webp "https://blob.vertracloud.dev/<namespace>/images/logo.png?w=400&format=webp"
```

```javascript JavaScript
const url = blob.imageUrl(obj, { width: 400, format: "webp" });
```

```python Python
url = obj["url"] + "?w=400&format=webp"
```

```go Go
url := *obj.URL + "?w=400&format=webp" // URL é nil para um objeto privado
```

</CodeGroup>

## Planos e limites mensais

As transformações de imagem começam no plano **Starter 2**. No Starter 1, a URL com parâmetros serve a imagem original.

| Plano | Transformações por mês |
|---|---|
| Starter 1 | não incluso |
| Starter 2 | 600 |
| Pro 4 | 1.500 |
| Pro 6 | 2.000 |
| Pro 8 | 2.500 |
| Business 12 | 4.000 |
| Business 16 e 24 | 5.000 |
| Enterprise (todos os tamanhos) | 10.000 |

Só transformações **únicas** contam: a mesma imagem com os mesmos parâmetros conta uma vez por mês, e as requisições repetidas atendidas pelo cache não contam para o limite. Depois do limite, a URL continua funcionando e serve a imagem **original**, sem erro. Seu uso no mês é `image_transformations_used` em [Obter estatísticas](/pt-br/api-reference/endpoint/blob/account/stats).

Imagens privadas nunca são transformadas.
