A API do Blob Storage fica em `https://blob.vertracloud.app/v1` e usa a mesma chave de API da plataforma, no header `Authorization: Bearer`. A referência de cada endpoint está em inglês, igual para todos os idiomas.

Antes de chamar a API, veja [Autenticação](/pt-br/blob/authentication) para os escopos e os tokens de upload.
