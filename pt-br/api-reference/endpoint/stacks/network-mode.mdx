description: Define como os membros de uma stack se alcançam. O modo aceito é `public`.
---

{/* @see RESTPostAPIStackNetworkModeBody, RESTPostAPIStackNetworkModeResponse — @vertracloud/api-types */}
Só `public` é aceito: os membros usam os endereços públicos dos serviços, e os bancos de dados são acessados com certificados de cliente. Qualquer outro valor falha com `STACK_NETWORK_MODE_UNAVAILABLE`. Precisa do escopo `stacks:write` quando chamado com uma chave de API.

<ParamField path="stack_id" type="string" required>
  O ID da stack.
</ParamField>

<ParamField query="workspace_id" type="string">
  O workspace ao qual a stack pertence, quando você age sobre ela como dono do workspace.
</ParamField>

<ParamField body="network_mode" type="string" required>
  `public`.
</ParamField>

### Resposta

A stack, como em [Obter stack](/pt-br/api-reference/endpoint/stacks/get).

### Erros

| Status | Código | Quando |
|---|---|---|
| 400 | `STACK_NETWORK_MODE_UNAVAILABLE` | O modo não é `public`. |
| 403 | `WORKSPACE_OWNER_ONLY` | Você é membro do workspace, não o dono. |
| 404 | `STACK_NOT_FOUND` | A stack não existe ou pertence a outra conta. |
