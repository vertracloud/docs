{/* @see RESTPostAPIStackSnapshotRestoreBody, RESTPostAPIStackSnapshotRestoreResponse — @vertracloud/api-types */}
Restaura todos os membros juntos: primeiro os bancos de dados, depois os apps. Ela para no primeiro erro e informa o que já foi restaurado em `details.restored`. Precisa do escopo `stacks:write` quando chamado com uma chave de API.

<ParamField path="stack_id" type="string" required>
  O ID da stack.
</ParamField>

<ParamField path="snapshot_id" type="string" required>
  O ID do snapshot da stack.
</ParamField>

<ParamField query="workspace_id" type="string">
  O workspace ao qual a stack pertence, quando você age sobre ela como dono do workspace.
</ParamField>

<ParamField body="restore_image_version" type="boolean" default="false">
  Os apps que executam uma imagem personalizada também voltam para a versão da imagem do snapshot, se ela ainda existir.
</ParamField>

### Resposta

O resultado da restauração, como em [Restaurar snapshot do app](/pt-br/api-reference/endpoint/apps/snapshots/restore).

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Você é membro do workspace, não o dono. |
| 404 | `STACK_NOT_FOUND` | A stack não existe ou pertence a outra conta. |
