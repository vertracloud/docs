{/* @see RESTPostAPIStackSnapshotResponse, APIStackSnapshot — @vertracloud/api-types */}
Faz um snapshot de cada app e banco de dados da stack e os agrupa. Valem as regras e as janelas de snapshot do plano, como nos [snapshots de um único recurso](/pt-br/api-reference/endpoint/apps/snapshots/create). Precisa do escopo `stacks:write` quando chamado com uma chave de API.

<ParamField path="stack_id" type="string" required>
  O ID da stack.
</ParamField>

<ParamField query="workspace_id" type="string">
  O workspace ao qual a stack pertence, quando você age sobre ela como dono do workspace.
</ParamField>

### Resposta

O snapshot criado, com os mesmos campos de um item de [Listar snapshots da stack](/pt-br/api-reference/endpoint/stacks/snapshots/list), com `reason` igual a `manual`.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `PLAN_RESTRICTED_FEATURE` | O plano não inclui snapshots manuais. |
| 403 | `WORKSPACE_OWNER_ONLY` | Você é membro do workspace, não o dono. |
| 404 | `STACK_NOT_FOUND` | A stack não existe ou pertence a outra conta. |
