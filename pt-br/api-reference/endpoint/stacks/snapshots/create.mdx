{/* @see RESTPostAPIStackSnapshotResponse, APIStackSnapshotAccepted — @vertracloud/api-types */}
Faz um snapshot de cada app e banco de dados da stack e os agrupa. Cada membro é um snapshot manual comum: aparece na lista de snapshots do app ou do banco, usa a cota de snapshots manuais da conta e fica guardado por 30 dias. O snapshot roda em segundo plano e a requisição responde **`202`** assim que é aceita; nada foi feito ainda. Precisa do escopo `stacks:write` quando chamado com uma chave de API.

<ParamField path="stack_id" type="string" required>
  O ID da stack.
</ParamField>

<ParamField query="workspace_id" type="string">
  O workspace ao qual a stack pertence, quando você age sobre ela como dono do workspace.
</ParamField>

### Resposta

A cota e as conferências de **todos** os membros acontecem antes do `202`: se um membro não pode ter snapshot (sem cota, plano sem snapshots manuais, restore ou deploy em andamento), a requisição responde com o erro dele, nada é iniciado e a cota usada volta. Veja [Criar snapshot de app](/pt-br/api-reference/endpoint/apps/snapshots/create) para esses códigos.

Acompanhe cada `job_id` em [Obter job de snapshot](/pt-br/api-reference/endpoint/apps/snapshots/jobs/get) (`GET /v1/users/{id}/snapshots/jobs/{job_id}`, em que `{id}` é o `resource_id` do job) até o `status` ser `ready` ou `failed`. O `id` do snapshot da stack aparece em [Listar snapshots da stack](/pt-br/api-reference/endpoint/stacks/snapshots/list) como `pending` e vira `ready` quando todos os jobs estão `ready`; só então pode ser restaurado. Se um membro falha, o snapshot da stack não é listado, e os snapshots dos membros que deram certo continuam nas listas deles como snapshots comuns.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `PLAN_NOT_ALLOWED` | O plano não inclui snapshots manuais. |
| 403 | `WORKSPACE_OWNER_ONLY` | Você é membro do workspace, não o dono. |
| 404 | `STACK_NOT_FOUND` | A stack não foi encontrada. |
| 404 | `STACK_MEMBER_NOT_FOUND` | A stack não tem app nem banco. |
| 409 | `OPERATION_IN_PROGRESS` | Já há um snapshot desta stack em andamento. |
| 429 | `SNAPSHOT_RATE_LIMITED` | Um membro não tem mais cota de snapshots manuais, ou teve snapshot há menos de 3 minutos. |
