{/* @see RESTGetAPIStacksResponse, APIStack — @vertracloud/api-types */}
Retorna todas as stacks que você possui, ou as stacks de um workspace quando você envia `workspace_id`. Uma stack agrupa apps, bancos de dados e pastas do Blob e as conexões entre eles. Veja [Stacks](/pt-br/templates/use/stacks) para o conceito.

Precisa do escopo `stacks:read` quando chamado com uma chave de API.

<ParamField query="workspace_id" type="string">
  Lista as stacks deste workspace em vez das suas. Membros do workspace podem ler stacks; só o dono pode alterá-las.
</ParamField>

### Resposta

<ResponseField name="response" type="object[]">
  Um array de stacks. Cada item tem o mesmo formato do objeto retornado por [Obter stack](/pt-br/api-reference/endpoint/stacks/get).
</ResponseField>

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | A chave não tem `stacks:read`. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
