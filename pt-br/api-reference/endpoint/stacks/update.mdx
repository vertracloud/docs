{/* @see RESTPatchAPIStackBody, RESTPatchAPIStackResponse — @vertracloud/api-types */}
Altera o nome ou a descrição de uma stack. Pelo menos um campo é obrigatório. Precisa do escopo `stacks:write` quando chamado com uma chave de API.

<ParamField path="stack_id" type="string" required>
  O ID da stack.
</ParamField>

<ParamField query="workspace_id" type="string">
  O workspace ao qual a stack pertence, quando você age sobre ela como dono do workspace.
</ParamField>

<ParamField body="name" type="string">
  O novo nome.
</ParamField>

<ParamField body="description" type="string | null">
  A nova descrição. `null` a remove.
</ParamField>

### Resposta

<ResponseField name="response" type="object">
  A stack atualizada, com os mesmos campos de [Obter stack](/pt-br/api-reference/endpoint/stacks/get).
</ResponseField>

<RequestExample>

```bash cURL
curl -X PATCH https://api.vertracloud.app/v1/stacks/stk-abc123def456 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "name": "shop-prod" }'
```

</RequestExample>

### Erros

| Status | Código | Quando |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Nenhum campo foi enviado, ou um valor é inválido. |
| 403 | `WORKSPACE_OWNER_ONLY` | Você é membro do workspace, não o dono. |
| 404 | `STACK_NOT_FOUND` | A stack não existe ou pertence a outra conta. |
