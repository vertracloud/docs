---
title: Redefinir a senha do banco de dados
sidebarTitle: Redefinir senha
api: POST https://api.vertracloud.app/v1/databases/{id}/credentials/reset
authMethod: bearer
description: Redefine a senha de um banco de dados específico pelo seu ID.
---

{/* @see { password: string } — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  O ID do banco de dados cuja senha será redefinida.
</ParamField>

### Resposta

<ResponseField name="response" type="object">
  A resposta com a nova senha.

  <Expandable title="Mostrar objeto">

  <ResponseField name="password" type="string">
    A nova senha do banco de dados.
  </ResponseField>

  <ResponseField name="restart_required" type="boolean">
    `true` quando pelo menos uma aplicação de uma stack conectada precisa reiniciar para ler a nova senha.
  </ResponseField>

  <ResponseField name="apps_to_restart" type="string[]">
    Os IDs dessas aplicações. Vazio quando `restart_required` é `false`.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "password": "a1b2c3d4e5f6g7h8",
    "restart_required": false,
    "apps_to_restart": []
  }
}
```

</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: O header `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: A chave de API é usada a partir de um IP fora da sua lista de IPs permitidos, ou não tem o escopo que a rota exige (`403`).
  - `ACCESS_DENIED`: O recurso pertence a outra conta, ou você não tem a permissão de workspace para ele (`403`).
  - `DATABASE_NOT_FOUND_OR_FORBIDDEN`: O banco de dados informado não existe ou o usuário não tem acesso.
  - `INVALID_PLAN_CONFIG`: A configuração do plano do banco de dados é inválida.
  - `FAILED_TO_REBUILD_DATABASE`: Falha ao recriar o banco de dados com a nova senha.
</ResponseField>

<ResponseField name="message" type="string">
  Uma mensagem descritiva com detalhes adicionais sobre o erro.
</ResponseField>

<ResponseExample>

```json Error Response (403)
{
  "code": "ACCESS_DENIED"
}
```

```json Error Response (404)
{
  "code": "DATABASE_NOT_FOUND_OR_FORBIDDEN"
}
```

```json Error Response (500)
{
  "code": "FAILED_TO_REBUILD_DATABASE"
}
```

</ResponseExample>
