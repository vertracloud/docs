Exclui o banco de dados na hora. A exclusão é permanente: não há como desfazer, então [crie um snapshot](/pt-br/api-reference/endpoint/apps/snapshots/create)
antes se puder precisar dos dados dele. Os snapshots que você já tem continuam disponíveis. Uma chave de API precisa do escopo `databases:delete`.

<ParamField path="id" type="string" required>
  O ID do banco de dados a excluir.
</ParamField>

<ParamField query="workspace_id" type="string">
  Se o banco de dados pertencer a um workspace, o ID do workspace.
</ParamField>

### Resposta

<ResponseField name="response" type="string">
  O ID do banco de dados excluído.
</ResponseField>

<ResponseExample>

```json Response
{
  "response": "00000000000000000000000000000001"
}
```

</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
  - `DATABASE_NOT_FOUND`: O banco de dados não foi encontrado (`404`).
  - `ACCESS_DENIED`: Você é membro de um workspace sem a permissão para esta ação, ou não enviou o `workspace_id` (`403`).
  - `OPERATION_IN_PROGRESS`: Outra operação de ciclo de vida está em andamento neste banco de dados (`409`).
  - `INTERNAL_SERVER_ERROR`: A plataforma não conseguiu remover o banco de dados; tente novamente mais tarde (`500`).
</ResponseField>
