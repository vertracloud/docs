{/* @see success — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  O ID do banco de dados a redefinir.
</ParamField>

### Resposta

<ResponseField name="response" type="string">
  A mensagem de resposta, indicando que a operação foi concluída com sucesso.
</ResponseField>

<ResponseExample>

```json Response
{
  "response": "success"
}
```

</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: O header `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: A chave de API é usada a partir de um IP fora da sua lista de IPs permitidos, ou não tem o escopo que a rota exige (`403`).
  - `ACCESS_DENIED`: O recurso pertence a outra conta, ou você não tem a permissão de workspace para ele (`403`).
  - `DATABASE_NOT_FOUND`: O banco de dados informado não existe ou o usuário não tem acesso.
  - `DATABASE_ID_REQUIRED`: O ID do banco de dados não foi informado.
  - `SNAPSHOT_FAILED`: Não foi possível fazer o snapshot de segurança; o banco de dados não foi redefinido. Entre em contato com o suporte (`500`).
  - `INTERNAL_SERVER_ERROR`: Falha ao redefinir o banco de dados.
</ResponseField>

<ResponseField name="message" type="string">
  Uma mensagem descritiva com detalhes adicionais sobre o erro.
</ResponseField>

<ResponseExample>

```json Error Response (403)
{
  "code": "ACCESS_DENIED"
}
```

```json Error Response (404)
{
  "code": "DATABASE_NOT_FOUND"
}
```

```json Error Response (400)
{
  "code": "DATABASE_ID_REQUIRED"
}
```

</ResponseExample>
