api: POST https://api.vertracloud.app/v1/databases/{id}/reset

description: Redefine um banco de dados pelo ID e apaga todos os dados, na hora e de forma definitiva. Crie um snapshot antes se puder precisar dos dados.
---

{/* @see success — @vertracloud/api-types */}
Apaga todos os dados do banco de dados na hora. A ação é permanente: não há como desfazer, então [crie um snapshot](/pt-br/api-reference/endpoint/apps/snapshots/create)
antes se puder precisar dos dados. Os snapshots que você já tem continuam disponíveis. Uma chave de API precisa do escopo `databases:delete`, e em um workspace o membro precisa da permissão `databases:delete`.

<ParamField path="id" type="string" required>
  O ID do banco de dados a redefinir.
</ParamField>

### Resposta

<ResponseField name="response" type="object">
  <Expandable title="Mostrar objeto">

  <ResponseField name="status" type="string">
    `success`, quando o banco de dados foi redefinido.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "status": "success"
  }
}
```

</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: O header `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: A chave de API é usada a partir de um IP fora da sua lista de IPs permitidos, ou não tem o escopo que a rota exige (`403`).
  - `ACCESS_DENIED`: Você é membro de um workspace sem a permissão para esta ação, ou não enviou o `workspace_id` (`403`).
  - `DATABASE_NOT_FOUND`: O banco de dados informado não foi encontrado.
  - `DATABASE_ID_REQUIRED`: O ID do banco de dados não foi informado.
  - `INTERNAL_SERVER_ERROR`: Falha ao redefinir o banco de dados.
</ResponseField>

<ResponseField name="message" type="string">
  Uma mensagem descritiva com detalhes adicionais sobre o erro.
</ResponseField>

<ResponseExample>

```json Error Response (403)
{
  "code": "ACCESS_DENIED"
}
```

```json Error Response (404)
{
  "code": "DATABASE_NOT_FOUND"
}
```

```json Error Response (400)
{
  "code": "DATABASE_ID_REQUIRED"
}
```

</ResponseExample>
