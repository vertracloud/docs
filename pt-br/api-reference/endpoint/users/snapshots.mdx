---
title: Listar todos os snapshots da conta
sidebarTitle: Todos os snapshots
api: GET https://api.vertracloud.app/v1/users/snapshots
authMethod: bearer
description: Lista todos os snapshots das aplicações ou dos bancos de dados da conta, agrupados por recurso. Exige o escopo snapshots:read.
---
Retorna os snapshots de cada aplicação (ou de cada banco de dados) que você possui, agrupados por
recurso. Para listar os snapshots de um único recurso, use [Obter snapshots](/pt-br/api-reference/endpoint/apps/snapshots/getall).

<ParamField query="scope" type="string">
  `applications` (padrão) ou `databases`.
</ParamField>

### Resposta

<ResponseField name="response" type="array">
  Uma entrada por recurso que tenha pelo menos um snapshot.

  <Expandable title="Mostrar objeto">

  <ResponseField name="resource_id" type="string">O ID da aplicação ou do banco de dados.</ResponseField>
  <ResponseField name="current_resource_name" type="string | null">O nome atual do recurso, ou `null` se ele não existir mais.</ResponseField>
  <ResponseField name="type" type="number">`1` para aplicações, `2` para bancos de dados.</ResponseField>
  <ResponseField name="snapshots" type="array">
    Os snapshots do recurso: `id`, `resource_id`, `resource_name` (o nome na hora em que o snapshot foi feito), `size` e `date`.
  </ResponseField>

  </Expandable>
</ResponseField>
