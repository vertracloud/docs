---
title: Atualizar perfil do usuário
sidebarTitle: Atualizar perfil
api: PATCH https://api.vertracloud.app/v1/users/me
authMethod: bearer
description: Atualiza o nome, o idioma e as preferências de e-mail de workspace do usuário autenticado. Exige o escopo account:write.
---
Envie pelo menos um campo. Uma chave de API precisa do escopo `account:write`.

<ParamField body="name" type="string">
  O nome de exibição.
</ParamField>

<ParamField body="language" type="string">
  O idioma da interface: `pt-br`, `en-us` ou `es-es`. Qualquer outro valor retorna `400 INVALID_PAYLOAD`.
</ParamField>

<ParamField body="workspace_invites_enabled" type="boolean">
  Se outras pessoas podem convidar você para os workspaces delas.
</ParamField>

### Resposta

<ResponseField name="response" type="object">
  O perfil atualizado: `id`, `name`, `email`, `language`, `workspace_invites_enabled`,
  `created_at` e `updated_at`.
</ResponseField>

### Respostas de erro

<ResponseField name="code" type="string">
  - `INVALID_PAYLOAD`: Nenhum campo foi enviado, ou um campo tem o tipo errado (`400`).
</ResponseField>
