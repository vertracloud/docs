title: Verificar status da infraestrutura
sidebarTitle: Verificar status
api: GET https://api.vertracloud.app/v1/status
authMethod: none
description: Verifica se a infraestrutura está totalmente operacional.
---

{/* @see APIStatus — @vertracloud/api-types */}
### Resposta

<ResponseField name="status" type="string">
  Indica o status atual da infraestrutura. Valores possíveis: `healthy`,
  `unknown`, `degraded`.
</ResponseField>

<ResponseField name="response" type="string">
  Uma mensagem descrevendo o status da infraestrutura. Valores possíveis: `All systems
  operational`, `Some systems are degraded`, `Some systems are down`.
</ResponseField>

<ResponseExample>

```json Response
{
  "status": "healthy",
  "response": "All systems operational"
}
```

</ResponseExample>
