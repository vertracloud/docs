---
title: Excluir webhook de deploy
sidebarTitle: Excluir webhook
api: DELETE https://api.vertracloud.app/v1/apps/{app_id}/deploys/webhook
authMethod: bearer
description: Exclui um webhook de deploy existente de uma aplicação.
---

{/* @see success/error — @vertracloud/api-types */}
<ParamField path="app_id" type="string" required>
O ID da aplicação da qual o webhook será excluído.
</ParamField>

### Resposta

Em caso de sucesso, a resposta é `200` com `{ "response": null }`.

<ResponseExample>
```json
{
  "response": null
}
```
</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
Códigos de erro possíveis:
- `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: o cabeçalho `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
- `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: a chave de API está sendo usada a partir de um IP fora da sua lista de permissões, ou não tem o escopo que a rota exige (`403`).
- `ACCESS_DENIED`: o recurso pertence a outra conta, ou você não tem a permissão do workspace para ele (`403`).
- `PLAN_RESTRICTED_FEATURE`: o plano do usuário não oferece suporte a deploy automático.
- `MISSING_APP_ID`: o ID da aplicação não foi informado.
- `APP_NOT_FOUND`: webhook de integração da aplicação não encontrado.
- `INSTALLATION_NOT_FOUND`: instalação do GitHub não encontrada para o usuário.
</ResponseField>

<ResponseField name="message" type="string">
  Uma mensagem descritiva com detalhes adicionais sobre o erro.
</ResponseField>

<ResponseExample>
```json
{
  "code": "APP_NOT_FOUND"
}
```
</ResponseExample>
