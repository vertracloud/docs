---
title: Obter deploys recentes
sidebarTitle: Deploys recentes
api: GET https://api.vertracloud.app/v1/apps/{app_id}/deploys
authMethod: bearer
description: Retorna os 20 deploys mais recentes de uma aplicação específica.
---

{/* @see deployments list — @vertracloud/api-types */}
<ParamField path="app_id" type="string" required>
O ID da aplicação cujos deploys recentes serão retornados.
</ParamField>

### Resposta

<ResponseField name="response" type="array">
Um array de objetos de deploy.

<Expandable title="Mostrar objeto">
  <ResponseField name="app_id" type="string">
  O ID da aplicação.
  </ResponseField>

  <ResponseField name="commit_id" type="string">
  O ID do commit do deploy.
  </ResponseField>

  <ResponseField name="message" type="string">
  Mensagem do commit.
  </ResponseField>

  <ResponseField name="pusher" type="string">
  O nome de usuário de quem disparou o deploy.
  </ResponseField>

  <ResponseField name="branch" type="string">
  A branch que foi publicada no deploy.
  </ResponseField>

  <ResponseField name="created_at" type="string">
  Timestamp ISO de quando o deploy aconteceu.
  </ResponseField>
</Expandable>
</ResponseField>

<ResponseExample>
```json
{
  "response": [
    {
      "app_id": "123",
      "commit_id": "abc123",
      "message": "Fix deployment bug",
      "pusher": "user1",
      "branch": "main",
      "created_at": "2026-03-14T20:00:00.000Z"
    }
  ]
}
```
</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
Códigos de erro possíveis:
- `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: o cabeçalho `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
- `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: a chave de API está sendo usada a partir de um IP fora da sua lista de permissões, ou não tem o escopo que a rota exige (`403`).
- `INTEGRATION_NOT_FOUND`: aplicação ou deploys não encontrados.
</ResponseField>

<ResponseField name="message" type="string">
  Uma mensagem descritiva com detalhes adicionais sobre o erro.
</ResponseField>

<ResponseExample>
```json
{
  "code": "INTEGRATION_NOT_FOUND"
}
```
</ResponseExample>
