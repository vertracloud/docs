---
title: Criar ou editar variáveis de ambiente da aplicação
sidebarTitle: Criar/editar variáveis de ambiente
api: POST https://api.vertracloud.app/v1/apps/{id}/envs
authMethod: bearer
description: Cria ou atualiza as variáveis de ambiente de uma aplicação pelo seu ID.
---

{/* @see APIApplicationEnvironment[] — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  O ID da aplicação para a qual as variáveis de ambiente serão criadas ou atualizadas.
</ParamField>

<ParamField query="workspace_id" type="string">
  Se a aplicação pertencer a um workspace, o ID do workspace. Obrigatório para membros do workspace que atuam em uma aplicação que não é deles.
</ParamField>

<ParamField body="environments" type="array" required>
  Um array de objetos de variável de ambiente.

  <Expandable title="Mostrar objeto">

  <ParamField name="key" type="string" required>
    A chave da variável de ambiente (máximo de 255 caracteres).
  </ParamField>

  <ParamField name="value" type="string" required>
    O valor da variável de ambiente (máximo de 3.072 caracteres).
  </ParamField>

  <ParamField name="note" type="string">
    Uma nota ou descrição opcional para a variável de ambiente.
  </ParamField>

  </Expandable>
</ParamField>

### Resposta

<ResponseField name="response" type="array">
  Um array de objetos de variável de ambiente após a criação ou atualização.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    O ID da variável de ambiente.
  </ResponseField>

  <ResponseField name="key" type="string">
    A chave da variável de ambiente.
  </ResponseField>

  <ResponseField name="value" type="string">
    O valor da variável de ambiente (descriptografado).
  </ResponseField>

  <ResponseField name="note" type="string | null">
    A nota ou descrição opcional da variável de ambiente.
  </ResponseField>

  <ResponseField name="created_at" type="string" format="date-time">
    O timestamp de quando a variável de ambiente foi criada.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": [
    {
      "id": "env123",
      "key": "API_KEY",
      "value": "secret123",
      "note": "API key for external service",
      "created_at": "2026-03-14T19:58:00Z"
    },
    {
      "id": "env456",

      "value": "mysql://user:pass@database-host/db",
      "note": null,
      "created_at": "2026-03-14T19:58:00Z"
    }
  ]
```

</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: o cabeçalho `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: a chave de API está sendo usada a partir de um IP fora da sua lista de permissões, ou não tem o escopo que a rota exige (`403`).
  - `ACCESS_DENIED`: o recurso pertence a outra conta, ou você não tem a permissão do workspace para ele (`403`).
  - `FORBIDDEN`: o usuário não tem permissão para acessar a aplicação.
  - `APP_NOT_FOUND`: a aplicação especificada não existe.
  - `INVALID_BODY`: o corpo da requisição não é um array válido ou está vazio.
  - `INVALID_ENVIRONMENT`: uma ou mais variáveis de ambiente são inválidas ou usam chaves proibidas.
  - `VALIDATION_ERROR`: uma `key` tem mais de 255 caracteres, ou um `value` tem mais de 3.072 caracteres (`400`); `details.path` aponta para o campo.
  - `ENV_LIMIT_EXCEEDED`: o número total de variáveis de ambiente ultrapassa o limite de 256.
</ResponseField>

<ResponseField name="message" type="string">
  Uma mensagem descritiva com detalhes adicionais sobre o erro.
</ResponseField>

<ResponseExample>

```json Error Response (403)
{

```

```json Error Response (404)

  "code": "APP_NOT_FOUND"
}
```

```json Error Response (400)
{
  "code": "INVALID_BODY"
}
```

</ResponseExample>
