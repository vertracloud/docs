---
title: Excluir uma variável de ambiente da aplicação
sidebarTitle: Excluir variável de ambiente
api: DELETE https://api.vertracloud.app/v1/apps/{id}/envs/{envId}
authMethod: bearer
description: Exclui uma variável de ambiente de uma aplicação pelo ID da variável.
---

{/* @see success/error — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  O ID da aplicação.
</ParamField>

<ParamField query="workspace_id" type="string">
  Se a aplicação pertencer a um workspace, o ID do workspace. Obrigatório para membros do workspace que atuam em uma aplicação que não é deles.
</ParamField>

<ParamField path="envId" type="string" required>
  O ID da variável de ambiente, conforme retornado por
  [Obter variáveis de ambiente](/pt-br/api-reference/endpoint/apps/enviroments/get). Não há corpo na requisição.
</ParamField>

### Resposta

Em caso de sucesso, a resposta é `200` com `{ "response": null }`. A variável é removida da configuração da aplicação;
reinicie a aplicação para que o processo em execução deixe de vê-la.

```json Response
{
  "response": null
}
```

### Respostas de erro

<ResponseField name="code" type="string">
  - `APP_NOT_FOUND`: a aplicação não existe (`404`).
  - `ACCESS_DENIED`: a sua conta não pode atuar nesta aplicação (`403`).
  - `ENV_NOT_FOUND`: nenhuma variável com esse ID nesta aplicação (`404`).
</ResponseField>
