{/* @see APIApplicationReleaseLog — @vertracloud/api-types */}
Retorna o log de crash registrado para uma release, para que você veja por que ela falhou ou travou depois de iniciar. O `content` é `null` quando a release não tem log ou quando o log expirou. Verifique `has_log` na [lista de releases](/pt-br/api-reference/endpoint/apps/releases/list) para saber antes.

<ParamField path="id" type="string" required>
  O ID da aplicação. Se a aplicação pertencer a um workspace, informe o ID dele no query parameter `workspace_id`.
</ParamField>

<ParamField path="release_id" type="string" required>
  O ID da release, como retornado pela [lista de releases](/pt-br/api-reference/endpoint/apps/releases/list).
</ParamField>

<ParamField query="workspace_id" type="string">
  Se a aplicação pertencer a um workspace, o ID do workspace.
</ParamField>

Exige o escopo `apps:read` quando chamado com uma chave de API.

### Resposta

<ResponseField name="response" type="object">
  Contém o log da release.

  <Expandable title="Mostrar objeto">

  <ResponseField name="content" type="string | null">
  O texto do log, ou `null` quando não há log para esta release ou ele expirou.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>
```json Response
{
  "response": {
    "content": "Error: Cannot find module 'express'\n    at Module._resolveFilename"
  }
}
```

```json Response (no log)
{
  "response": {
    "content": null
  }
}
```
</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
Códigos de erro possíveis:
- `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: o header `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
- `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: a chave de API é usada a partir de um IP fora da sua allowlist, ou não tem o escopo que a rota exige (`403`).
- `APP_NOT_FOUND`: a aplicação não existe, ou não pertence a esta conta ou workspace (`404`).
- `RELEASE_NOT_FOUND`: a release não existe, ou pertence a outra aplicação (`404`).
</ResponseField>

<ResponseField name="message" type="string">
  Uma mensagem descritiva com detalhes adicionais sobre o erro.
</ResponseField>

<ResponseExample>
```json
{
  "code": "RELEASE_NOT_FOUND"
}
```
</ResponseExample>
