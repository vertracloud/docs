authMethod: bearer
description: Baixa o arquivo ZIP de um snapshot específico de uma aplicação ou banco de dados. A resposta é o ZIP, qualquer que seja o tamanho.
---

{/* @see binary — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  O ID da aplicação ou do banco de dados.
</ParamField>

<ParamField path="snapshot_id" type="string" required>
  O ID do snapshot a baixar.
</ParamField>

<ParamField query="scope" type="string" required>
  O tipo do recurso. Valores possíveis: `applications`, `databases`.
</ParamField>

### Resposta

A resposta é o arquivo ZIP: `200` com o ZIP no corpo, para snapshots de qualquer tamanho.

```bash
curl -o snapshot.zip \
  -H "Authorization: Bearer $VERTRA_API_KEY" \
  "https://api.vertracloud.app/v1/users/{id}/snapshots/{snapshot_id}/download?scope=applications"
```

Exige o escopo `snapshots:read`.

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: o header `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: a chave de API é usada a partir de um IP fora da sua allowlist, ou não tem o escopo que a rota exige (`403`).
  - `USER_NOT_FOUND`: o usuário autenticado não foi encontrado.
  - `ACCESS_DENIED`: o snapshot não pertence ao usuário autenticado.
  - `TEMPLATE_CLOSED`: o snapshot é de uma aplicação de um [template fechado](/pt-br/templates/use/closed-templates) e não pode ser baixado (`403`).
  - `SNAPSHOT_TYPE_MISMATCH`: o tipo de recurso do snapshot não corresponde ao `scope` pedido (`400`).
  - `SNAPSHOT_NOT_FOUND`: o snapshot informado não existe.
  - `INTERNAL_SERVER_ERROR`: ocorreu um erro inesperado no servidor.
</ResponseField>
