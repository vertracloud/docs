---
title: Status de todas as aplicações
sidebarTitle: Status de todas as aplicações
api: GET https://api.vertracloud.app/v1/apps/status
authMethod: bearer
description: Retorna o status de todas as aplicações do usuário autenticado ou de um workspace específico.
---

{/* @see APIApplicationStatusShort[] — @vertracloud/api-types */}
<ParamField query="workspace_id" type="string">
  O ID do workspace para consultar o status das aplicações, se aplicável.
</ParamField>

### Resposta

<ResponseField name="response" type="array">
  Um array com um objeto de status para cada aplicação.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    O ID da aplicação.
  </ResponseField>

  <ResponseField name="cpu" type="string">
    Uso de CPU em porcentagem (por exemplo, `25.5%`).
  </ResponseField>

  <ResponseField name="ram" type="string">
    Uso de RAM (por exemplo, `512 MB`).
  </ResponseField>

  <ResponseField name="running" type="boolean">
    Indica se a aplicação está em execução.
  </ResponseField>

  <ResponseField name="installing" type="boolean">
    Presente e `true` enquanto as dependências estão sendo instaladas ou a aplicação está sendo recriada. Durante esse período, `running` pode ser `false` mesmo com trabalho em andamento.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": [
    {
      "id": "app-abc123def456",
      "cpu": "25.50%",
      "ram": "512.00 MB",
      "running": true
    },
    {
      "id": "app-xyz789mno012",
      "cpu": "0.00%",
      "ram": "0.00 MB",
      "running": false
    }
  ]
}
```

</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: o cabeçalho `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: a chave de API está sendo usada a partir de um IP fora da sua lista de permissões, ou não tem o escopo que a rota exige (`403`).
  - `WORKSPACE_NOT_FOUND`: o workspace especificado não existe.
  - `USER_NOT_IN_WORKSPACE`: o usuário não é membro do workspace especificado.
</ResponseField>

<ResponseField name="message" type="string">
  Uma mensagem descritiva com detalhes adicionais sobre o erro.
</ResponseField>

<ResponseExample>

```json Error Response (403)
{
  "code": "API_KEY_SCOPE_DENIED"
}
```

```json Error Response (404)
{
  "code": "WORKSPACE_NOT_FOUND"
}
```

```json Error Response (403)
{
  "code": "USER_NOT_IN_WORKSPACE"
}
```

</ResponseExample>
