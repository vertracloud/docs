---
title: Logs da aplicação
sidebarTitle: Logs da aplicação
api: GET https://api.vertracloud.app/v1/apps/{id}/logs
authMethod: bearer
description: Retorna os logs de uma aplicação pelo seu ID.
---

{/* @see string — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  O ID da aplicação cujos logs serão retornados. Se a aplicação pertencer a um workspace, informe o ID dele no query parameter `workspace_id`.
</ParamField>

<ParamField query="workspace_id" type="string">
  Se a aplicação pertencer a um workspace, o ID do workspace. Obrigatório para membros do workspace que agem sobre uma aplicação que não lhes pertence.
</ParamField>

### Resposta

<ResponseField name="response" type="string">
  O conteúdo dos logs da aplicação informada.
</ResponseField>

<ResponseExample>

```json Response
{
  "response": "2026-03-20T19:58:00Z [INFO] Application iniciada com sucesso\n2026-03-20T19:58:01Z [DEBUG] Connected to database\n2026-03-20T19:58:02Z [ERROR] Failed to process request"
}
```

</ResponseExample>
