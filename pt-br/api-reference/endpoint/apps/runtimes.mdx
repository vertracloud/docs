---
title: Listar runtimes
sidebarTitle: Runtimes
api: GET https://api.vertracloud.app/v1/apps/runtimes
authMethod: bearer
description: Retorna o catálogo de linguagens e runtimes suportados e suas versões disponíveis, para usar na criação de uma aplicação.
---
### Resposta

<ResponseField name="response" type="object">
  Um mapa do nome da linguagem para a sua entrada de runtime.

  <Expandable title="Mostrar objeto">

  <ResponseField name="recommended" type="string">
    A versão recomendada para novas aplicações.
  </ResponseField>

  <ResponseField name="latest" type="string">
    A versão mais recente disponível.
  </ResponseField>

  <ResponseField name="specific" type="array">
    Outras versões exatas que podem ser fixadas. Vazio para runtimes sem fixação de versão (por exemplo, `static`).
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "javascript": { "recommended": "22.23.4", "latest": "24.22.1", "specific": ["22.23.4", "24.22.1"] },
    "python": { "recommended": "3.13.17", "latest": "3.13.17", "specific": ["3.11.17", "3.12.15", "3.13.17"] },
    "deno": { "recommended": "2.9.8", "latest": "2.9.8", "specific": ["2.8.3", "2.9.8"] },
    "static": { "recommended": "latest", "latest": "latest", "specific": [] }
  }
}
```

</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: o header `Authorization` está ausente, a chave de API é inválida ou a sessão do painel foi revogada (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: a chave de API é usada a partir de um IP fora da sua allowlist, ou não tem o escopo que a rota exige (`403`).
  - `INTERNAL_SERVER_ERROR`: ocorreu um erro inesperado no servidor.
</ResponseField>

<ResponseExample>

```json Error Response (401)
{
  "code": "AUTH_TOKEN_MISSING"
}
```

</ResponseExample>
