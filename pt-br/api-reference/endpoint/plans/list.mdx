{/* @see RESTGetAPIPlansResponse, APIPlansCatalog — @vertracloud/api-types */}
Retorna os planos que você pode comprar hoje, com o preço, a memória, a vCPU, os limites e os recursos de cada um, e os períodos de cobrança com seus descontos. A rota é pública: não precisa de chave de API nem de sessão, então dá para chamá-la antes de a conta existir. Ela é limitada a 60 requisições por minuto por endereço IP, e a resposta pode ficar em cache por 60 segundos.

Use-a para montar uma tabela de preços ou para validar os nomes de plano que você envia em [Criar pedido](/pt-br/api-reference/endpoint/billing/create-order). O valor que a conta realmente paga vem de [Cotar pedido](/pt-br/api-reference/endpoint/billing/quote-order), porque pode incluir um cupom ou um preço mantido de um plano anterior.

### Resposta

<ResponseField name="response" type="object">
  <Expandable title="Toggle object">

  <ResponseField name="grid" type="string">
    A grade de planos em vigor: `v3` é a atual. `legacy` é a grade anterior, retornada apenas antes de a atual entrar à venda.
  </ResponseField>

  <ResponseField name="cycles" type="object[]">
    Os períodos de cobrança que você pode comprar e o desconto de cada um sobre o preço mensal.

    <Expandable title="Toggle object">
    <ResponseField name="months" type="integer">`1`, `3`, `6` or `12`.</ResponseField>
    <ResponseField name="discount_percent" type="number">Desconto sobre o preço mensal: 0, 10, 15 e 25 para 1, 3, 6 e 12 meses.</ResponseField>
    </Expandable>
  </ResponseField>

  <ResponseField name="plans" type="object[]">
    Os planos à venda, do menor para o maior.

    <Expandable title="Toggle object">
    <ResponseField name="name" type="string">O nome do plano, o valor que você envia em `plan` ao criar um pedido, como `starter-1`, `pro-4`, `business-12` ou `enterprise-32`.</ResponseField>
    <ResponseField name="family" type="string | null">`starter`, `pro`, `business` ou `enterprise`. `null` para um plano da grade anterior.</ResponseField>
    <ResponseField name="legacy" type="boolean">`true` para um plano da grade anterior, que não é mais vendido. É `false` em todos os planos quando `grid` é `v3`.</ResponseField>
    <ResponseField name="memory_mb" type="integer">A memória que a conta pode alocar entre suas aplicações e bancos de dados, em MB.</ResponseField>
    <ResponseField name="max_vcpus_per_app" type="number">O máximo de vCPU que uma aplicação pode usar no plano.</ResponseField>
    <ResponseField name="price" type="number">O preço mensal em BRL, sem nenhum desconto de período. O preço de um período é `price` vezes `months` vezes `(1 - discount_percent / 100)`, arredondado para o centavo.</ResponseField>
    <ResponseField name="payment_methods" type="string[]">`pix` e `card`.</ResponseField>

    <ResponseField name="limits" type="object">
      <Expandable title="Toggle object">
      <ResponseField name="deploys_per_hour" type="integer">Deploys por hora.</ResponseField>
      <ResponseField name="requests_per_minute" type="integer">Requisições de API por minuto com uma chave de API.</ResponseField>
      <ResponseField name="requests_per_day" type="integer">Requisições de API por dia com uma chave de API.</ResponseField>
      <ResponseField name="max_domains" type="integer">Domínios personalizados por aplicação.</ResponseField>
      <ResponseField name="max_domain_ports" type="integer">Portas além da 80 que uma aplicação com domínios pode servir.</ResponseField>
      <ResponseField name="manual_backups_per_day" type="integer">Backups manuais por conta por dia.</ResponseField>
      <ResponseField name="workspace_members" type="integer">Membros de um workspace.</ResponseField>
      <ResponseField name="workspace_roles" type="integer">Funções personalizadas de um workspace.</ResponseField>
      <ResponseField name="release_versions" type="integer">Versões guardadas para rollback.</ResponseField>
      <ResponseField name="release_retention_days" type="integer">Dias em que uma versão é guardada.</ResponseField>
      <ResponseField name="max_custom_images" type="integer">Imagens Docker personalizadas. `0` quando o plano não tem.</ResponseField>
      <ResponseField name="blob" type="object">
        Limites do Blob Storage: `quota_bytes`, `max_rules`, `max_custom_domains`, `image_transformations_per_month` e `s3_requests_per_10s`.
      </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="features" type="object">
      Booleanos do que o plano inclui: `web_published`, `daily_backups`, `create_backup`, `advanced_metrics`, `create_workspace`, `custom_domain`, `custom_subdomain`, `file_manager`, `database_manager`, `auto_deploy`, `rollback`, `auto_rollback`, `zero_downtime`, `delete_snapshot`, `powered_by_badge`, `blob_metadata`, `blob_share_password`, `blob_unlimited_upload_rate`, `blob_no_cache` e `blob_short_expiration`.
    </ResponseField>
    </Expandable>
  </ResponseField>

  </Expandable>
</ResponseField>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `RATE_LIMIT_EXCEEDED`: Mais de 60 requisições em um minuto do mesmo endereço IP (`429`). `details.retry_after` informa a espera.
  - `INTERNAL_SERVER_ERROR`: Ocorreu um erro inesperado no servidor.
</ResponseField>
