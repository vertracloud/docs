{/* @see RESTDeleteAPIWorkspaceResponse — @vertracloud/api-types */}
<Note>
  Uma chave de API precisa do escopo `workspaces:delete`. Ele não tem o sufixo `read` nem `write`, então
  os presets `read` e `write` nunca o incluem — só `full` ou uma seleção personalizada. A verificação
  de dono continua valendo: uma chave age como a conta que a possui.
</Note>

A exclusão é lógica: membros, papéis, convites e vínculos de aplicações e bancos de dados são
removidos, e o nome fica livre para ser reutilizado em um novo workspace.

### Caminho

<ParamField path="id" type="string" required>
  ID do workspace.
</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | Chamada com uma chave de API que não tem o escopo `workspaces:delete`. |
| 403 | `WORKSPACE_OWNER_ONLY` | Quem chama não é o dono. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou já foi apagado. |
