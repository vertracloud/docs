description: Remove um membro do workspace. Exige `members:manage`, ou que o próprio membro saia.
---

{/* @see RESTDeleteAPIWorkspaceMemberResponse — @vertracloud/api-types */}
Duas formas de chamar: quem chama tem `members:manage`, **ou** `user_id` é o ID do próprio chamador (o
caso de "sair do workspace"). Uma chave de API precisa do escopo `workspaces:write`.

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>
<ParamField path="user_id" type="string" required>ID do usuário do membro.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quem chama não tem `members:manage` e não está removendo a si mesmo. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
