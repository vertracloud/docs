description: Revoga um convite pendente. Exige `members:manage`; uma chave de API precisa do escopo `workspaces:invites`.
---

{/* @see RESTDeleteAPIWorkspaceInviteResponse — @vertracloud/api-types */}
<Note>
  Uma chave de API precisa do escopo `workspaces:invites` (só no preset `full` ou em uma seleção
  personalizada). Criar convites continua exclusivo do painel.
</Note>

Exige `members:manage`.

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>
<ParamField path="invite_id" type="string" required>ID do convite.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | Chamada com uma chave de API que não tem o escopo `workspaces:invites`. |
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quem chama não tem `members:manage`. |
| 404 | `WORKSPACE_INVITE_NOT_FOUND` | O convite não existe, já foi revogado, aceito ou esgotado, ou pertence a outro workspace. |
