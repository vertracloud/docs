api: POST https://api.vertracloud.app/v1/workspaces/invites/{token}/decline

description: Recusa um convite sem entrar no workspace. Qualquer conta logada; uma chave de API precisa do escopo `workspaces:invites`.
---

{/* @see RESTPostAPIWorkspaceInviteDeclineResponse — @vertracloud/api-types */}
<Note>
  Uma chave de API precisa do escopo `workspaces:invites` e age como a conta que a possui: um convite
  por e-mail só bate se o e-mail dessa conta for o convidado. Mesmo limite de 10/min por sessão e IP de
  [Visualizar convite](/pt-br/api-reference/endpoint/workspaces/invites/preview).
</Note>

### Caminho

<ParamField path="token" type="string" required>O token do convite.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | Chamada com uma chave de API que não tem o escopo `workspaces:invites`. |
| 404 | `WORKSPACE_INVITE_NOT_FOUND` | O token não existe, ou o convite já foi revogado, aceito ou esgotado. |
| 410 | `WORKSPACE_INVITE_EXPIRED` | O convite existiu, mas o prazo dele já passou. |
