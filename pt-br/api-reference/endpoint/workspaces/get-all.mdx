---
title: Listar workspaces
sidebarTitle: Listar
api: GET https://api.vertracloud.app/v1/workspaces
authMethod: bearer
description: Lista todos os workspaces que a conta autenticada possui ou dos quais é membro.
---

{/* @see APIWorkspace, RESTGetAPIWorkspacesResponse — @vertracloud/api-types */}
Disponível para qualquer conta logada — você não precisa de `members:read` em nenhum workspace para
listar os que você integra. Uma chave de API precisa do escopo `workspaces:read`.

### Resposta

<ResponseField name="response" type="APIWorkspace[]">
  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string" />
  <ResponseField name="name" type="string" />
  <ResponseField name="description" type="string | null" />
  <ResponseField name="owner_id" type="string" />
  <ResponseField name="owner" type="object">`{ display_name }` do dono.</ResponseField>
  <ResponseField name="members_count" type="number" />
  <ResponseField name="deleted_at" type="string | null" format="date-time">Marcador de exclusão lógica. Sempre `null` aqui — workspaces apagados não aparecem na lista.</ResponseField>
  <ResponseField name="created_at" type="string" format="date-time" />
  <ResponseField name="updated_at" type="string" format="date-time" />

  </Expandable>
</ResponseField>
