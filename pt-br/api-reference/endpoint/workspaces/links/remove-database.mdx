Mesmas regras de [Desvincular aplicação](/pt-br/api-reference/endpoint/workspaces/links/remove-app).

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>
<ParamField path="db_id" type="string" required>ID do banco de dados.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quem chama não é o dono do workspace. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
| 404 | `DATABASE_NOT_FOUND` | O banco de dados não está vinculado a este workspace. |
