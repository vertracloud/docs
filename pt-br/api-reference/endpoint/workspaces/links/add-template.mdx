{/* @see RESTPostAPIWorkspaceTemplateStackLinkResponse — @vertracloud/api-types */}
Move um dos seus templates privados para o workspace. As mesmas regras valem para uma stack em
`POST https://api.vertracloud.app/v1/workspaces/{id}/stacks/{stack_id}`; uma stack só é movida quando
todos os seus membros já estão no workspace. Mesmas regras de [Vincular aplicação](/pt-br/api-reference/endpoint/workspaces/links/add-app):
somente o dono, escopo `workspaces:write` para uma chave de API, e o recurso precisa pertencer a quem chama.

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>
<ParamField path="template_id" type="string" required>ID do template. Para uma stack, use `/stacks/{stack_id}` com o ID da stack.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quem chama não é o dono do workspace. |
| 403 | `PLAN_RESTRICTED_FEATURE` | O plano do dono está congelado. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
| 404 | `TEMPLATE_NOT_FOUND` | O template não existe ou não pertence a quem chama. |
| 404 | `STACK_NOT_FOUND` | A stack não existe ou não pertence a quem chama. |
| 409 | `STACK_MEMBER_CONFLICT` | Um membro da stack não está no workspace. |
