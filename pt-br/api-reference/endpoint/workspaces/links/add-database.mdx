{/* @see RESTPostAPIWorkspaceResourceLinkResponse — @vertracloud/api-types */}
Mesmas regras de [Vincular aplicação](/pt-br/api-reference/endpoint/workspaces/links/add-app): somente o dono,
escopo `workspaces:write` para uma chave de API, e o banco de dados precisa pertencer a quem chama.

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>
<ParamField path="db_id" type="string" required>ID do banco de dados. Precisa pertencer a quem chama.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quem chama não é o dono do workspace. |
| 403 | `PLAN_RESTRICTED_FEATURE` | O plano do dono está congelado. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
| 404 | `DATABASE_NOT_FOUND` | O banco de dados não existe ou não pertence a quem chama. |
