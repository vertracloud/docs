{/* @see RESTDeleteAPIWorkspaceTemplateStackLinkResponse — @vertracloud/api-types */}
Move o template de volta para a sua conta. O mesmo vale para uma stack em
`DELETE https://api.vertracloud.app/v1/workspaces/{id}/stacks/{stack_id}`. Mesmas regras de
[Desvincular aplicação](/pt-br/api-reference/endpoint/workspaces/links/remove-app): somente o dono, e uma chave de API
precisa do escopo `workspaces:write`. Nada é apagado.

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>
<ParamField path="template_id" type="string" required>ID do template. Para uma stack, use `/stacks/{stack_id}` com o ID da stack.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quem chama não é o dono do workspace. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
| 404 | `TEMPLATE_NOT_FOUND` | O template não está vinculado a este workspace. |
| 404 | `STACK_NOT_FOUND` | A stack não está vinculada a este workspace. |
