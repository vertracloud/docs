description: Remove uma aplicação do workspace. Somente o dono. Não apaga a aplicação.

{/* @see RESTDeleteAPIWorkspaceResourceLinkResponse — @vertracloud/api-types */}
Somente o **dono** do workspace. Uma chave de API precisa do escopo `workspaces:write`. A aplicação em
si não é alterada — ela só deixa de estar associada a este workspace e volta a ser um projeto pessoal do dono.

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>
<ParamField path="app_id" type="string" required>ID da aplicação.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Quem chama não é o dono do workspace. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
| 404 | `APP_NOT_FOUND` | A aplicação não está vinculada a este workspace. |
