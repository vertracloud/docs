{/* @see RESTDeleteAPIWorkspaceRoleResponse — @vertracloud/api-types */}
Exige `roles:manage`. Uma chave de API precisa do escopo `workspaces:write`.

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>
<ParamField path="role_id" type="string" required>ID do papel.</ParamField>

### Resposta

Resposta vazia em caso de sucesso.

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quem chama não tem `roles:manage`. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
| 404 | `WORKSPACE_ROLE_NOT_FOUND` | O `role_id` não pertence a este workspace. |
| 409 | `WORKSPACE_ROLE_IN_USE` | Um membro tem este papel, ou existe um convite pendente com ele. Reatribua ou revogue antes. |
