---
title: Listar papéis
sidebarTitle: Listar
api: GET https://api.vertracloud.app/v1/workspaces/{id}/roles
authMethod: bearer
description: Lista os papéis de um workspace. Exige a permissão `members:read`.
---

{/* @see APIWorkspaceRole, RESTGetAPIWorkspaceRolesResponse — @vertracloud/api-types */}
Exige `members:read` (não é um `roles:read` separado — ler a lista de papéis vem junto com ler os
membros). Uma chave de API precisa do escopo `workspaces:read`.

### Caminho

<ParamField path="id" type="string" required>ID do workspace.</ParamField>

### Erros

| Status | Código | Quando |
|---|---|---|
| 403 | `WORKSPACE_PERMISSION_DENIED` | Quem chama não tem `members:read`. |
| 404 | `WORKSPACE_NOT_FOUND` | O workspace não existe ou você não é membro. |
