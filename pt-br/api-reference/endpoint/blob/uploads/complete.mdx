{/* @see RESTPostAPIBlobUploadCompleteResponse, APIBlobObject — @vertracloud/api-types */}

Finaliza um upload direto. A API verifica se todas as partes estão armazenadas, se o tamanho total confere, se o checksum confere (caso você tenha enviado um) e se o conteúdo não é um executável. Depois disso, cria o objeto e o retorna. Enquanto esta chamada não der certo, o objeto não existe.

**Escopo:** `blob:write`. Aceita um token de upload.

**Token de upload:** esta rota também aceita um token de upload (`Authorization: Bearer vcup_...`) em vez de uma chave de API.

<ParamField path="upload_id" type="string" required>
  O ID do upload.
</ParamField>

<ParamField query="workspace_id" type="string">
  O ID do workspace, quando o blob pertence a um workspace. A chamada atua sobre o blob do dono do workspace e precisa da permissão de workspace `blob:read` (`blob:manage` nas rotas que alteram dados). Omita para atuar sobre o seu próprio blob.
</ParamField>

### Exemplo de requisição

```bash
curl -X POST "https://blob.vertracloud.app/v1/uploads/7c1d2e3f-4a5b-4c6d-8e7f-0a1b2c3d4e5f/complete" \
  -H "Authorization: Bearer $VERTRA_API_KEY"
```

### Resposta

<ResponseField name="response" type="object">
  O objeto do blob criado.
  <Expandable title="propriedades">
  <ResponseField name="id" type="string">ID estável do objeto. Ele nunca muda, mesmo quando o caminho, a visibilidade ou a expiração mudam.</ResponseField>
  <ResponseField name="path" type="string">Caminho completo dentro da conta, por exemplo `images/avatars/joao.png`.</ResponseField>
  <ResponseField name="size" type="number">Tamanho em bytes.</ResponseField>
  <ResponseField name="content_type" type="string">Tipo MIME, derivado no servidor a partir da extensão do arquivo.</ResponseField>
  <ResponseField name="etag" type="string">Entity tag do conteúdo armazenado.</ResponseField>
  <ResponseField name="sha256" type="string | null">SHA-256 do conteúdo em hexadecimal, quando o upload enviou um checksum. Caso contrário, `null`.</ResponseField>
  <ResponseField name="visibility" type="string">`public` (legível pela URL pública) ou `private` (precisa de um link temporário ou de um compartilhamento).</ResponseField>
  <ResponseField name="url" type="string | null">URL pública. `null` enquanto o objeto estiver privado.</ResponseField>
  <ResponseField name="cache_control" type="string | null">`immutable`, `max-age=<segundos>` ou `no-cache` (`no-cache` exige Enterprise-26 ou superior). `null` significa o padrão.</ResponseField>
  <ResponseField name="content_disposition" type="string">`inline` (exibido pelo navegador) ou `attachment` (baixado). HTML, SVG e XML são sempre `attachment`.</ResponseField>
  <ResponseField name="filename" type="string | null">Nome sugerido no download. `null` usa o último segmento de `path`.</ResponseField>
  <ResponseField name="metadata" type="object">Até 5 chaves, cada uma `[a-z0-9-]{1,64}`, 512 bytes no total. Enterprise-12 ou superior; `{}` nos outros planos.</ResponseField>
  <ResponseField name="expires_at" type="string | null">Quando o objeto é apagado, como timestamp ISO 8601. `null` significa sem expiração.</ResponseField>
  <ResponseField name="created_at" type="string">Data e hora de criação em ISO 8601.</ResponseField>
  <ResponseField name="updated_at" type="string">Data e hora da última alteração em ISO 8601.</ResponseField>
  </Expandable>
</ResponseField>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `AUTH_TOKEN_MISSING` (`401`): Nenhum header `Authorization` foi enviado.
  - `API_KEY_INVALID` (`401`): A chave de API não existe, foi revogada ou o segredo não confere.
  - `API_KEY_SCOPE_DENIED` (`403`): A chave não tem o escopo que a rota exige (`blob:read` ou `blob:write`); `details.required` informa qual.
  - `WORKSPACE_PERMISSION_DENIED` (`403`): Somente com `workspace_id`: você não é membro, ou seu papel não tem a permissão de blob.
  - `WORKSPACE_NOT_FOUND` (`404`): Somente com `workspace_id`: não existe workspace com esse ID, ou você não é membro.
  - `BLOB_UPLOAD_TOKEN_INVALID` (`401`): O token de upload não existe, expirou ou foi revogado (somente com token de upload).
  - `BLOB_UPLOAD_NOT_FOUND` (`404`): Nenhum upload com esse ID nesta conta, ou ele já foi concluído ou abortado.
  - `BLOB_UPLOAD_EXPIRED` (`410`): O prazo do upload passou. Inicie um novo upload.
  - `BLOB_UPLOAD_INCOMPLETE` (`409`): Faltam partes, ou o tamanho armazenado difere do `size` declarado.
  - `BLOB_CHECKSUM_MISMATCH` (`400`): O conteúdo armazenado não confere com o `checksum_sha256` enviado no início.
  - `BLOCKED_FILE_TYPE` (`422`): O conteúdo é um executável, detectado pelos seus bytes.
  - `BLOB_OBJECT_ALREADY_EXISTS` (`409`): O `path` foi ocupado por outro objeto enquanto o upload estava em andamento, e `overwrite` não é `true`.
</ResponseField>
