{/* @see APITemplateDetail, RESTGetAPITemplateQuery, RESTGetAPITemplateResponse — @vertracloud/api-types */}
Retorna um template, com tudo o que é preciso para pedir as respostas ao usuário e mostrar o que acontece em seguida. Templates públicos **não precisam de autenticação**. Um template privado fica visível apenas para o dono ou, quando pertence a um workspace, para os membros que podem ler as aplicações do workspace; para qualquer outra pessoa, a resposta é o mesmo `404` de um template que não existe. Com uma sessão ou uma chave de API (escopo `templates:read`), a resposta também traz o bloco `account`. Um template fechado nunca traz código. As leituras são limitadas a 60 requisições por minuto por cliente.

<ParamField path="template_id" type="string" required>
  O ID do template ou o slug dele. Templates ocultos e descontinuados são servidos aqui, mesmo que a galeria não os liste (veja `visibility`).
</ParamField>

<ParamField query="workspace_id" type="string">
  O workspace de um template privado. Necessário para resolver um template de workspace pelo **slug**; pelo ID é opcional.
</ParamField>

### Resposta

<ResponseField name="response" type="object">
  O template. Ele tem **todos os campos dos itens retornados por [Listar templates](/pt-br/api-reference/endpoint/templates/list)** (`id`, `slug`, `origin`, `visibility`, `name`, `description`, `category`, `tags`, `icon_url`, `author_display`, `links`, `landing`, `featured`, `current_version`, `services`, `creates_stack`, `ram_min_total`, `byok`, `required_plan`, `code_view`, `uses_count`, `owner`, `github`, `created_at`, `updated_at` e, quando autenticado, `account`), mais os abaixo.

  <Expandable title="Mostrar objeto">

  <ResponseField name="inputs" type="object[]">
    As perguntas que o usuário responde ao usar o template. Envie as respostas em `inputs` de [Fazer deploy de template](/pt-br/api-reference/endpoint/templates/deploy), pelo `id` de cada pergunta.

    <Expandable title="Mostrar objeto">

    <ResponseField name="id" type="string">
      O ID da pergunta, único no template.
    </ResponseField>

    <ResponseField name="type" type="string">
      `text`, `secret`, `select`, `boolean`, `number`, `url` ou `email`.
    </ResponseField>

    <ResponseField name="label" type="object">
      A pergunta nos três idiomas.
    </ResponseField>

    <ResponseField name="help" type="object">
      Explicação opcional, nos três idiomas.
    </ResponseField>

    <ResponseField name="required" type="boolean">
      Opcional, `false` quando ausente.
    </ResponseField>

    <ResponseField name="default" type="string | number | boolean">
      Resposta padrão opcional.
    </ResponseField>

    <ResponseField name="validation" type="object">
      Limites opcionais para a resposta: `regex`, `min`, `max`, `min_length` e `max_length`.
    </ResponseField>

    <ResponseField name="generate" type="string">
      Para perguntas `secret`: `random:<n>` ou `uuid`. A plataforma gera o valor quando a resposta é deixada vazia.
    </ResponseField>

    <ResponseField name="editable" type="boolean">
      `false` junto com `generate` significa que o valor gerado não pode ser substituído.
    </ResponseField>

    <ResponseField name="when" type="object">
      A pergunta só se aplica quando a resposta a outra coincide: `input` (o ID da outra pergunta) e `equals`.
    </ResponseField>

    <ResponseField name="options" type="object[]">
      Para perguntas `select`. Cada opção tem `value`, um `label` opcional e `sets` opcional, o que a escolha altera: `services` (um ID de serviço para `on` ou `off`), `env` (variáveis por serviço) e `ram_extra` (memória extra em MB por serviço).
    </ResponseField>

    </Expandable>
  </ResponseField>

  <ResponseField name="permissions" type="object">
    O que você pode fazer com uma aplicação criada a partir do template. Todos os valores são booleanos: `code_view`, `code_edit`, `ram_change`, `ram_below_min`, `ram_above_max`, `env_add`, `commands_edit`, `terminal`, `save_as_template` e `detach` (`true` quando editar o código desvincula a aplicação do template; somente em templates abertos). Veja [Templates fechados](/pt-br/templates/use/closed-templates).
  </ResponseField>

  <ResponseField name="outputs" type="object[]">
    O que é exibido ao final de um deploy. Cada um tem `label`, `value` (um texto ou um texto por idioma, que pode ser um placeholder), `secret` e `once` (o valor é exibido uma vez e nunca mais).
  </ResponseField>

  <ResponseField name="readme" type="object | null">
    A documentação do template em Markdown, por idioma, ou `null`.
  </ResponseField>

  <ResponseField name="changelog" type="object | null">
    O changelog da versão mais recente, por idioma, ou `null`.
  </ResponseField>

  </Expandable>
</ResponseField>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `VALIDATION_ERROR`: Um parâmetro não é válido (`400`).
  - `API_KEY_SCOPE_DENIED`: A chave de API não tem o escopo `templates:read` (`403`).
  - `TEMPLATE_NOT_FOUND`: O template não existe, foi removido ou não está visível para você (`404`).
  - `WORKSPACE_NOT_FOUND`: O workspace em `workspace_id` não existe ou você não faz parte dele (`404`).
  - `RATE_LIMIT_EXCEEDED`: Requisições demais (`429`).
  - `INTERNAL_SERVER_ERROR`: Falha inesperada (`500`).
</ResponseField>
