api: POST https://api.vertracloud.app/v1/templates/{template_id}/share-links
authMethod: bearer
description: Cria um link de compartilhamento para um template privado, no modo de uso ou de cópia completa, com limite de usos e validade opcionais.

{/* @see RESTPostAPITemplateShareLinkBody, RESTPostAPITemplateShareLinkResponse — @vertracloud/api-types */}
Esta chamada cria um link de compartilhamento para um template privado e responde `201` com o link e o token dele. **O token é mostrado somente nesta resposta e não pode ser recuperado**: guarde-o agora. Só um hash dele é mantido, e a resposta não é armazenada em cache. Um token começa com `vtpl_`.

Um link pode ter um de dois modos. Um link `use` permite que quem o abrir crie as próprias aplicações a partir do template, sem copiá-lo. Um link `full_copy` dá a essa pessoa um template privado próprio, independente do seu, que conta no limite dela de 5 templates privados. `full_copy` exige que `share.full_copy` esteja `true` no template, e não está disponível para um [template fechado](/pt-br/templates/use/closed-templates) nem para uma versão que tenha variáveis `env_hidden`. Leia [Links de compartilhamento](/pt-br/templates/create/share-links) antes de escolher.

Precisa do escopo `templates:write` quando chamada com uma chave de API. Só o dono do template pode criar links; em um workspace, um membro nem consegue listá-los. Quem recebe o link vê o aviso "Não verificado pela Vertra" na prévia.

<ParamField path="template_id" type="string" required>
  O ID do template.
</ParamField>

<ParamField query="workspace_id" type="string">
  Se o template pertencer a um workspace, o ID do workspace.
</ParamField>

<ParamField body="mode" type="string">
  `use` ou `full_copy`. Padrão `use`.
</ParamField>

<ParamField body="max_uses" type="integer">
  O número máximo de usos. Sem ele, não há limite. Um uso é contado quando alguém começa a criar a partir do link; um uso recusado ou desfeito é devolvido.
</ParamField>

<ParamField body="expires_in_days" type="integer">
  O número de dias até o link expirar. Sem ele, o link não expira.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.vertracloud.app/v1/templates/tpl-abc123def456/share-links \
  -H "Authorization: Bearer $VERTRA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "mode": "use", "max_uses": 10, "expires_in_days": 7 }'
```

</RequestExample>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `API_KEY_SCOPE_DENIED`: A chave de API não tem o escopo `templates:write` (`403`).
  - `TEMPLATE_NOT_FOUND`: O template não existe, foi excluído ou não é seu (`404`).
  - `TEMPLATE_SAVE_NOT_ALLOWED`: `full_copy` foi pedido e o template não permite (`share.full_copy` não é `true`) (`403`).
  - `TEMPLATE_CLOSED`: `full_copy` foi pedido para um template fechado (`403`).
  - `VALIDATION_ERROR`: `max_uses` ou `expires_in_days` não é um inteiro positivo (`400`).
  - `WORKSPACE_OWNER_ONLY`: Só o dono do workspace cria links dos templates dele.
</ResponseField>
