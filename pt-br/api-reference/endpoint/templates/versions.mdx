{/* @see APITemplateVersion, RESTGetAPITemplateVersionsResponse — @vertracloud/api-types */}
Retorna as versões prontas de um template, da mais nova para a mais antiga, até 100. Versões nunca mudam depois de publicadas. A visibilidade é a de [Obter template](/pt-br/api-reference/endpoint/templates/get): templates públicos não precisam de autenticação, um privado é visível só para o dono ou para leitores do workspace, e qualquer outra pessoa recebe `TEMPLATE_NOT_FOUND`. Com uma chave de API, o escopo é `templates:read`. As leituras são limitadas a 60 requisições por minuto por cliente.

<ParamField path="template_id" type="string" required>
  O ID do template ou o seu slug.
</ParamField>

<ParamField query="workspace_id" type="string">
  O workspace de um template privado. Necessário para resolver um template de workspace pelo slug.
</ParamField>

Você só pode fazer deploy de uma versão anterior quando o template permite; veja `version` em [Deploy de template](/pt-br/api-reference/endpoint/templates/deploy).

### Resposta

<ResponseField name="response" type="object[]">
  Um array de versões.

  <Expandable title="Mostrar objeto">

  <ResponseField name="id" type="string">
    O ID da versão.
  </ResponseField>

  <ResponseField name="version" type="string">
    A versão semântica, como `1.2.0`.
  </ResponseField>

  <ResponseField name="security" type="boolean">
    `true` para uma release de segurança. Donos de aplicações em uma versão anterior são avisados.
  </ResponseField>

  <ResponseField name="created_at" type="string" format="date-time">
    Quando a versão foi publicada.
  </ResponseField>

  <ResponseField name="changelog" type="object | null">
    O que mudou, como um texto por idioma (`pt-br`, `en`, `es`), ou `null`.
  </ResponseField>

  <ResponseField name="manifest" type="object | null">
    O manifesto da versão: `id`, `version`, `name`, `description`, `category`, `tags`, `inputs`, `services`, `permissions`, `outputs` e os outros campos descritos na [referência do manifesto](/pt-br/templates/create/manifest-reference). Valores de variáveis ocultas nunca são incluídos. Fica `null` quando o template está fechado e você não é o dono.
  </ResponseField>

  </Expandable>
</ResponseField>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `VALIDATION_ERROR`: Um parâmetro não é válido (`400`).
  - `API_KEY_SCOPE_DENIED`: A chave de API não tem o escopo `templates:read` (`403`).
  - `TEMPLATE_NOT_FOUND`: O template não existe, foi removido ou não é visível para você (`404`).
  - `WORKSPACE_NOT_FOUND`: O workspace em `workspace_id` não existe ou você não faz parte dele (`404`).
  - `RATE_LIMIT_EXCEEDED`: Requisições demais (`429`).
  - `INTERNAL_SERVER_ERROR`: Falha inesperada (`500`).
</ResponseField>
