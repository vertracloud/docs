---
title: Baixar o contexto da imagem
sidebarTitle: Baixar contexto
api: GET https://api.vertracloud.app/v1/images/{image_id}/context
authMethod: bearer
description: Retorna uma URL temporária para baixar o contexto de build atual de uma imagem.
---

{/* @see RESTGetAPICustomImageContextResult — @vertracloud/api-types */}
O contexto atual é o contexto de build completo do último build bem-sucedido, sem os arquivos `.env*`. Ele também é a base dos [commits](/pt-br/guides/custom-docker-images#commit-on-top-of-the-current-context).

Exige o escopo `images:read` quando chamada com uma chave de API.

<ParamField path="image_id" type="string" required>
  O ID da imagem.
</ParamField>

<ParamField query="workspace_id" type="string">
  Se a imagem pertencer a um workspace, o ID do workspace. Obrigatório para membros do workspace que atuam sobre uma imagem que não lhes pertence.
</ParamField>

### Resposta

<ResponseField name="response" type="object">
  <Expandable title="Mostrar objeto">

  <ResponseField name="url" type="string">
    Uma URL temporária para baixar o contexto de build atual como um arquivo ZIP.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "url": "https://api.vertracloud.app/..."
  }
}
```

</ResponseExample>

### Respostas de erro

<ResponseField name="code" type="string">
  O código de erro que indica o motivo da falha. Valores possíveis:
  - `API_KEY_SCOPE_DENIED`: A chave de API não tem o escopo exigido (`403`).
  - `IMAGE_NOT_FOUND`: A imagem não existe ou você não tem acesso a ela (`404`).
  - `INTERNAL_SERVER_ERROR`: Falha inesperada (`500`).
</ResponseField>

<ResponseExample>

```json Error Response
{
  "code": "IMAGE_NOT_FOUND"
}
```

</ResponseExample>
