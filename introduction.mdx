## What is Vertra Cloud?

Vertra Cloud is a Brazilian application hosting platform (PaaS): deploy from GitHub or a zip file,
isolated containers, managed databases, file storage, snapshots, a CLI and a VS Code extension.
Discord, WhatsApp and Telegram bots are first-class workloads. You write the code; the platform
builds the image, runs the container, routes the subdomain and keeps the snapshots.

This is the official documentation: how to deploy, what each plan includes, how the managed
databases work, and the full reference for the public REST API.

## What can you run on Vertra Cloud?

Applications in ten runtimes, four managed database engines, static and dynamic sites, and
background workers such as bots — each in its own container, with dedicated memory and storage.
