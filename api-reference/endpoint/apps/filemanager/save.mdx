api: PUT https://api.vertracloud.app/v1/apps/{id}/files
authMethod: bearer
description: Creates or updates a file or folder for an application by its ID.
---

{/* @see success/error — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  The ID of the application to create or update the file or folder in. If the application belongs to a workspace, pass its ID in the `workspace_id` query parameter.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the application belongs to a workspace, the workspace's ID. Members with an Owner, Admin or Developer role can use the file manager on a workspace app they don't own; without this, only the app's own owner can.
</ParamField>

<ParamField query="path" type="string" required>
  The path where the file or folder will be created or updated. End with `/` to create a folder.
</ParamField>

<ParamField body="content" type="string">
  The content of the file to create or update. Required for files, not applicable for folders.
</ParamField>

<ParamField body="last_modified" type="string">
  Optional ISO timestamp of the file's last known mtime, as returned by [`GET /files/content`](/api-reference/endpoint/apps/filemanager/content). When provided and it doesn't match the file's current mtime on disk, the save is rejected with `FILE_MODIFIED` instead of silently overwriting a newer version — use this to detect edit conflicts. Omit it to save unconditionally.
</ParamField>

### Response

A success returns `200` with `{ "response": null }`.

<ResponseExample>

```json Response
{
  "response": null
}
```

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for failure. Possible values:
  - `UNAUTHORIZED`: The user is not authenticated or lacks sufficient permissions.
  - `FORBIDDEN`: The user does not have permission to access the application.
  - `APP_NOT_FOUND`: The specified application does not exist.
  - `PLAN_RESTRICTED_FEATURE`: The user's plan does not support file manager access.
  - `MISSING_PATH`: The path query parameter was not provided.
  - `MISSING_CONTENT`: The content body parameter is required for files.
  - `INVALID_PATH`: The provided path is invalid.
  - `TARGET_IS_DIRECTORY`: The path already exists as a folder and can't be written to as a file.
  - `FILE_MODIFIED`: The file's current mtime doesn't match the `last_modified` sent — someone else changed it since it was last read. Reload the file before saving again.
  - `PUT_FILE_FAILED`: Failed to create or update the file or folder.
  - `OWNER_APP_WITHOUT_LIMITS`: The owner's plan limits could not be found.
</ResponseField>

<ResponseField name="message" type="string">
  A descriptive message providing additional details about the error.
</ResponseField>
