---
title: Delete Application File or Folder
sidebarTitle: Delete File or Folder
api: DELETE https://api.vertracloud.app/v1/apps/{id}/files
authMethod: bearer
description: Deletes a file or folder for an application by its ID.
---

{/* @see success/error — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  The ID of the application to delete the file or folder from. If the application belongs to a workspace, pass its ID in the `workspace_id` query parameter.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the application belongs to a workspace, the workspace's ID. Members with an Owner, Admin or Developer role can use the file manager on a workspace app they don't own; without this, only the app's own owner can.
</ParamField>

<ParamField query="path" type="string" required>
  The path to the file or folder to delete.
</ParamField>

<ParamField query="confirm_detach" type="boolean">
  Set to `true` to confirm that the change detaches an application that came from an open template (it stops receiving versions). Without it the request changes nothing and answers `409` `TEMPLATE_DETACH_CONFIRMATION_REQUIRED`. Ignored for other applications. See [Detach from a template](/api-reference/endpoint/templates/detach).
</ParamField>

### Response

A success returns `200` with `{ "response": null }`.

<ResponseExample>

```json Response
{
  "response": null
}
```

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for failure. Possible values:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: The `Authorization` header is missing, the API key is invalid, or the dashboard session was revoked (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: The API key is used from an IP outside its allowlist, or it lacks the scope the route requires (`403`).
  - `ACCESS_DENIED`: The resource belongs to another account, or you lack the workspace permission for it (`403`).
  - `FORBIDDEN`: The user does not have permission to access the application.
  - `APP_NOT_FOUND`: The specified application does not exist.
  - `PLAN_RESTRICTED_FEATURE`: The user's plan does not support file manager access.
  - `MISSING_PATH`: The path query parameter was not provided.
  - `FORBIDDEN_PATH`: The specified path is restricted.
  - `FILE_DELETE_FAILED`: Failed to delete the file or folder.
  - `TEMPLATE_DETACH_CONFIRMATION_REQUIRED`: The change would detach the application from its template and `confirm_detach` was not sent (`409`). Nothing was changed.
</ResponseField>

<ResponseField name="message" type="string">
  A descriptive message providing additional details about the error.
</ResponseField>
