title: Application Logs
sidebarTitle: Application Logs
api: GET https://api.vertracloud.app/v1/apps/{id}/logs
authMethod: bearer
description: Retrieves logs for an application by its ID.
---

{/* @see string — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  The application ID to retrieve real-time logs. If the application belongs to a workspace, pass its ID in the `workspace_id` query parameter.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the application belongs to a workspace, the workspace's ID. Required for workspace members acting on an application they don't own.
</ParamField>

### Response

<ResponseField name="response" type="string">
  The log content for the specified application.
</ResponseField>
