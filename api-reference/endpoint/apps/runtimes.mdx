---
title: List Runtimes
sidebarTitle: Runtimes
api: GET https://api.vertracloud.app/v1/apps/runtimes
authMethod: bearer
description: Returns the catalog of supported languages/runtimes and their available versions, for use when creating an application.
---
### Response

<ResponseField name="response" type="object">
  A map of language name to its runtime entry.

  <Expandable title="Toggle object">

  <ResponseField name="recommended" type="string">
    The recommended version for new applications.
  </ResponseField>

  <ResponseField name="latest" type="string">
    The latest available version.
  </ResponseField>

  <ResponseField name="specific" type="array">
    Other exact versions that can be pinned. Empty for runtimes without version pinning (e.g. `static`).
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "javascript": { "recommended": "22.23.4", "latest": "24.22.1", "specific": ["22.23.4", "24.22.1"] },
    "python": { "recommended": "3.13.17", "latest": "3.13.17", "specific": ["3.11.17", "3.12.15", "3.13.17"] },
    "deno": { "recommended": "2.9.8", "latest": "2.9.8", "specific": ["2.8.3", "2.9.8"] },
    "static": { "recommended": "latest", "latest": "latest", "specific": [] }
  }
}
```

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for failure. Possible values:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: The `Authorization` header is missing, the API key is invalid, or the dashboard session was revoked (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: The API key is used from an IP outside its allowlist, or it lacks the scope the route requires (`403`).
  - `INTERNAL_SERVER_ERROR`: An unexpected server error occurred.
</ResponseField>

<ResponseExample>

```json Error Response (401)
{
  "code": "AUTH_TOKEN_MISSING"
}
```

</ResponseExample>
