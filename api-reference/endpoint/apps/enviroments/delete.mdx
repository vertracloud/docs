---
title: Delete an Application Environment Variable
sidebarTitle: Delete Environment Variable
api: DELETE https://api.vertracloud.app/v1/apps/{id}/envs/{envId}
authMethod: bearer
description: Deletes one environment variable of an application by the variable's ID.
---

{/* @see success/error — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  The ID of the application.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the application belongs to a workspace, the workspace's ID. Required for workspace members acting on an application they don't own.
</ParamField>

<ParamField path="envId" type="string" required>
  The ID of the environment variable, as returned by
  [List Environment Variables](/api-reference/endpoint/apps/enviroments/get). There is no request body.
</ParamField>

### Response

A success returns `200` with `{ "response": null }`. The variable is removed from the application's
configuration; restart the application for the running process to stop seeing it.

```json Response
{
  "response": null
}
```

### Error Responses

<ResponseField name="code" type="string">
  - `APP_NOT_FOUND`: The application does not exist (`404`).
  - `ACCESS_DENIED`: Your account can't act on this application (`403`).
  - `ENV_NOT_FOUND`: No variable with that ID on this application (`404`).
</ResponseField>
