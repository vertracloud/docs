sidebarTitle: Delete
api: DELETE https://api.vertracloud.app/v1/users/me/api-keys/{id}
authMethod: bearer
description: Permanently deletes an API key. Dashboard session only.
---

{/* @see RESTDeleteAPIUserApiKeyResponse — @vertracloud/api-types */}
### Path

<ParamField path="id" type="string" required>
  The key's ID.
</ParamField>

### Response

Empty response on success (HTTP `200`).

### Errors

| Status | Code | When |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | The session is an API key. |
| 404 | `API_KEY_NOT_FOUND` | No key with that ID on this account. |
