---
title: Download Image Context
sidebarTitle: Download Context
api: GET https://api.vertracloud.app/v1/images/{image_id}/context
authMethod: bearer
description: Returns a temporary download URL for the current build context of an image.
---

{/* @see RESTGetAPICustomImageContextResult — @vertracloud/api-types */}
The current context is the full build context of the last successful build, with `.env*` files removed. It is also the base for [commits](/guides/custom-docker-images#commit-on-top-of-the-current-context).

Needs the `images:read` scope when called with an API key.

<ParamField path="image_id" type="string" required>
  The image ID.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the image belongs to a workspace, the workspace's ID. Required for workspace members acting on an image they don't own.
</ParamField>

### Response

<ResponseField name="response" type="object">
  <Expandable title="Toggle object">

  <ResponseField name="url" type="string">
    A temporary URL to download the current build context as a ZIP file.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "url": "https://api.vertracloud.app/..."
  }
}
```

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for the failure. Possible values:
  - `API_KEY_SCOPE_DENIED`: The API key does not have the required scope (`403`).
  - `IMAGE_NOT_FOUND`: The image does not exist or you cannot access it (`404`).
  - `INTERNAL_SERVER_ERROR`: Unexpected failure (`500`).
</ResponseField>

<ResponseExample>

```json Error Response
{
  "code": "IMAGE_NOT_FOUND"
}
```

</ResponseExample>
