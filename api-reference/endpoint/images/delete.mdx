---
title: Delete Image
sidebarTitle: Delete Image
api: DELETE https://api.vertracloud.app/v1/images/{image_id}
authMethod: bearer
description: Deletes an image, its versions, its context and every application created from it.
---

{/* @see RESTDeleteAPICustomImageBody, RESTDeleteAPICustomImageResult — @vertracloud/api-types */}
<Warning>
  Deleting an image **also deletes every application created from it**. Each app follows the usual rules for deleting an application, including the safety snapshot on plans that have it.
</Warning>

Needs the `images:delete` scope when called with an API key; `images:write` does not cover it. When the image has applications, the key also needs the `apps:delete` scope, because they are deleted too. Without it the call fails with `API_KEY_SCOPE_DENIED` and `details.required` set to `apps:delete`. Deleting is refused while a build is running, and it is allowed on plans that can no longer create images.

<ParamField path="image_id" type="string" required>
  The image ID.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the image belongs to a workspace, the workspace's ID. Required for workspace members acting on an image they don't own.
</ParamField>

<ParamField body="confirm_name" type="string" required>
  Must be equal to the image name.
</ParamField>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for the failure. Possible values:
  - `API_KEY_SCOPE_DENIED`: The API key does not have the `images:delete` scope, or the image has applications and the key does not have the `apps:delete` scope. `details.required` names the missing scope (`403`).
  - `IMAGE_NOT_FOUND`: The image does not exist or you cannot access it (`404`).
  - `IMAGE_NAME_MISMATCH`: `confirm_name` is not the image name (`400`).
  - `IMAGE_BUILD_IN_PROGRESS`: A build is running; wait for it to end (`409`).
  - `INTERNAL_SERVER_ERROR`: Unexpected failure (`500`).
</ResponseField>

</ResponseExample>
