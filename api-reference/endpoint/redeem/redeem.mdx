---
title: Redeem Code
sidebarTitle: Redeem Code
api: POST https://api.vertracloud.app/v1/redeem/{code}
authMethod: bearer
description: Redeems a plan code, applying its plan to the authenticated account.
---
<ParamField path="code" type="string" required>
  The redeem code.
</ParamField>

### Response

<ResponseField name="response" type="object">
  <Expandable title="Toggle object">

  <ResponseField name="plan" type="object">
    <Expandable title="Toggle object">
    <ResponseField name="name" type="string">The plan slug that was applied.</ResponseField>
    <ResponseField name="duration" type="integer">Duration granted, in days.</ResponseField>
    </Expandable>
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "plan": { "name": "pro", "duration": 30 }
  }
}
```

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for failure. Possible values:
  - `UNAUTHORIZED`: The user is not authenticated.
  - `INVALID_OR_EXPIRED_CODE`: The code does not exist, was already used, or has expired.
  - `INVALID_PLAN_NAME`: The code points to a plan that no longer exists.
  - `INTERNAL_SERVER_ERROR`: An unexpected server error occurred.
</ResponseField>

<ResponseExample>

```json Error Response (404)
{
  "code": "INVALID_OR_EXPIRED_CODE"
}
```

</ResponseExample>
