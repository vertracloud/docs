{/* @see RESTGetAPIPlansResponse, APIPlansCatalog — @vertracloud/api-types */}
Returns the plans you can buy today, with the price, memory, vCPU, limits and features of each one, and the billing periods with their discounts. The route is public: it needs no API key or session, so you can call it before an account exists. It is limited to 20 requests per minute per IP address, and the response can be cached for 10 minutes.

Use it to build a pricing table or to validate the plan names you send to [Create Order](/api-reference/endpoint/billing/create-order). The amount an account is actually charged comes from [Quote Order](/api-reference/endpoint/billing/quote-order), because it can include a coupon or a price kept from a previous plan.

### Response

<ResponseField name="response" type="object">
  <Expandable title="Toggle object">

  <ResponseField name="cycles" type="object[]">
    The billing periods you can buy and their discount over the monthly price.

    <Expandable title="Toggle object">
    <ResponseField name="months" type="integer">`1`, `3`, `6` or `12`.</ResponseField>
    <ResponseField name="discount_percent" type="number">Discount over the monthly price: 0, 10, 15 and 25 for 1, 3, 6 and 12 months.</ResponseField>
    </Expandable>
  </ResponseField>

  <ResponseField name="plans" type="object[]">
    The plans on sale, from the smallest to the largest.

    <Expandable title="Toggle object">
    <ResponseField name="name" type="string">The plan name, the value you send as `plan` when you create an order, such as `starter-1`, `pro-4`, `business-12` or `enterprise-32`.</ResponseField>
    <ResponseField name="family" type="string | null">`starter`, `pro`, `business` or `enterprise`. `null` for a plan that is no longer sold.</ResponseField>
    <ResponseField name="legacy" type="boolean">`true` for a plan that is no longer sold.</ResponseField>
    <ResponseField name="memory_mb" type="integer">The memory the account can allocate across its applications and databases, in MB.</ResponseField>
    <ResponseField name="max_vcpus_per_app" type="number">The most vCPU one application can use on the plan.</ResponseField>
    <ResponseField name="price" type="number">The monthly price in BRL, without any period discount. The price of a period is `price` times `months` times `(1 - discount_percent / 100)`, rounded to the cent.</ResponseField>
    <ResponseField name="payment_methods" type="string[]">`pix` and `card`.</ResponseField>

    <ResponseField name="limits" type="object">
      <Expandable title="Toggle object">
      <ResponseField name="deploys_per_hour" type="integer">Deploys per hour.</ResponseField>
      <ResponseField name="requests_per_minute" type="integer">API requests per minute with an API key.</ResponseField>
      <ResponseField name="requests_per_day" type="integer">API requests per day with an API key.</ResponseField>
      <ResponseField name="max_domains" type="integer">Custom domains per application.</ResponseField>
      <ResponseField name="max_domain_ports" type="integer">Ports besides 80 that an application with domains can serve.</ResponseField>
      <ResponseField name="manual_backups_per_day" type="integer">Manual backups per account per day.</ResponseField>
      <ResponseField name="workspace_members" type="integer">Members of a workspace.</ResponseField>
      <ResponseField name="workspace_roles" type="integer">Custom roles of a workspace.</ResponseField>
      <ResponseField name="release_versions" type="integer">Versions kept for rollback.</ResponseField>
      <ResponseField name="release_retention_days" type="integer">Days a version is kept.</ResponseField>
      <ResponseField name="max_custom_images" type="integer">Custom Docker images. `0` when the plan has none.</ResponseField>
      <ResponseField name="blob" type="object">
        Blob Storage limits: `quota_bytes`, `max_rules`, `max_custom_domains`, `image_transformations_per_month` and `s3_requests_per_10s`.
      </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="features" type="object">
      Booleans for what the plan includes: `web_published`, `daily_backups`, `create_backup`, `advanced_metrics`, `create_workspace`, `custom_domain`, `custom_subdomain`, `file_manager`, `database_manager`, `auto_deploy`, `rollback`, `auto_rollback`, `zero_downtime`, `delete_snapshot`, `powered_by_badge`, `blob_metadata`, `blob_share_password`, `blob_unlimited_upload_rate`, `blob_no_cache` and `blob_short_expiration`.
    </ResponseField>
    </Expandable>
  </ResponseField>

  </Expandable>
</ResponseField>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for failure. Possible values:
  - `RATE_LIMIT_EXCEEDED`: More than 20 requests in a minute from the same IP address (`429`). `details.retry_after` gives the wait.
  - `INTERNAL_SERVER_ERROR`: An unexpected server error occurred.
</ResponseField>
