{/* @see RESTPostAPIWorkspaceTemplateStackLinkResponse — @vertracloud/api-types */}
Moves one of your private templates to the workspace. The same rules apply to a stack on `POST https://api.vertracloud.app/v1/workspaces/{id}/stacks/{stack_id}`; a stack moves only when all its members are already in the workspace. Same rules as [Link Application](/api-reference/endpoint/workspaces/links/add-app): owner only, `workspaces:write` scope for an API key, and the resource must be owned by the caller.

### Path

<ParamField path="id" type="string" required>Workspace ID.</ParamField>
<ParamField path="template_id" type="string" required>Template ID. For a stack, use `/stacks/{stack_id}` with the stack ID instead.</ParamField>

### Response

Empty response on success.

### Errors

| Status | Code | When |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Caller isn't the workspace owner. |
| 403 | `PLAN_RESTRICTED_FEATURE` | Owner's plan is frozen. |
| 404 | `WORKSPACE_NOT_FOUND` | Workspace doesn't exist or you're not a member. |
| 404 | `TEMPLATE_NOT_FOUND` | The template doesn't exist or isn't owned by the caller. |
| 404 | `STACK_NOT_FOUND` | The stack doesn't exist or isn't owned by the caller. |
| 409 | `STACK_MEMBER_CONFLICT` | A member of the stack is not in the workspace. |
