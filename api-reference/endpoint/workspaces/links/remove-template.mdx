{/* @see RESTDeleteAPIWorkspaceTemplateStackLinkResponse — @vertracloud/api-types */}
Moves the template back to your account. The same applies to a stack on `DELETE https://api.vertracloud.app/v1/workspaces/{id}/stacks/{stack_id}`. Same rules as [Unlink Application](/api-reference/endpoint/workspaces/links/remove-app): owner only, and an API key needs the `workspaces:write` scope. Nothing is deleted.

### Path

<ParamField path="id" type="string" required>Workspace ID.</ParamField>
<ParamField path="template_id" type="string" required>Template ID. For a stack, use `/stacks/{stack_id}` with the stack ID instead.</ParamField>

### Response

Empty response on success.

### Errors

| Status | Code | When |
|---|---|---|
| 403 | `WORKSPACE_OWNER_ONLY` | Caller isn't the workspace owner. |
| 404 | `WORKSPACE_NOT_FOUND` | Workspace doesn't exist or you're not a member. |
| 404 | `TEMPLATE_NOT_FOUND` | The template isn't linked to this workspace. |
| 404 | `STACK_NOT_FOUND` | The stack isn't linked to this workspace. |
