---
title: List Workspaces
sidebarTitle: List
api: GET https://api.vertracloud.app/v1/workspaces
authMethod: bearer
description: Lists every workspace the authenticated account owns or is a member of.
---

{/* @see APIWorkspace, RESTGetAPIWorkspacesResponse — @vertracloud/api-types */}
Available to any logged-in account — you don't need `members:read` on any workspace to list the
ones you belong to. An API key needs the `workspaces:read` scope.

### Response
