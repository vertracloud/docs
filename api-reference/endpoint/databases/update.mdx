---

{/* @see APIDatabase — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  The ID of the database to update.
</ParamField>


<ParamField query="workspace_id" type="string">
  If the database belongs to a workspace, the workspace's ID.
</ParamField>

<ParamField body="name" type="string">
  The new name for the database. 1 to 50 characters.
</ParamField>

<ParamField body="description" type="string | null">
  The new description, up to 128 characters. An empty string or `null` clears it.
</ParamField>

<ParamField body="ram" type="number">
  The new RAM in MB, a positive integer. It must fit in the plan's free memory and respect the
  engine's minimum (512 MB for Redis, 1024 MB for the others).
</ParamField>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for failure. Possible values:
  - `VALIDATION_ERROR`: A body or query field failed validation (`400`).
  - `INVALID_RAM_LIMIT`: The requested RAM is outside what the engine and plan allow (`400`).
  - `INSUFFICIENT_MEMORY`: The plan doesn't have enough free memory for the new RAM (`400`).
  - `ACCESS_DENIED`: Your account can't act on this database (`403`).
  - `DATABASE_NOT_FOUND`: The database does not exist (`404`).
  - `OPERATION_IN_PROGRESS`: Another lifecycle operation is running on this database (`409`).
</ResponseField>
