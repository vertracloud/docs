title: Delete Database
sidebarTitle: Delete Database
api: DELETE https://api.vertracloud.app/v1/databases/{id}
authMethod: bearer
description: Deletes a database by its ID, right away and for good. Take a snapshot first if you may need its data again. Requires the databases:delete scope.
---
Deletes the database right away. It is permanent: there is no undo, so [create a snapshot](/api-reference/endpoint/apps/snapshots/create)
first if you may need its data again. Snapshots you already have stay available. An API key needs the `databases:delete` scope.

<ParamField path="id" type="string" required>
  The ID of the database to delete.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the database belongs to a workspace, the workspace's ID.
</ParamField>

### Response

<ResponseField name="response" type="string">
  The ID of the deleted database.
</ResponseField>

<ResponseExample>

```json Response
{
  "response": "00000000000000000000000000000001"
}
```

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  - `DATABASE_NOT_FOUND`: The database was not found (`404`).
  - `ACCESS_DENIED`: You are a workspace member without the permission for this action, or you did not send the `workspace_id` (`403`).
  - `OPERATION_IN_PROGRESS`: Another lifecycle operation is running on this database (`409`).
  - `INTERNAL_SERVER_ERROR`: The platform could not remove the database; retry later (`500`).
</ResponseField>
