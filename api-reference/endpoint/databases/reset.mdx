{/* @see success — @vertracloud/api-types */}
<ParamField path="id" type="string" required>
  The ID of the database to reset.
</ParamField>

### Response

<ResponseField name="response" type="string">
  The response message, indicating successful operation.
</ResponseField>

<ResponseExample>

```json Response
{
  "response": "success"
}
```

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for failure. Possible values:
  - `AUTH_TOKEN_MISSING`, `API_KEY_INVALID`, `SESSION_REVOKED`: The `Authorization` header is missing, the API key is invalid, or the dashboard session was revoked (`401`).
  - `API_KEY_IP_DENIED`, `API_KEY_SCOPE_DENIED`: The API key is used from an IP outside its allowlist, or it lacks the scope the route requires (`403`).
  - `ACCESS_DENIED`: The resource belongs to another account, or you lack the workspace permission for it (`403`).
  - `DATABASE_NOT_FOUND`: The specified database does not exist or the user lacks access.
  - `DATABASE_ID_REQUIRED`: The database ID was not provided.
  - `SNAPSHOT_FAILED`: The safety snapshot could not be taken; the database was not reset. Contact support (`500`).
  - `INTERNAL_SERVER_ERROR`: Failed to reset the database.
</ResponseField>

<ResponseField name="message" type="string">
  A descriptive message providing additional details about the error.
</ResponseField>


</ResponseExample>
