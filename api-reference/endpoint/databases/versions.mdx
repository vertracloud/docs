---
title: List Database Versions
sidebarTitle: Versions
api: GET https://api.vertracloud.app/v1/databases/versions
authMethod: bearer
description: Returns the versions available for new databases of each engine, and the recommended one, for use when creating a database.
---
{/* @see RESTGetAPIDatabaseVersionsResponse — @vertracloud/api-types */}
### Response

<ResponseField name="response" type="object">
  A map of database engine `type` (`1` PostgreSQL, `2` MongoDB, `3` Redis, `4` MySQL) to its version entry.

  <Expandable title="Toggle object">

  <ResponseField name="recommended" type="string">
    The recommended version, used when `version` is omitted on creation.
  </ResponseField>

  <ResponseField name="available" type="array">
    Every version that can be chosen for a new database of this engine.
  </ResponseField>

  </Expandable>
</ResponseField>

<ResponseExample>

```json Response
{
  "response": {
    "1": { "recommended": "18", "available": ["18", "17"] },
    "2": { "recommended": "8.0", "available": ["9.0", "8.0"] },
    "3": { "recommended": "8.2", "available": ["8.2", "7.2"] },
    "4": { "recommended": "9.7", "available": ["9.7", "8.4"] }
  }
}
```

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for failure. Possible values:
  - `UNAUTHORIZED`: The user is not authenticated.
  - `RATE_LIMIT_EXCEEDED`: Too many requests; retry after the time in `retry_after`.
  - `INTERNAL_SERVER_ERROR`: An unexpected server error occurred.
</ResponseField>

<ResponseExample>

```json Error Response (401)
{
  "code": "UNAUTHORIZED"
}
```

</ResponseExample>
