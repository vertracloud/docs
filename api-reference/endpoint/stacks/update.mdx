{/* @see RESTPatchAPIStackBody, RESTPatchAPIStackResponse — @vertracloud/api-types */}
Changes the name or the description of a stack. At least one field is required. Needs the `stacks:write` scope when called with an API key.

<ParamField path="stack_id" type="string" required>
  The stack ID.
</ParamField>

<ParamField query="workspace_id" type="string">
  The workspace the stack belongs to, when you act on it as the workspace owner.
</ParamField>

<ParamField body="name" type="string">
  The new name.
</ParamField>

<ParamField body="description" type="string | null">
  The new description. `null` removes it.
</ParamField>

### Response

<ResponseField name="response" type="object">
  The updated stack, with the same fields as [Get Stack](/api-reference/endpoint/stacks/get).
</ResponseField>

<RequestExample>

```bash cURL
curl -X PATCH https://api.vertracloud.app/v1/stacks/stk-abc123def456 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "name": "shop-prod" }'
```

</RequestExample>

### Errors

| Status | Code | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | No field was sent, or a value is invalid. |
| 403 | `WORKSPACE_OWNER_ONLY` | You are a workspace member, not the owner. |
| 404 | `STACK_NOT_FOUND` | The stack does not exist or belongs to another account. |
