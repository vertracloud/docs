---
title: Set Stack Network Mode
sidebarTitle: Network Mode
api: POST https://api.vertracloud.app/v1/stacks/{stack_id}/network-mode
authMethod: bearer
description: Sets how the members of a stack reach each other. The accepted mode is `public`.
---

{/* @see RESTPostAPIStackNetworkModeBody, RESTPostAPIStackNetworkModeResponse — @vertracloud/api-types */}
Only `public` is accepted: the members use the public addresses of the services, and databases are reached with client certificates. Any other value fails with `STACK_NETWORK_MODE_UNAVAILABLE`. Needs the `stacks:write` scope when called with an API key.

<ParamField path="stack_id" type="string" required>
  The stack ID.
</ParamField>

<ParamField query="workspace_id" type="string">
  The workspace the stack belongs to, when you act on it as the workspace owner.
</ParamField>

<ParamField body="network_mode" type="string" required>
  `public`.
</ParamField>

### Response

The stack, as in [Get Stack](/api-reference/endpoint/stacks/get).

### Errors

| Status | Code | When |
|---|---|---|
| 400 | `STACK_NETWORK_MODE_UNAVAILABLE` | The mode is not `public`. |
| 403 | `WORKSPACE_OWNER_ONLY` | You are a workspace member, not the owner. |
| 404 | `STACK_NOT_FOUND` | The stack does not exist or belongs to another account. |
