{/* @see RESTGetAPIStacksResponse, APIStack — @vertracloud/api-types */}
Returns every stack you own, or the stacks of a workspace when you pass `workspace_id`. A stack groups applications, databases and Blob folders and the connections between them. See [Stacks](/templates/use/stacks) for the concept.

Needs the `stacks:read` scope when called with an API key.

<ParamField query="workspace_id" type="string">
  List the stacks of this workspace instead of your own. Workspace members can read stacks; only the owner can change them.
</ParamField>

### Response

<ResponseField name="response" type="object[]">
  An array of stacks. Each item has the same shape as the object returned by [Get Stack](/api-reference/endpoint/stacks/get).
</ResponseField>

### Errors

| Status | Code | When |
|---|---|---|
| 403 | `API_KEY_SCOPE_DENIED` | The key does not have `stacks:read`. |
| 404 | `WORKSPACE_NOT_FOUND` | The workspace does not exist or you are not a member. |
