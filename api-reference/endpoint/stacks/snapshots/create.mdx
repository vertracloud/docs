{/* @see RESTPostAPIStackSnapshotResponse, APIStackSnapshot — @vertracloud/api-types */}
Takes a snapshot of each application and database of the stack and groups them. The plan's snapshot rules and windows apply, as for [snapshots of a single resource](/api-reference/endpoint/apps/snapshots/create). Needs the `stacks:write` scope when called with an API key.

<ParamField path="stack_id" type="string" required>
  The stack ID.
</ParamField>

<ParamField query="workspace_id" type="string">
  The workspace the stack belongs to, when you act on it as the workspace owner.
</ParamField>

### Response

The snapshot created, with the same fields as an item of [List Stack Snapshots](/api-reference/endpoint/stacks/snapshots/list), with `reason` set to `manual`.

### Errors

| Status | Code | When |
|---|---|---|
| 403 | `PLAN_RESTRICTED_FEATURE` | The plan does not include manual snapshots. |
| 403 | `WORKSPACE_OWNER_ONLY` | You are a workspace member, not the owner. |
| 404 | `STACK_NOT_FOUND` | The stack does not exist or belongs to another account. |
