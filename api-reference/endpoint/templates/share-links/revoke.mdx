{/* @see RESTDeleteAPITemplateShareLinkResponse — @vertracloud/api-types */}
This call revokes a share link: it accepts no new use and stops offering updates to what was created from it. Applications and stacks already created from the link keep running, and copies already made stay with their owners. Revoking is idempotent: revoking a revoked link answers with the link as it is.

Needs the `templates:write` scope when called with an API key. Only the owner of the template can revoke its links.

<ParamField path="template_id" type="string" required>
  The template ID.
</ParamField>

<ParamField path="link_id" type="string" required>
  The link ID.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the template belongs to a workspace, the workspace's ID.
</ParamField>

<RequestExample>

```bash cURL
curl -X DELETE https://api.vertracloud.app/v1/templates/tpl-abc123def456/share-links/lnk-abc123def456 \
  -H "Authorization: Bearer $VERTRA_API_KEY"
```

</RequestExample>

### Response

<ResponseField name="response" type="object">
  The link, with `revoked_at` filled.

  <Expandable title="Toggle object">

  <ResponseField name="id" type="string">
    The link ID.
  </ResponseField>

  <ResponseField name="template_id" type="string">
    The template the link belongs to.
  </ResponseField>

  <ResponseField name="mode" type="string">
    `use` or `full_copy`.
  </ResponseField>

  <ResponseField name="last4" type="string">
    The last 4 characters of the token, to tell links apart.
  </ResponseField>

  <ResponseField name="uses" type="integer">
    How many times the link was used.
  </ResponseField>

  <ResponseField name="max_uses" type="integer | null">
    The maximum number of uses, or `null` for no limit.
  </ResponseField>

  <ResponseField name="expires_at" type="string | null" format="date-time">
    When the link expires, or `null` when it does not expire.
  </ResponseField>

  <ResponseField name="revoked_at" type="string | null" format="date-time">
    When the author revoked the link, or `null`.
  </ResponseField>

  <ResponseField name="created_at" type="string" format="date-time">
    When the link was created.
  </ResponseField>

  </Expandable>
</ResponseField>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for the failure. Possible values:
  - `API_KEY_SCOPE_DENIED`: The API key does not have the `templates:write` scope (`403`).
  - `TEMPLATE_NOT_FOUND`: The template does not exist or is not yours (`404`).
  - `SHARE_LINK_NOT_FOUND`: The link does not exist in that template (`404`).
  - `WORKSPACE_OWNER_ONLY`: Only the workspace owner revokes the links of its templates.
</ResponseField>

<ResponseExample>

```json Error Response
{
  "code": "SHARE_LINK_NOT_FOUND"
}
```

</ResponseExample>
