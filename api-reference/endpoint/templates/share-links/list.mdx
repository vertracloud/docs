title: List the Share Links of a Template
sidebarTitle: List Links
api: GET https://api.vertracloud.app/v1/templates/{template_id}/share-links

description: Lists the share links of a private template with their mode, uses, limit, expiry and revocation, without the tokens.
---

{/* @see RESTGetAPITemplateShareLinksResponse — @vertracloud/api-types */}
This call lists every share link of a private template, including revoked and expired ones, so you can see how each is used. Tokens are never returned again: each link shows only the last 4 characters (`last4`) to tell them apart.

Needs the `templates:read` scope when called with an API key. Only the owner of the template can list its links; a workspace member cannot.

<ParamField path="template_id" type="string" required>
  The template ID.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the template belongs to a workspace, the workspace's ID.
</ParamField>

<RequestExample>

```bash cURL
curl https://api.vertracloud.app/v1/templates/tpl-abc123def456/share-links \
  -H "Authorization: Bearer $VERTRA_API_KEY"
```

</RequestExample>

### Response

<ResponseField name="response" type="object[]">
  The links.

  <Expandable title="Toggle object">

  <ResponseField name="id" type="string">
    The link ID.
  </ResponseField>

  <ResponseField name="template_id" type="string">
    The template the link belongs to.
  </ResponseField>

  <ResponseField name="mode" type="string">
    `use` or `full_copy`.
  </ResponseField>

  <ResponseField name="last4" type="string">
    The last 4 characters of the token, to tell links apart.
  </ResponseField>

  <ResponseField name="uses" type="integer">
    How many times the link was used.
  </ResponseField>

  <ResponseField name="max_uses" type="integer | null">
    The maximum number of uses, or `null` for no limit.
  </ResponseField>

  <ResponseField name="expires_at" type="string | null" format="date-time">
    When the link expires, or `null` when it does not expire.
  </ResponseField>

  <ResponseField name="revoked_at" type="string | null" format="date-time">
    When the author revoked the link, or `null`.
  </ResponseField>

  <ResponseField name="created_at" type="string" format="date-time">
    When the link was created.
  </ResponseField>

  </Expandable>
</ResponseField>

</ResponseExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for the failure. Possible values:
  - `API_KEY_SCOPE_DENIED`: The API key does not have the `templates:read` scope (`403`).
  - `TEMPLATE_NOT_FOUND`: The template does not exist or is not yours (`404`).
  - `WORKSPACE_OWNER_ONLY`: Only the workspace owner lists the links of its templates.
</ResponseField>

<ResponseExample>

```json Error Response
{
  "code": "TEMPLATE_NOT_FOUND"
}
```

</ResponseExample>
