{/* @see RESTPostAPITemplateShareCopyBody, RESTPostAPITemplateShareCopyResponse — @vertracloud/api-types */}
This call turns a `full_copy` link into a private template that belongs to you and answers `201` with it. Nothing links the copy to the author afterwards: if the author deletes the template, the image or the account, your copy does not change, and you get no updates from the original. The code and any image are copied to your account, secrets the author hid never come with it, and the author's name stays as the credit. The copy counts against your limit of 5 private templates and, for a template with images, takes one image slot per distinct image.

It requires an account (a session or an API key with the `templates:write` scope). The plan rules of [Create a Private Template](/api-reference/endpoint/templates/create) apply to you, and in a workspace only its owner can receive a copy. The permission is checked at the moment of the call: if the author removed `share.full_copy` after creating the link, the call fails with `SHARE_LINK_REVOKED` and no use is spent. A `use` link is refused here with `400`: use [Use Link](/api-reference/endpoint/templates/share-links/deploy).

<ParamField path="token" type="string" required>
  The token of the link.
</ParamField>

<ParamField body="workspace_id" type="string">
  The workspace that will own the copy. Without it, the copy is yours.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.vertracloud.app/v1/share/templates/vtpl_EXAMPLE_TOKEN/copy \
  -H "Authorization: Bearer $VERTRA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

</RequestExample>

### Response

The private template of [Create a Private Template](/api-reference/endpoint/templates/create), with `201 Created`. Its `slug` is the original one, or the first free of `<slug>-copy`, `<slug>-copy-2` and so on; `author_display` credits the original author.

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for the failure. Possible values:
  - `API_KEY_SCOPE_DENIED`: The API key does not have the `templates:write` scope (`403`).
  - `SHARE_LINK_NOT_FOUND`: The token has the wrong form, does not exist, or its template was deleted (`404`).
  - `SHARE_LINK_REVOKED`: The link was revoked, or the author no longer allows full copies (`410`).
  - `SHARE_LINK_EXPIRED`, `SHARE_LINK_EXHAUSTED`: The link expired or reached `max_uses` (`410`).
  - `TEMPLATE_PRIVATE_LIMIT_REACHED`: You already have 5 private templates.
  - `PLAN_DOES_NOT_SUPPORT_CUSTOM_IMAGES`: Your plan cannot create templates.
  - `TEMPLATE_IMAGE_SLOTS_EXHAUSTED`: The copy needs more image slots than you have free.
  - `WORKSPACE_OWNER_ONLY`: Only the workspace owner receives a copy in it.
</ResponseField>
