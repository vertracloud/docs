{/* @see RESTPostAPITemplateShareDeployBody, RESTPostAPITemplateShareDeployResponse — @vertracloud/api-types */}
This call creates, as one operation, everything the template behind a `use` link describes, and answers `202` with a job in `status: "queued"`. If any step fails, everything the job created is removed. Follow the job with [Get Template Deploy](/api-reference/endpoint/templates/deploy-status) or its [event stream](/api-reference/endpoint/templates/deploy-events). The body is the same as [using a catalog template](/api-reference/endpoint/templates/deploy), without the choice of version: the link gives one version.

It requires an account (a session or an API key with the `templates:deploy` scope), and only the owner of a workspace can use a template in it; a member gets `WORKSPACE_OWNER_ONLY`. A `full_copy` link is refused here with `400`: use [Copy Template from Link](/api-reference/endpoint/templates/share-links/copy). Each call uses one of the link's uses; a call that does not end in a new job gives the use back, and so does a job that is undone. Preview the link first with [Preview Link](/api-reference/endpoint/templates/share-links/preview). The applications created from a link can later be reported by their owner and offer updates only while the link is alive.

<ParamField path="token" type="string" required>
  The token of the link.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Makes the call safe to repeat: the same key with the same request returns the same job (`200`) and spends no second use, and the same key with a different request returns `IDEMPOTENCY_KEY_CONFLICT`. Recommended on every call.
</ParamField>

<ParamField body="name" type="string" required>
  The name of the application, or of the stack when the template has more than one service.
</ParamField>

<ParamField body="description" type="string">
  The description.
</ParamField>

<ParamField body="inputs" type="object">
  The answers to the questions of the template, by question id. A value is a string, a number or a boolean.
</ParamField>

<ParamField body="services" type="object">
  Choices per service, by service id. Each can have `name`, `ram` (MB, within what the template allows) and `subdomain` (`"random"` or the one you want, for an application with web).
</ParamField>

<ParamField body="network_mode" type="string">
  Only `public` is accepted. Any other value fails with `STACK_NETWORK_MODE_UNAVAILABLE`.
</ParamField>

<ParamField body="workspace_id" type="string">
  The workspace that will own what is created.
</ParamField>

<ParamField body="folder_id" type="string">
  The folder to put the application or stack in.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.vertracloud.app/v1/share/templates/vtpl_EXAMPLE_TOKEN/deploy \
  -H "Authorization: Bearer $VERTRA_API_KEY" \
  -H "Idempotency-Key: 6f1c2d3e-0000-4000-8000-000000000001" \
  -H "Content-Type: application/json" \
  -d '{ "name": "support-bot", "inputs": { "discord_token": "..." } }'
```

</RequestExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for the failure. Possible values:
  - `API_KEY_SCOPE_DENIED`: The API key does not have the `templates:deploy` scope (`403`).
  - `SHARE_LINK_NOT_FOUND`: The token has the wrong form, does not exist, or its template was deleted (`404`).
  - `SHARE_LINK_REVOKED`, `SHARE_LINK_EXPIRED`, `SHARE_LINK_EXHAUSTED`: The link was revoked, expired, or reached `max_uses` (`410`).
  - `TEMPLATE_INPUT_INVALID`: An answer is missing or invalid.
  - `TEMPLATE_PLAN_REQUIRED`: The plan of the account does not cover the template (`403`); `details.reason` says why.
  - `TEMPLATE_RAM_INSUFFICIENT`: Not enough free memory for the template (`400`).
  - `TEMPLATE_IMAGE_SLOTS_EXHAUSTED`: The template needs more custom image slots than the account has free (`403`).
  - `TEMPLATE_DEPLOY_IN_PROGRESS`: Another deploy of the account is running (`409`).
  - `IDEMPOTENCY_KEY_CONFLICT`: The key was used with a different request.
  - `MAX_APPS_REACHED`, `MAX_DATABASES_REACHED`: The plan limit would be exceeded.
  - `WORKSPACE_OWNER_ONLY`: Only the owner of a workspace uses templates in it.
  - `DEPLOY_RATE_LIMITED`: Too many deploys in the last hour.
</ResponseField>
