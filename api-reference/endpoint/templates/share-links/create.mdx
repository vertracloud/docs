api: POST https://api.vertracloud.app/v1/templates/{template_id}/share-links

description: Creates a share link for a private template, in use mode or full-copy mode, with an optional use limit and expiry.

{/* @see RESTPostAPITemplateShareLinkBody, RESTPostAPITemplateShareLinkResponse — @vertracloud/api-types */}
This call creates a share link for a private template and answers `201` with the link and its token. **The token is shown only in this response and cannot be recovered**: store it now. Only a hash of it is kept, and the response is not cached. A token starts with `vtpl_`.

A link has one of two modes. A `use` link lets whoever opens it create their own applications from the template, without copying it. A `full_copy` link gives them a private template of their own, independent of yours, that counts against their limit of 5 private templates. `full_copy` needs `share.full_copy` set to `true` in the template, and it is not available for a [closed template](/templates/use/closed-templates) or for a version that has `env_hidden` variables. Read [Share links](/templates/create/share-links) before choosing.

Needs the `templates:write` scope when called with an API key. Only the owner of the template can create links; in a workspace, a member cannot even list them. Receivers see the notice "Not verified by Vertra" on the preview.

<ParamField path="template_id" type="string" required>
  The template ID.
</ParamField>

<ParamField query="workspace_id" type="string">
  If the template belongs to a workspace, the workspace's ID.
</ParamField>

<ParamField body="mode" type="string">
  `use` or `full_copy`. Default `use`.
</ParamField>

<ParamField body="max_uses" type="integer">
  The maximum number of uses. Without it, there is no limit. A use is counted when someone starts creating from the link; a use that is refused or undone is given back.
</ParamField>

<ParamField body="expires_in_days" type="integer">
  The number of days until the link expires. Without it, the link does not expire.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://api.vertracloud.app/v1/templates/tpl-abc123def456/share-links \
  -H "Authorization: Bearer $VERTRA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "mode": "use", "max_uses": 10, "expires_in_days": 7 }'
```

</RequestExample>

### Error Responses

<ResponseField name="code" type="string">
  The error code indicating the reason for the failure. Possible values:
  - `API_KEY_SCOPE_DENIED`: The API key does not have the `templates:write` scope (`403`).
  - `TEMPLATE_NOT_FOUND`: The template does not exist, is deleted or is not yours (`404`).
  - `TEMPLATE_SAVE_NOT_ALLOWED`: `full_copy` was requested and the template does not allow it (`share.full_copy` is not `true`) (`403`).
  - `TEMPLATE_CLOSED`: `full_copy` was requested for a closed template (`403`).
  - `VALIDATION_ERROR`: `max_uses` or `expires_in_days` is not a positive integer (`400`).
  - `WORKSPACE_OWNER_ONLY`: Only the workspace owner creates links for its templates.
</ResponseField>
