## Requirements

- Python 3.x installed locally
- Account on [Vertra Cloud](https://vertracloud.app)
- `requirements.txt` file at project root

## Project Structure

```
my-project/
├── main.py
├── requirements.txt
└── vertracloud.config  (optional)
```

## Configuration

### requirements.txt

List all project dependencies:

```txt
flask==3.0.0
gunicorn==21.2.0
requests==2.31.0
```

<Note>
  The platform automatically runs `pip install -r requirements.txt`. Do not include `venv` or `__pycache__` in the upload.
</Note>

### vertracloud.config (Optional)

```ini
MAIN=main.py
VERSION=recommended
```

## Example: Discord Bot (discord.py)

```python
import discord
import os

intents = discord.Intents.default()
intents.message_content = True

client = discord.Client(intents=intents)

@client.event
async def on_ready():
    print(f'{client.user} is online!')

@client.event
async def on_message(message):
    if message.author == client.user:
        return
    if message.content == '!ping':
        await message.send('Pong!')

client.run(os.environ['DISCORD_TOKEN'])
```

## Example: Flask API

```python
from flask import Flask, jsonify
import os

app = Flask(__name__)

@app.route('/')
def index():
    return jsonify({'message': 'Hello from Vertra Cloud!'})

@app.route('/health')
def health():
    return jsonify({'status': 'ok'})

if __name__ == '__main__':
    port = int(os.environ.get('PORT', 80))
    app.run(host='0.0.0.0', port=port)
```

## Deploy

<Tabs>
  <Tab title="Dashboard">
    1. Compress the project into a `.zip` (folders like `node_modules`, `venv` and `target` are removed automatically) or push it to GitHub.
    2. In the dashboard, click **New Project** and upload the `.zip` or paste the repository URL.
    3. In **Build**, check the runtime (**Python**), the main file (`main.py`) and the memory. Start and build commands are under **Advanced settings**.
    4. Add your environment variables in **Environment**.
    5. In **Network**, turn on **web publishing** so the app gets a `*.vertraweb.app` address (Pro plan or higher, 512 MB of memory). The app must listen on port 80.
    6. Review and deploy. Follow the output in the **Logs** tab.
  </Tab>
  <Tab title="CLI">
    ```bash
    vertra deploy
    vertra logs -f
    ```
    See [CLI](/cli) for installation and login.
  </Tab>
  <Tab title="VS Code">
    Open the folder with the Vertra Cloud extension installed and run **Deploy current project**. See [VS Code extension](/vscode-extension).
  </Tab>
</Tabs>

The full walkthrough is in [First deploy](/how-to-host).

## Notes

- **Dependencies** are automatically installed via `pip install -r requirements.txt`
- For **Discord bots**, set the token as environment variable `DISCORD_TOKEN` in the dashboard
- For **web APIs**, listen on port `PORT` and host `0.0.0.0`
- **Poetry** and **pipenv** are not natively supported; use `requirements.txt`

## Common Issues

<AccordionGroup>
  <Accordion title="ModuleNotFoundError">
    Check if the module is listed in `requirements.txt` with the correct version.
  </Accordion>
  <Accordion title="SyntaxError: invalid syntax">
    Make sure you are using the correct Python version. Python 3.10+ code may not work on earlier versions.
  </Accordion>
  <Accordion title="Bot doesn't connect to Discord">
    Check if environment variable `DISCORD_TOKEN` is configured in the application's environment variables.
  </Accordion>
</AccordionGroup>
