## Requirements

- Node.js installed locally (for development)
- Account on [Vertra Cloud](https://vertracloud.app)
- `package.json` file at project root

## Project Structure

```
my-project/
├── src/
│   └── index.js
├── package.json
└── vertracloud.config  (optional)
```

## Configuration

### package.json

Make sure `package.json` has a `start` script defined:

```json
{
  "name": "my-project",
  "version": "1.0.0",
  "main": "src/index.js",
  "scripts": {
    "start": "node src/index.js"
  },
  "dependencies": {
  }
}
```

<Note>
  The platform automatically runs `npm install` before starting your application. Do not include `node_modules` in the upload.
</Note>

### vertracloud.config (Optional)

```ini
MAIN=src/index.js
START=npm start
VERSION=recommended
```

## Example: Simple HTTP Server

```javascript
const http = require('http');

const port = process.env.PORT || 80;

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ message: 'Hello from Vertra Cloud!' }));
});

server.listen(port, '0.0.0.0', () => {
  console.log(`Server running on port ${port}`);
});
```

## Deploy

<Tabs>
  <Tab title="Dashboard">
    1. Compress the project into a `.zip` (folders like `node_modules`, `venv` and `target` are removed automatically) or push it to GitHub.
    2. In the dashboard, click **New Project** and upload the `.zip` or paste the repository URL.
    3. In **Build**, check the runtime (**JavaScript**), the main file (`index.js`) and the memory. Start and build commands are under **Advanced settings**.
    4. Add your environment variables in **Environment**.
    5. In **Network**, turn on **web publishing** so the app gets a `*.vertraweb.app` address (Pro plan or higher, 512 MB of memory). The app must listen on port 80.
    6. Review and deploy. Follow the output in the **Logs** tab.
  </Tab>
  <Tab title="CLI">
    ```bash
    vertra deploy
    vertra logs -f
    ```
    See [CLI](/cli) for installation and login.
  </Tab>
  <Tab title="VS Code">
    Open the folder with the Vertra Cloud extension installed and run **Deploy current project**. See [VS Code extension](/vscode-extension).
  </Tab>
</Tabs>

The full walkthrough is in [First deploy](/how-to-host).

## Notes

- **Dependencies** are automatically installed via `npm install`
- **Environment variables** can be configured in the dashboard or via API
- **Logs** are available in real-time in the dashboard terminal
- **Auto-restart** is on by default, automatically restarting on crash
- Always listen on `process.env.PORT` and on host `0.0.0.0`

## Common Issues

<AccordionGroup>
  <Accordion title="Error: Cannot find module">
    Make sure all dependencies are listed in `package.json`. The platform only installs what is declared.
  </Accordion>
  <Accordion title="EADDRINUSE: address already in use">
    Your application might be trying to use a fixed port. Use `process.env.PORT` for the correct port.
  </Accordion>
  <Accordion title="Container keeps restarting">
    Check the logs to identify the error. Syntax errors or missing dependencies are common causes. The crash loop detection system will pause auto-restart after 5 crashes in 10 minutes.
  </Accordion>
</AccordionGroup>
