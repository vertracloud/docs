## Requirements

- PHP 8.2+ installed locally
- Composer for dependency management
- Account on [Vertra Cloud](https://vertracloud.app)

## Project Structure

```
my-api-php/
├── src/
│   ├── index.php
│   └── routes.php
├── vendor/
├── public/
│   └── .htaccess
├── composer.json
└── vertracloud.config
```

## Configuration

### composer.json

```json
{
  "name": "example/my-api-php",
  "description": "PHP API on Vertra Cloud",
  "type": "project",
  "require": {
    "php": ">=8.2",
    "illuminate/http": "^10.0",
    "guzzlehttp/guzzle": "^7.5"
  },
  "require-dev": {
    "phpunit/phpunit": "^10.0"
  },
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  },
  "scripts": {
    "start": "php -S 0.0.0.0:${PORT:-8000} -t public"
  }
}
```

<Note>
  The platform automatically runs `composer install`. Do not include the `vendor` folder in the upload.
</Note>

### vertracloud.config

```ini
MAIN=public/index.php
START=php -S 0.0.0.0:$PORT -t public
VERSION=recommended
```

## Example: Simple REST API

### public/index.php

```php
<?php
header('Content-Type: application/json');

function json_response($data, $status = 200) {
    http_response_code($status);
    echo json_encode($data);
    exit;
}

if ($_SERVER['REQUEST_URI'] === '/' && $_SERVER['REQUEST_METHOD'] === 'GET') {
    json_response([
        'message' => 'API PHP on Vertra Cloud',
        'version' => '1.0.0'
    ], 200);
}

if ($_SERVER['REQUEST_URI'] === '/health' && $_SERVER['REQUEST_METHOD'] === 'GET') {
    json_response([
        'status' => 'healthy',
        'service' => 'php-api'
    ], 200);
}

json_response(['error' => 'Not found'], 404);
?>
```

## Deploy

<Tabs>
  <Tab title="Dashboard">
    1. Compress the project into a `.zip` (folders like `node_modules`, `venv` and `target` are removed automatically) or push it to GitHub.
    2. In the dashboard, click **New Project** and upload the `.zip` or paste the repository URL.
    3. In **Build**, check the runtime (**PHP**), the main file (`index.php`) and the memory. Start and build commands are under **Advanced settings**.
    4. Add your environment variables in **Environment**.
    5. In **Network**, turn on **web publishing** so the app gets a `*.vertraweb.app` address (Pro plan or higher, 512 MB of memory). The app must listen on port 80.
    6. Review and deploy. Follow the output in the **Logs** tab.
  </Tab>
  <Tab title="CLI">
    ```bash
    vertra deploy
    vertra logs -f
    ```
    See [CLI](/cli) for installation and login.
  </Tab>
  <Tab title="VS Code">
    Open the folder with the Vertra Cloud extension installed and run **Deploy current project**. See [VS Code extension](/vscode-extension).
  </Tab>
</Tabs>

The full walkthrough is in [First deploy](/how-to-host).

## Notes

- **Dependencies**: Use Composer to manage dependencies
- **Environment variables**: Access via `$_SERVER['...']` or use libraries like `vlucas/phpdotenv`
- **Logs**: Print to stdout/stderr to appear in dashboard logs
- **Sessions**: Configure in-memory sessions or with Redis if needed
- **Security**: Use `header('Content-Type: application/json')` for APIs
- Listen on `0.0.0.0` on port `$PORT`
